## C++・Rust差分検査

2026年8月1日、C++20の照会器とRust参照実装をGitHub Actions上で直接比較しました。

### 4×4

実行条件：

```bash
cargo run --release --bin kyouen-cross-check -- \
  --cpp /tmp/kyouen-query \
  --size 4 \
  --samples 40 \
  --seed 20260801 \
  --max-stones 8 \
  --solve-max-size 4
```

結果：

- 有効局面40個で合法手・禁止点・8対称・正規形が一致
- 意図的に作った禁止四つ組を含む無効局面1個を双方が拒否
- 40局面すべてのWIN・LOSSが一致
- 勝ち局面19個について、C++の勝ち手をRustで検査
- 同じ19局面について、Rustの勝ち手をC++で検査
- 勝ち手の相互検証は合計38回
- `cross_check=OK`

### 10×10

実行条件：

```bash
cargo run --release --bin kyouen-cross-check -- \
  --cpp /tmp/kyouen-query \
  --size 10 \
  --samples 100 \
  --seed 20260802 \
  --max-stones 12 \
  --solve-max-size 0
```

結果：

- 合法手だけを選ぶ決定的なランダムウォークで作った有効局面100個を比較
- 意図的に作った禁止四つ組を含む無効局面1個を双方が拒否
- 合法手集合が全件一致
- 空点のうち禁止される点が全件一致
- 8つの回転・反転後の盤面が全件一致
- 正規形が全件一致
- 禁止四つ組数54,441が一致
- `cross_check=OK`

10×10の差分検査は勝敗の巨大再探索ではありません。共円判定、合法手生成、禁止点生成、対称変換、正規化という探索の土台を二実装で照合したものです。

ローカルでも次の一括スクリプトで従来の検査を実行できます。

```bash
sh check.sh
```

差分検査の詳細と再現方法は [`CROSS_CHECK.md`](CROSS_CHECK.md) を参照してください。
