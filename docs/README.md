# Documentation

`docs/` は、初見の人が現在の研究内容を理解するための説明文書に寄せていきます。

将来的にここへ置くもの:

- ゲームのルール
- 現在の主要成果
- 弱解決・強解決の説明
- solver / certificate / Lean の役割
- 固定幅・一般化などの概説
- 関連研究

将来的にここへ置かないもの:

- 個別実験の preregistration
- 1回の測定結果
- 実装作業ログ
- 時系列のRound/Cycle報告

既存の実験固有文書は移行期間中そのまま残します。新規文書から役割分離を適用し、
安定後に `research/experiments/`, `research/log/`, `research/archive/` へ順次整理します。
