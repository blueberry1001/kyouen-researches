# Artifacts

このディレクトリは、他の明確な分類に入らない保存価値のある生成物のための場所です。

今後の基本的な境界:

- `results/`: CSV / JSON / 集計表など、解析結果として直接読むデータ
- `certificates/`: 勝敗・探索・定理などを機械検証する証明書
- `artifacts/`: 上記以外の、研究再現や監査のため保存する生成物

既存のファイルは互換性のためそのまま残します。新しいファイルを何でもここへ置くのではなく、
実験に閉じるものは可能なら `research/experiments/<experiment>/` に置きます。
