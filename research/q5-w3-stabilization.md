# q=5・3×m の安定化：184→56、m=11 証人、m=12..16 完全排除

## 結論

q=5 の 3×m 盤について、一般 q 点版固定幅定理の十分条件は
[
T_{3,5}=184
]
だった。三行・五点版の行構造を直接使うと、これを

[
oxed{M_{3,5}le56}
]

まで改善できる。

一方、3×11 には11石の極大安全集合が存在するので

[
oxed{M_{3,5}ge12}.
]

従って現時点の厳密なブラケットは

[
oxed{12le M_{3,5}le56}.
]

さらに m=12,13,14,15,16 については、専用の完全列挙により
**不足行を持つ極大安全集合が存在しない**ことを確認した。従ってこの5盤では
全極大安全集合が12石であり、全安全局面 S について

[
oxed{g(S)=(12-|S|)mod2}
]

が成立する。q=5 は奇数なので、これらの空盤は全て後手勝ちである。

ただし m=12..16 の成立だけから「以後ずっと」を推論してはいけない。
真の安定化長を一点に閉じるには m=17..55 の再出現可能性を排除する必要がある。

## 1. なぜ五点共円は 2+2+1 だけか

三行を y=0,1,2 とする。q=5 では同一行に5石置けば共線になるので、安全集合では
各行4石以下である。

一つの円は各水平行と高々2点でしか交わらない。従って5点が一円上に載るなら、
三行への分布は必ず

[
2+2+1
]

である。

また水平行そのものではない直線は三行と高々3点でしか交わらない。
従って、石が3個以下の対象行 L に新点 p を置いたときに新しい禁止5点組ができるなら、
それは必ず円による。

## 2. 解析上界 56

対象行 L の既存石数を a≤3、残り二行の占有 x 座標集合を B,C とする。
安全性から |B|,|C|≤4 である。

L 上の空点 p が円で塞がれる場合を、円上の既存 L 点数で二種類に分ける。

### 2.1 p が L 上で唯一の点の場合

この円は B から2点、C から2点を取る。

水平な二本の弦が同じ円に載るなら、その中点の x 座標は同じである。
従って B の二点対と C の二点対は同じ x 座標和 s を持つ必要がある。

4点以下の集合 X について

[
r_X(s)=#{{x,x'}subset X:x+x'=s}
]

とする。4個の相異なる実数では、同じ二点和を持つ異なる二対は互いに素であり、
重複和は高々一つしかない。従って

[
sum_s r_X(s)^2le8.
]

Cauchy--Schwarz により、同じ和を持つ B,C の二点対の組数は

[
sum_s r_B(s)r_C(s)
le
sqrt{sum_s r_B(s)^2sum_s r_C(s)^2}
le8.
]

各二点対の組は高々一つの円を決め、その円は L と高々2点で交わる。
従ってこの型で塞げる L 上の点は高々

[
16
]

個である。

### 2.2 p と既存一点 a∈L が同じ円に載る場合

残り三点は、一方の外部行から2点、もう一方から1点である。

例えば B の二点 b1,b2 が円上にあるなら、水平弦の中点が一致するため

[
a+p=b_1+b_2.
]

従って B の一つの二点対ごとに p は高々一つしかない。
B は4点以下なので二点対は高々6個。C が二点を出す場合も同様に高々6個である。

よって固定した既存点 a 一つにつき、新たに塞げる点は高々

[
6+6=12
]

個。既存 L 点は a≤3 個なので、この型は高々 12a 点を塞ぐ。

### 2.3 合計

L 上の利用不能点数は、占有済み a 点も含めて

[
a+16+12a=16+13ale55.
]

従って

[
mge56
]

なら、石が3個以下の行には必ず合法な追加点がある。

よって m≥56 の極大安全集合は各行4石、総数12石である。
残り手数について帰納すれば

[
oxed{g(S)=(12-|S|)mod2}
]

が全安全局面で成立する。

これは一般上界 T_{3,5}=184 を 56 まで改善する全称的な証明である。

## 3. 3×11 の不足極大証人

次の配置を考える。

[
egin{aligned}
y=0 &: {1,4,8},\
y=1 &: {1,2,4,7},\
y=2 &: {1,4,7,10}.
end{aligned}
]

石数は11であり、満容量12より1少ない。

検証器は lifted matrix
[
(x^2+y^2,x,y,1)
]
の全4行小行列式を整数で検査し、この11点集合が q=5 の意味で安全であることを確認する。
さらに盤内の残り22点を一つずつ追加し、全てで禁止5点組が発生することを直接確認する。

従ってこの集合は 3×11 の11石極大安全集合であり、

[
oxed{M_{3,5}ge12}
]

である。

## 4. m=12..16 の完全排除

不足行 L を持つ極大安全集合があると仮定する。L は高々3石、他の二行は高々4石である。

不存在証明では、他の二行を任意に4石まで、L を任意に3石まで**形式的に追加**してよい。
追加後の集合が安全である必要はない。点を追加しても、元から存在した禁止完成円は消えず、
新しい blocker は増えるだけだからである。

従って、不足極大集合が存在するための必要条件として、

- 対象行 A: 3点
- 他行 B,C: 各4点

という拡張配置だけを調べれば十分である。

専用検証器は B,C の全4-subset を列挙し、対象行が外側の場合と中央の場合を別々に扱う。

円方程式を各水平行へ制限すると、二根の和 s は全行で共通で、積 p_i は

[
p_0-2p_1+p_2=2
]

を満たす。この式を使って、B,C から対象行上で塞がれ得る点を整数演算だけで生成する。
その blocker 集合と3個の占有点で対象行全体を覆えるかを全3-subsetについて検査する。

結果は次の通り。

| m | 4-subset 数/行 | 外側行を全て覆う候補 | 中央行を全て覆う候補 |
|---:|---:|:---:|:---:|
| 12 | 495 | なし | なし |
| 13 | 715 | なし | なし |
| 14 | 1001 | なし | なし |
| 15 | 1365 | なし | なし |
| 16 | 1820 | なし | なし |

従って m=12..16 では不足極大安全集合は存在せず、全極大集合が12石である。
