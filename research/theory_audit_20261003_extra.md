# 中心分母5・8の完全点数と、最小半径の逆転定理

2026-10-03。有限盤で切断する前の、円上の**全整数格子点**を扱う。
中心の正確な共通分母を q とし、少なくとも m 点を持つ円の最小半径を `R_q(m)` と書く。
「正確な分母」とは中心 `(a/q,b/q)` が `gcd(a,b,q)=1` を満たすことをいう。

既存の[分母3・4の定理](verification/round10-circle-denominator.md)と
[分母6の定理](theory-audit-20261003.md#4-正確な中心分母6の点数公式と最小半径)を拡張する。
以下の一般公式・比較は証明付きであり、有限計算からの推測ではない。

## 結果

- **分母5:** すべての非空円で、既存の一般上界が等号になる。
  最小半径は、素数5を除いた `1 mod 4` 素数の約数個数の最適化へ厳密に還元される。
- **分母8:** `5 mod 8` 素数の指数配分の偶奇だけで点数が決まる。
  こちらも全 m の最小半径を、明示した整数の最小化へ厳密に還元できる。
- **順序の逆転:** 分母8は m=1,2 では分母4・6より小さい半径を実現するが、
  **すべての m≥3 で分母4・6より大きい半径を必要とする。**
  分母5も m=1 では分母4より有利だが、全 m≥2 では不利になる。
- 任意の分母 q に対する **2点閾値の閉形式**も得られる。
- 2点閾値は分母を大きくしても有界だが、**固定 m≥3 の最小半径は少なくとも √q の速さで発散する**。

## 1. 共通の記法

円の中心を `(a/q,b/q)`、半径を R とし、`M=q²R²` と置く。
格子点があれば M は正整数である。
対応 `z=(qx−a)+i(qy−b)` により、完全点数は

```
z conjugate(z)=M,     z≡−a−bi (mod q Z[i])
```

を満たすガウス整数の個数になる。

`3 mod 4` 素因数が奇数冪で現れる M には、そもそも二平方和表現がない。
以下、その障害がない場合の `1 mod 4` 素数の指数を e_p とし、

```
D(M) = ∏_{p≡1 (mod 4)} (e_p+1)
N_m  = min { ∏_{p≡1 (mod 4)} p^{e_p} : ∏(e_p+1)≥m }
```

とする。空積1も認める。既存結果は

```
R_4(m)² = N_m/16          (m≥1)
R_6(m)² = N_m/18          (m≥2)
R_6(1)² = 1/36
```

である。

## 2. 分母5: 上界の等号と全閾値の式

### 2.1 完全点数

```
D5(M) = ∏_{p≡1 (mod 4), p≠5} (e_p+1)
```

とする。**正確な分母5の円は、非空なら必ず完全点数 D5(M) を持つ。**
より詳しく、24個の原始中心剰余類を走査した点数分布は

| M の条件 | 非空剰余類の個数 | 各円の完全点数 |
|---|---:|---:|
| 5∤M | 4 | D5(M) |
| 5∣M | 8 | D5(M) |

となり、残りは空である。二平方和表現がない M では全部空とする。

**証明。** 法5のガウス整数環は `F₅×F₅` と同型であり、ノルムは二成分の積になる。
非零ノルムの剰余類は4個で、四単数 `{±1,±i}` が推移的に作用する。
したがって 5∤M では、どの素因数配分からも指定剰余類にちょうど一つの単数倍が入る。

5∣M の場合、`5=ππ̄` の指数を両側へ分けると z が5で割り切れ、中心が原始でなくなる。
許されるのは全指数をπ側またはπ̄側に寄せる二通りだけである。
両者は法5で二つの零ノルム軸の非零部分へ写り、それぞれ4剰余類からなる単数軌道となる。
他の素因数配分の数は D5(M) なので、主張の分布を得る。□

### 2.2 最小半径

```
E_m = min { ∏_{p≡1 (mod 4), p≠5} p^{e_p} : ∏(e_p+1)≥m }
```

と置く。候補 `13^(m−1)` があるため、全 m≥1 で最小値が存在する。
前節の完全点数から

\[
\boxed{R_5(m)^2=E_m/25\qquad(m\ge1)}
\]

となる。実際、Mから2、5、惰性素数の因子を除いても D5 は変わらず、
残った積は E_m 以上である。逆に M=E_m は表現を持ち、4個の原始中心で D5≥m を達成する。

### 2.3 分母4との一様比較

m≥2 なら E_m には素因数 p≥13 がある。
その `p^e` を `5^e` に置き換えると約数個数を保って N_m の候補となるので

```
N_m ≤ E_m (5/p)^e ≤ 5E_m/13.
```

従って

\[
\boxed{R_5(m)^2\ge\frac{208}{125}R_4(m)^2\quad(m\ge2).}
\]

m=2 では E₂=13、N₂=5 なので、この比較定数は等号を達成する。
一方、m=1 では `R₅(1)²=1/25<1/16=R₄(1)²` であり、2点を要求した時点で順序が逆転する。

## 3. 分母8: 二つの単数軌道への配分

### 3.1 完全点数の公式

```
D0 = ∏_{p≡1 (mod 8)} (e_p+1)
D1 = ∏_{p≡5 (mod 8)} (e_p+1)
δ  = 1  if every e_p for p≡5 (mod 8) is even; otherwise 0
U(M) = D0(D1+δ)/2
```

とする。原始中心剰余類は `8²−4²=48` 個である。
`v₂(M)≥2` なら表現の両座標が偶数になり、分母8の原始中心はすべて空である。
二平方和表現があり `v₂(M)≤1` なら、48個の剰余類の点数は重複込みで

```
4個: D0(D1+δ)/2
4個: D0(D1−δ)/2
40個: 0
```

となる。したがって中心を選べるときの最大完全点数は U(M) である。

**証明。** 各分裂素数 p に対し、ノルム p のガウス素数を
`π=a+bi`、a が奇数・b が偶数となるように選ぶ。
法8でπは可逆であり、直接計算すると

```
π/π̄ ≡ 1        if p≡1 (mod 8),
π/π̄ ≡ 1+4i     if p≡5 (mod 8).
```

実際、前者は4∣b、後者は b≡2 (mod 4) に対応する。
`r=1+4i` と置くと `r²≡1 (mod 8)` なので、素因数配分の影響は後者の指数和の偶奇だけになる。

基準表現を z₀ とすると、二つの候補は単数軌道 `z₀{±1,±i}` と `rz₀{±1,±i}` である。
これらは原始表現について異なる4元軌道となる。
Mが奇数なら z₀ は法8で可逆で、rが単数でないことから区別できる。
Mが偶数なら z₀ の両座標が奇数であり、r倍は両座標へ4を加える操作になる。
これはどの単数倍とも一致しない（例えば−1との一致は座標が偶数であることを要求し、
±iとの一致も合同式を加減すると同じ矛盾を生む）。

配分指数の偶数・奇数個数は、`T²=1` における

```
D0 ∏_{p≡5 (mod 8)} (1+T+…+T^{e_p})
```

の二係数であり、それらは `D0(D1±δ)/2` となる。□

### 3.2 全閾値の厳密な最適化式

```
P_m = min { K=∏_{p≡1 (mod 4)} p^{e_p} : U(K)≥m }
```

と置く。`17^(m−1)` が候補なので、最小値は常に存在する。
上の公式の U は2の因子や惰性素数の偶数冪に依存しないため、最小半径は

\[
\boxed{R_8(m)^2=P_m/64\qquad(m\ge1)}
\]

である。これは単なる上界ではない。
任意の M から点数を保って不要な因子を除けるので下界となり、
M=P_m の大きい側の単数軌道を中心として選べば達成される。

### 3.3 3点以降での順序逆転

**定理。すべての m≥3 に対して**

\[
\boxed{P_m\ge5N_m,\quad
R_8(m)^2\ge\frac54R_4(m)^2
             =\frac{45}{32}R_6(m)^2.}
\]

証明は P_m=K の素因数を二場合に分ける。

1. `p≡5 (mod 8)` が指数 e≥1 で現れる場合。
   他の配分を固定すると、指定された偶奇を満たす配分は高々 `⌊e/2⌋+1` 個。
   p の指数を `⌊e/2⌋` に下げた積の通常の約数型点数は、元の円の点数以上となる。
   よって `N_m≤K/p^{⌈e/2⌉}≤K/5`。
2. すべての素因数が `1 mod 8` の場合。
   これらの最小素数は17、次は41である。
   指数 e≥2 の素因数があれば、それを `5^e` へ置換して
   `N_m≤(5/17)²K<K/5`。
   すべての指数が1なら、m≥3 のため異なる素因数が少なくとも二つある。
   小さい二つを5と13へ置換し、
   `N_m≤65K/(17·41)<K/5` を得る。

いずれも約数個数を保つか必要点数以上を保つため、N_m の正当な候補である。□

小さい閾値を比較すると

| m | R₄(m)² | R₆(m)² | R₈(m)² |
|---:|---:|---:|---:|
| 1 | 1/16 | 1/36 | **1/64** |
| 2 | 5/16 | 5/18 | **17/64** |
| 3 | 25/16 | **25/18** | 289/64 |

で、m=1,2では分母8の方が小さい。
**最初の2点までの比較を、3点以上へ外挿すると順序が逆になる。**
分母8の3点最小例は中心 `(1/8,0)`、半径 `17/8` の円で、
完全な点集合は `(-2,0),(2,-1),(2,1)` である。

## 4. 全分母に対する2点閾値

任意の正整数 q について

\[
\boxed{
R_q(2)^2=
\begin{cases}
\frac12+\frac1{2q^2},&q\text{ が奇数},\\
\frac14,&q=2,\\
\frac14+\frac1{q^2},&q\ge4\text{ が偶数}.
\end{cases}}
\]

**奇数 q。** 距離1の格子点対を通る円の中心は一座標が真の半整数になるため、奇数分母では不可能。
次の候補は距離√2の対 `(0,0),(1,1)` である。
その垂直二等分線上では中心を `(1/2+t,1/2−t)` と書け、
分母qの座標は半整数から少なくとも `1/(2q)` 離れる。
したがって半径二乗は `1/2+2t²≥1/2+1/(2q²)`。
より遠い格子点対の距離二乗は4以上なので、半径二乗は1以上であり、この値を下回らない。
中心 `((q−1)/(2q),(q+1)/(2q))` で等号となり、分子が連続整数なので分母は正確にqである。

**偶数 q≥4。** 距離1の対 `(0,0),(1,0)` を取れば、中心は `(1/2,b/q)`。
垂直変位0では正確な分母が2になってしまうので、正確なqでは変位が少なくとも1/qである。
よって半径二乗は `1/4+1/q²` 以上で、中心 `(1/2,1/q)` が達成する。
距離√2以上の対では半径二乗が1/2以上となり、この値を下回らない。
q=2の例外は中心 `(1/2,0)`・半径1/2である。□

この定理は、分母5・6・8の2点閾値と独立に一致する。
分母の奇偶により、半径二乗の極限が `1/2` と `1/4` に分かれることも明示される。

## 5. 2点と3点の間の、分母に関する成長の違い

正確な分母 q の円に3個以上の格子点があるとし、原始整数方程式を

```
A(x²+y²)+Bx+Cy+D=0,     A>0, gcd(A,B,C,D)=1
```

とする。格子点を一つ原点へ平行移動すれば D=0 になり、
原始化から `gcd(A,B,C)=1` が従う。
中心の分母は `2A/gcd(2A,B,C)` なので、その最大公約数は1または2である。
後者の場合は A が奇数でなければならない。したがって

\[
\boxed{A=\frac{q}{\gcd(q,2)}}.
\]

また、同じ円上の任意の格子三角形の符号付き面積の2倍 d は A の整数倍になる。
一頂点を原点へ移し、残る二点の円方程式へ Cramer の公式を適用すると
`A∣dB` と `A∣dC` が得られ、`gcd(A,B,C)=1` から `A∣d` が従うためである。
三点は非共線なので、その面積は少なくとも A/2 である。

半径Rの円に内接する三角形の最大面積は、正三角形の `3√3 R²/4`。
これを使うと、すべての m≥3 に対して

\[
\boxed{R_q(m)^2\ge\frac{2q}{3\sqrt3\,\gcd(q,2)}}.
\]

さらに円上の m 点は厳密凸位置にある。
それらの凸多角形を一頂点から m−2 個の三角形へ分けると、面積は少なくとも `(m−2)A/2`。
多角形は面積πR²の円盤に含まれるので

\[
\boxed{R_q(m)^2\ge\frac{q(m-2)}{2\pi\,\gcd(q,2)}}
\]

も成り立つ。二つの下界は大きい方を使える。

さらに、内接m角形の最大面積 `mR² sin(2π/m)/2` を使うと、これらを

\[
\boxed{R_q(m)^2\ge
\frac{(m-2)q}{m\sin(2\pi/m)\,\gcd(q,2)}}
\]

へ強化できる。最大面積が正m角形で達成されることは、隣接点間の中心角を使って示せる。
πを超える中心角があれば隣接頂点を動かして面積を増やせるため最大ではなく、
残る `[0,π]` 上では sin の凹性から中心角が等しいときに最大となる。
m=3では最初の三角形下界そのものである。

従って、分母 q→∞ に対して2点閾値は前節の一定値へ収束する一方、
**どの固定 m≥3 の閾値も発散する**。
「分母を大きくすると小さい円に点を集めやすい」という2点での現象は、3点以上では継続しない。
ここで主張したのは一般下界であり、任意の q に対して同じ次数の上界があるとまでは主張しない。
