# 格子円の全中心最大値と、帯幅定理の独立監査

2026-10-03。対象は退化しない円と整数格子点です。
本稿の `M(n)` は n×n 盤の円上最大点数であり、局面の Grundy 最大値とは別です。

[分母5・8と全分母への続編](theory_audit_20261003_extra.md)では、
点数閾値による最小半径の順序逆転と、2点・3点の間の分母依存の違いを証明しています。

## 確定した結果

1. **n=2,…,112 について、中心・半径に打切りを設けず M(n) を厳密決定した。**
   半整数中心に限らない全円を対象にし、従来の F-K / F-Z にあった有限範囲の根拠不足を補う。
2. 同じ範囲で、中心が `(1/2)Z²` に属さない円の最大点数 `M_other(n)` も厳密決定した。
   n≥4 では今回の全範囲で `M_other(n)≤M(n)/2` だった。これは**有限計算の事実**で、全 n の定理ではない。
3. [帯幅の一般定理](geometry-20261003.md)を独立に監査し、最後に残った幅17を**法43**で排除した。
   これにより「任意の円は、w≥16 の連続整数行の中に高々 w 格子点を持つ」が成立する。
   幅15には16点円が入るため、すべての幅以降で成立する開始幅16は最良である。
4. **正確な中心分母6について、点数公式と全点数閾値の最小半径を証明した。**
   2点以上を要求する全閾値で、分母6の最小半径は分母4の `√(8/9)` 倍になる。
   分母が大きいほど不利という単調性に対する、有限例ではない新しい比較である。

### 全円を尽くせる理由

盤は `{0,…,n−1}²` とする。
円の盤内点集合の最小 x 座標を整数平行移動で0にする。
これにより、もとの全点が盤内に残り、円は左端の点 `(0,a)` を通る。
必要なら y を `n−1−y` に反転すれば、ある左端点について `a≤(n−1)/2` とできる。
したがって最大値の探索では、この範囲の左端アンカーだけを調べればよい。
平行移動と反転は、中心が半整数格子に属するかどうかも保存する。

アンカー `(0,a)` から見た二点の差を `(x,y),(X,Y)` とし、

```
A = xY − Xy
B = (x²+y²)Y − (X²+Y²)y
C = x(X²+Y²) − X(x²+y²)
```

とする。`A≠0` のとき円は

```
A·(u²+v²) = B·u + C·v
```

と一意に定まる。A を正にして `gcd(A,B,C)` で割れば、アンカー固定の正規化キーになる。
すべて整数演算であり、円の中心や半径を浮動小数点で比較しない。

一つの円が盤内に m 点を持ち、アンカーを含むなら、キーの出現数は厳密に
`binom(m−1,2)` である。円上の相異なる三点は非共線なので、欠ける対はない。
プログラムは全キーをソートし、同じキーの点対の端点から円上点集合を復元する。
その個数と `binom(m−1,2)` の一致も assertion で検査する。

中心の2倍は相対座標で `(B/A,C/A)` なので、正規化後の **A=1 が半整数中心の必要十分条件**。
同じ探索から両種の最大値が得られる。

最大盤 N=112 の探索中に、復元点集合を `{0,…,n−1}²` へ切り戻せば全 n≤N の値を同時に得る。
小さい n についてもアンカー条件 `a≤(n−1)/2` を満たすものだけを使用する。
最大値を与える小盤の円は、この大盤の列挙にも必ず含まれる。
3点以下の例外は明示的な下界例で初期化している。

処理した非共線アンカー点対は **4,402,821,304** 個。
4点以上の円とアンカーの組は **87,611,618** 個だった。
後者は異なる円の総数ではない。
主配列は最大約1.26 GB。各アンカーを順に処理するため、全円を同時にメモリへ保存しない。

## 2. 帯幅定理の独立監査と法43

一般証明は[主論文](geometry-20261003.md)にまとめた。
本担当は次を独立に確認した。

- 円の方程式 `x²+y²+Bx+Cy+D=0` について、同じ整数行に2点があれば B は整数。
- C の既約分母 v が3以上なら、すべての占有行は法 v で一致するため、
  点数は `2 ceil(w/v)≤w`（w≥3）。
- v=2 で奇数幅に1点超過するには、該当する全行が2点ずつ必要。
  5連続の該当行は法9の平方剰余条件で不可能。
- v=1 なら D も整数で、占有行は
  `N−(2y+C)²` が平方数となる行に限られる。
  法441の全 **441²** 個の `(C,N)` を直接列挙すると、
  幅16、18、20,…,31では該当行数が幅の半分以下になる。
- 幅19は、法9、49、121の行マスクを交差させると10行以上の候補が消える。
- 幅17は、法9、49、121の交差後に唯一
  `{0,2,5,7,8,9,11,14,16}` が残る。
  **法43の全1,849組の `(C,N)` のどれも、この9行すべてを平方剰余にできない。**
  これで幅17も排除される。

すべての w≥16 は、幅16のブロックと最後の幅16,…,31のブロックへ分割できる。
各ブロックの上界を足せば一般定理が得られる。
中心や半径が非常に大きい円にもこの議論が適用される。

[独立検算スクリプト](verification/scripts/theory_audit_20261003_verify.py)は
主論文のスクリプトを import せず、剰余対の直接ループから同じ結論を得る。
この法43による追加は、円の有限半径探索による不存在判定ではない。

## 3. F-K / F-Z の扱いと未解決範囲

従来の F-K / F-Z では、半整数中心だけの走査を根拠に「全円の最大」と記していた。
その走査だけでは、中心分母3以上の円を排除できない。
後年の B131 / B132 の個票ではこの一般問題が未解決として区別されている。
今回の全中心探索により、**n≤112 の最大値に限って**この証拠の穴を埋めた。

また F-K の旧本文には、n=8,…,24で N=130 の16点が入るとの記載があるが、
その完全な16点を収容できるのは **n=12 から**であり、n=8,…,11 の最大は12点である。
F-Z の二平方和表現数の恒等式自体と、盤内最大値への還元は分けて扱う必要がある。
円の完全点数が32でも、有限盤で切断された28点が最大となる n=46,47 のような段階もある。

今回も次は証明していない。

- 任意の n で、最多点円を半整数中心から選べること（B131 の全称形）。
- 任意の n≥4 で `M_other(n)≤M(n)/2` となること。
- 盤内最大点数の一般的な閉形式や、上記停滞区間が無限に続く規則。

帯幅16の一般定理は、これらとは別に全幅・全半径について証明されている。

## 4. 正確な中心分母6の点数公式と最小半径

この節は有限盤で切断する前の、**円上の全格子点数**を扱う。
中心を `(a/6,b/6)`、`gcd(a,b,6)=1` とし、半径を R、`M=36R²` と書く。
格子点が存在すれば M は正整数である。
点数は、ノルム M のガウス整数 `z=u+iv` のうち
`(u,v)≡(−a,−b) (mod 6)` であるものの個数に等しい。

### 4.1 中心の剰余類ごとの完全点数

M の `p≡1 (mod 4)` の素因数の指数を e_p とし、

```
D0 = ∏_{p≡1 (mod 12)} (e_p+1)
D1 = ∏_{p≡5 (mod 12)} (e_p+1)
δ  = 1  if all e_p for p≡5 (mod 12) are even; otherwise 0
```

と定める。空積は1とする。
素数3の因子がある場合、`v₂(M)≥2` の場合、または `3 mod 4` 素因数の奇数冪がある場合は、
正確な分母6の円に格子点はない。
以下はこれらに該当しない場合である。

**M が偶数の場合。** 非空な中心剰余類は4個あり、各円の完全点数はすべて

```
D0 D1
```

である。他の20個の原始中心剰余類は空である。

**M が奇数の場合。** 24個の原始中心剰余類の点数は、重複込みで

```
4個: D0(D1+δ)/2
4個: D0(D1−δ)/2
16個: 0
```

となる。後者の式が0なら、その4個も空である。
ここでは各組の点数の集合を記述しており、どの中心が上側の値を取るかまで固定していない。

証明はガウス整数の素因数配分を法6で分類することで得られる。
法3では、非零ノルムを指定した剰余類は四単数の一軌道なので、
各素因数配分に対し、指定剰余類に合わせる単数は一意である。
M が偶数なら両座標が奇数であり、法2の条件は四単数すべてで変わらない。
したがって全 `D0D1` 配分が通る。

M が奇数なら、一方の座標だけが奇数である。
`p=ππ̄` の配分を一段変えると、法3での比は `π/π̄` になる。

- `p≡1 (mod 12)` では、π の片方の座標が法3で0になり、この比は `±1`。
  単数を調整しても座標の偶奇は入れ替わらない。
- `p≡5 (mod 12)` では、両座標が法3で非零になり、この比は `±i`。
  単数の調整が座標の偶奇を入れ替える。

よって法2の残りの条件は、後者の素因数配分指数の和の偶奇だけで決まる。
生成多項式を `T²=1` のもとで掛ければ、その二つの係数は
`D0(D1±δ)/2` である。
四単数で回転した4中心が各値を共有し、上の公式が従う。

### 4.2 全閾値に対する最小半径

[分母3・4の既存定理](verification/round10-circle-denominator.md)と同じく

```
N_m = min { ∏_{p≡1 (mod 4)} p^{e_p} : ∏(e_p+1)≥m }
```

とし、中心の正確な分母が q で少なくとも m 点を持つ円の最小半径を `R_q(m)` とする。

**定理。**

\[
R_6(1)^2=1/36,\qquad
\boxed{R_6(m)^2=N_m/18\quad(m\ge2).}
\]

従ってすべての m≥2 で

\[
R_6(m)=\frac{1}{\sqrt2}R_3(m)
      =\sqrt{\frac89}\,R_4(m).
\]

**達成。** `M=2N_m` と取る。
上の偶数ノルム公式により、適切な原始中心剰余類で `D(N_m)≥m` 点を持つ。
半径二乗は `M/36=N_m/18` である。

**下界：偶数 M。** 少なくとも m 点なら `D(M)≥m`。
2進因子と `3 mod 4` 素因数を除いた積は少なくとも N_m であるため、
`M≥2N_m` となる。

**下界：奇数 M。** 次の二場合に分ける。

1. `p≡5 (mod 12)` の素因数 p が指数 e≥1 で現れる場合。
   他の配分を固定すると、p の e+1 個の配分のうち指定された偶奇を満たすものは
   高々 `⌊e/2⌋+1` 個である。
   p の指数を `⌊e/2⌋` へ下げた積の約数型点数は、元の円の点数以上を保つ。
   不要な惰性素因数も除けば N_m の候補となるので
   `N_m≤M/p^{⌈e/2⌉}≤M/5`。特に `M>2N_m`。
2. そのような素因数がない場合。
   m≥2 なので `p≡1 (mod 12)` の素因数 p≥13 が少なくとも一つある。
   その `p^e` を `5^e` に置換すると約数型点数を保ち、
   N_m の候補は `M(5/p)^e≤5M/13<M/2` となる。
   ここでも `M>2N_m`。

したがって奇数 M では上の達成例を上回れず、定理が示された。
m=1 については `M≥1` と、中心 `(1/6,0)`・半径 `1/6` の円で等号を達成する。

例えば4点閾値は `N_4=65` なので、分母6の最小半径二乗は **65/18**。
中心 `(7/6,3/2)` の円は `(0,0),(0,3),(3,1),(3,2)` の4点を持ち、これを達成する。
分母4の最小値 **65/16** より小さい。
