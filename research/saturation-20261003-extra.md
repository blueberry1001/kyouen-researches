# 21石・22石の構成と、10盤の局所最適性障壁

標準ルール（同一直線・同一円上の4点を禁止）、盤面
\(B_n=\{0,\ldots,n-1\}^2\) を扱う。\(K_n\) は安全集合の最大サイズ。
点番号は \(p=x+ny\)。2026-10-03 の
[飽和集合ノート](saturation-20261003.md) の追加研究である。

## 明示構成：\(K_{11}\ge21\)、\(K_{12}\ge22\)

次の21点集合 \(A\subset B_{11}\) は安全かつ極大である。

```text
2,6,17,19,23,27,35,38,44,68,73,81,84,85,88,89,91,106,108,110,120
```

これは前ノートのほぼ安全な20点集合

```text
U = [2,6,16,18,21,25,32,35,40,59,62,67,74,77,78,80,81,83,97,99]
```

から10盤の点番号59、すなわち \((9,5)\) を除いた19点集合を、そのまま
11盤に埋め込み、\((0,10),(10,10)\) を加えて得られる。
この19点集合が11盤で持つ合法な追加点は**ちょうどこの2点**であり、
2点を同時に追加しても安全性を保つ。

さらに \(A\) を \((1,0)\) だけ平行移動して12盤に入れると、合法な追加点は
\((0,11)\) だけになる。これを追加した22点集合を \(C\) とする。

```text
C = [(3,0),(7,0),(7,1),(9,1),(2,2),(6,2),(3,3),(6,3),(1,4),
     (3,6),(8,6),(5,7),(8,7),(9,7),(1,8),(2,8),(4,8),
     (8,9),(10,9),(1,10),(11,10),(0,11)]
```

独立検証器は \(A\) の全 \(\binom{21}{4}=5985\) 組、\(C\) の全
\(\binom{22}{4}=7315\) 組について整数行列式が非零であることを確認する。
さらに、それぞれ100個・122個の空点すべてに禁止4点組の証人を与える。
したがって両集合は安全であるだけでなく極大である。

これらを世界記録や最適値とは主張しない。既存の `research/findings.md`、
`research/exploration/`、`research/verification/` の \(K_{11},K_{12}\)、
11盤・12盤および21石・22石の記述を再照合した範囲では、同じ有効な下界証人は
確認できなかった。旧 `N11-STATE-SPACE.md` の \(K_{11}=11\) は撤回対象で、
`N11-WORKLOG.md` も旧計算を棄却している。旧文書が参照する
`fact_kmin_n11_safe.json` はこのチェックアウトでは見つからず、
その名前だけから内容を推測していない。本節の主張は上記座標の直接検証に依存する。

## 22点集合は盤外の1層も完全に塞ぐ

\(C\) は12盤で極大というだけでなく、外側1層
\(\{-1,\ldots,12\}^2\setminus B_{12}\) の**52点すべて**を塞ぐ。
したがって \(C+(1,1)\) は14盤でも22点のまま極大である。

さらに外側2層目
\(\{-2,\ldots,13\}^2\setminus\{-1,\ldots,12\}^2\) の60点では、
合法な点はちょうど

\[
(-2,13),\qquad(12,-2)
\]

の2点である。両方を追加して \((2,2)\) だけ平行移動すると、16盤の安全極大24点集合を得る。
全 \(\binom{24}{4}=10626\) 組と、232個の空点を独立に検証した。
大盤の最適下界を狙った主張ではなく、小さな核が周囲の格子点をどこまで塞ぐかの
具体的な幾何証人である。検証JSONは外周の各被覆点にも、元の22点のうちの
3点と、それらが定める円または直線の整数係数を保存する。

## 10盤の19点集合から20点への、9点交換までの障壁

前ノートの安全極大19点集合

```text
T = [0,7,8,14,16,20,21,31,35,42,47,67,69,70,73,82,89,93,99]
```

について、次の**局所的な非存在**を完全探索で得た。

> 安全な20点集合 \(S\subset B_{10}\) で \(|S\cap T|\ge10\) となるものはない。

探索器は \(T\) から1点〜9点を除くすべての選択について、残りを含む20点安全集合を
昇順に全列挙する。途中では禁止点集合を更新し、残り合法点数が不足した枝だけを打ち切る。
合計 \(\sum_{r=1}^9\binom{19}{r}=262143\) 個の削除部分集合、
364,429,603個の拡張節点を完走し、解はなかった。
\(S\) と \(T\) の共通点が10点以上あれば、そのうち10点を残す9点削除の枝で必ず探索される。

同じ探索を \(F_0=U\setminus\{25\}\) に対して行っても、262143部分集合、
426,848,807節点を完走して解がない。
したがって任意の安全な20点集合に対して \(|S\cap F_0|\le9\) である。

## ほぼ安全な20点全体についての、制限付き最適値19

\(U\) の禁止4点組は唯一で、

\[
Q=\{25,59,62,83\},\qquad x^2+y^2-11x-11y+48=0
\]

の円上にある。\(q\in Q\) を1個除いた4集合 \(U\setminus\{q\}\) はすべて
安全極大19点集合であり、一石交換で互いに移り合う \(K_4\) をなす。

この \(U\) に対して、さらに強い制限付き最適値が確定した。

\[
\boxed{\max\{\,|S|:S\subset B_{10}\text{ が安全},\ |S\cap U|\ge10\,\}=19.}
\]

証明の残りは次の有限な層に縮約できる。安全な20点集合 \(S\) で
\(|S\cap U|\ge10\) と仮定すると、上の \(F_0\) の探索結果から
\(25\in S\)、\(|S\cap U|=10\) が必要である。
また安全性より \(Q\not\subset S\) でなければならない。
従って \(R=S\cap U\) の候補数は

\[
\binom{19}{9}-\binom{16}{6}=92378-8008=84370.
\]

この84370個の10点集合すべてについて、残りの10点を
\(B_{10}\setminus U\) から追加する探索を完走した。
拡張節点は50,552,292個で、解はない。
20点より大きい安全集合がこの条件を満たした場合も、共通点を10個残した
20点部分集合を取れば矛盾する。19点の達成例は4個の \(K_4\) 家族である。

従って20点安全集合が10盤に存在するとしても、\(U\) の20点のうち**11点以上を置き換える**
必要がある。違反が1個しかない20点集合であっても、小規模な修復ができるとは限らない。
これは \(K_{10}\le19\) の証明ではない。

## 再現方法と信頼境界

通常の整数幾何監査はPython標準ライブラリのみで実行できる。

```bash
python research/verification/scripts/saturation_20261003_extra_verify.py
```

明示集合の安全性、極大性、外周被覆、唯一の禁止4点組、探索ログの部分集合数を検証し、
`saturation_20261003_extra_verified.json` に全空点の証明書を書き出す。
安全性の検証は4次行列式の24項展開であり、探索器の補完マスクを再利用しない。

**通常モードで非存在探索を再実行するわけではない。** 局所非存在の根拠は
添付C++探索器の完全列挙である。3探索すべてを再実行し、節点数まで照合するには、
同じ検証器に次のオプションを付ける（`g++` が必要）。

```bash
python research/verification/scripts/saturation_20261003_extra_verify.py --rerun-exact
```

計測時の3探索は約198秒・244秒・29秒、合計約8分だった。実時間は環境による。
再実行時は時間制限を設けず、3件すべての完走と保存ログとの一致を要求する。
検索器の盤面は固定の10盤、点マスクは2ワードであり、64点超の切り捨てはない。
不存在探索の枝刈りは残り合法点数だけで、ヒューリスティックな上界は使用していない。

必要なソース・記録は以下の5ファイルと本ノートだけである。

- `saturation_20261003_extra_verify.py`
- `saturation_20261003_extra_verified.json`
- `saturation_20261003_extra_exact_results.json`
- `saturation_20261003_extra_nineteen_neighborhood.cpp`
- `saturation_20261003_extra_union_neighborhood.cpp`

11盤22石を狙った600秒の別ヒューリスティック探索は、最良でも禁止4点組3個を残し終了した。
この未発見を不存在の証拠には用いない。構成の確認にも局所非存在の再現にも不要な
試行用ヒューリスティック実装は、上の最小再現一式に含めない。
