# 奇数 q の鏡映戦略：偶数マス長方形は全長で後手勝ち

作成: 2026-10-03。再現:
[`verification/scripts/q48_odd_q_reflection.py`](verification/scripts/q48_odd_q_reflection.py)、
出力: [`verification/q48_odd_q_reflection.json`](verification/q48_odd_q_reflection.json)。

## 一般定理

D を平面上の有限点集合、ρ を一本の直線に関する鏡映とする。

1. ρ(D)=D。
2. D に鏡映の固定点、すなわち鏡映軸上の点がない。
3. q は奇数（本リポジトリの範囲では q≥5）。

このとき、q点共円・共線禁止ゲームの任意の安全な鏡映対称局面

\[
\rho(S)=S
\]

は P 局面であり、

\[
\boxed{g(S)=0}.
\]

特に空盤では、後手が先手の置いた点 p の鏡映点 ρ(p) へ毎回置く戦略で必勝となる。
**十分長いという条件も、整数格子という条件も不要である。**

## 証明

安全な鏡映対称局面 S で、相手が p に合法に置いたとする。
ρ(p) は p と異なり、まだ未使用である。これは固定点がなく、S が鏡映対称だからである。

ρ(p) への応手で初めて禁止円または直線 C が完成したと仮定する。
S∪{p} は安全で、最後に一石だけ増えたので、C 上の占有点数はちょうど q になる。
C は必ず ρ(p) を含む。二つの場合に分ける。

### C が p を含まない場合

C は S の石を q−1 個と、ρ(p) を含む。
S が鏡映対称なので、ρ(C) は S の石 q−1 個と p を含む。
従って最初の p 自体が禁止 q点を完成していたことになり、合法性に反する。

### C が p と ρ(p) の両方を含む場合

C は鏡映不変になる。

- 円なら、その中心は弦 pρ(p) の垂直二等分線である鏡映軸上にある。
- 直線なら、それは p と ρ(p) を結ぶ、鏡映軸に垂直な直線である。

従って S∩C の点は鏡映対ごとに現れ、その個数は偶数。
さらに二点 p,ρ(p) を加えた後の占有数も偶数である。
しかしそれがちょうど奇数 q になるという仮定に反する。

したがって応手は常に合法で、二手後は再び安全な鏡映対称局面になる。
盤は有限なので、相手が先に合法手を失う。任意の S が P 局面、従って g(S)=0 である。□

同じ証明は circle-only、line-only の両変種にも適用できる。

## 長方形盤への系

標準盤

\[
D(w,m)=\{0,\ldots,m-1\}\times\{0,\ldots,w-1\}
\]

で w,m の少なくとも一方が偶数なら、その方向の中央線は格子点を通らない鏡映軸になる。
従って

\[
\boxed{q\text{ が奇数、}wm\text{ が偶数}\quad\Longrightarrow\quad g(\varnothing)=0.}
\]

適用例:

- **四行・七点版は、m=1から全て後手勝ち**。
  全安全局面が石数だけで決まる開始点 M₄,₇=13 と、空盤の勝敗が全長で分かることは区別される。
- 三行・五点版の偶数 m の後手勝ちは、全局面計算や長さの閾値を使わずに証明できる。
- 任意の偶数 n の n×n 盤は、全ての奇数 q の版で後手勝ち。

これは十分条件であり、面積が奇数の盤の勝敗を主張しない。
また鏡映非対称な途中局面の Grundy 数までは、この定理だけでは決まらない。

## 条件は外せない

### q が偶数では鏡映応手が負け手になり得る

4×4 の円

\[
(x-3/2)^2+(y-3/2)^2=5/2
\]

上の8点から (1,0),(1,3) を除いた6石は、y=3/2 に関して鏡映対称である。
q=8 では、(1,0) に置く手は合法だが、鏡映先 (1,3) へ置くと8点円が完成してしまう。

### 中央反転は鏡映の代わりにならない

q=5 とし、原点に関する中央反転で対称な安全集合

\[
S=\{\pm(12,7),\ \pm(13,12),\ \pm(12,17)\}
\]

を考える。(5,0) に置く手は合法だが、その中央反転先 (−5,0) を置くと

\[
x^2+y^2-24y-25=0
\]

上に (12,7),(13,12),(12,17),(5,0),(−5,0) の5点が揃う。
この円は原点に関する中央反転では不変でない。

再現器は元の6石、最初の追加後7石、応手後8石について全候補円・直線を整数で検査し、
前二者が安全、最後だけ非安全であることを確認する。
従って「固定点のない対合なら何でもよい」という一般化は成り立たない。

## 有限検証

再現器は、長方形2×4、2×5、3×4、4×4、4×5で q=5,7,9 を確認し、
さらに格子長方形ではない12点の鏡映不変盤を追加する。

- 16ケース、鏡映対称な安全局面3,321個を全列挙。
- その全ての合法な初手に対する鏡映応手、計28,352件が合法であることを確認。
- 16点以下のケースでは通常の全安全局面 Grundy 探索も別に実行。
  合計177,951局面を評価し、鏡映対称な安全局面の値が全て0であることを確認。
- 偶数 q と中央反転の二反例も検査。
