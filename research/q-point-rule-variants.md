# q点版のルール変種：line-only / circle-only の全長強解決領域

標準 q 点版は「q 点共円 **または** q 点共線」を禁止する。
ここでは片方だけを禁止する二つの変種を考える。

候補点は w 本の異なる平行線上にあり、各線に m 点あるものとする。
等間隔格子であることは以下の証明には不要である。

## 1. line-only：q>w なら全 m を強解決

**定理**。q 点共線だけを禁止し、q>w とする。

平行線族の一本そのものではない直線は、各候補線と高々一度しか交わらない。
従ってそのような直線が含める候補点は高々 w<q 点であり、q 点共線を作れない。

よって禁止 q-set は、候補線の一本から q 点取ったものだけである。

したがって各行は互いに独立な容量 q−1 の箱になり、

[
C_{w,q}(m)=wmin(m,q-1)
]

と置けば、任意の安全局面 S で

[
oxed{g(S)=igl(C_{w,q}(m)-|S|igr)mod2}
]

が**全 m≥1**について成立する。

空盤の勝者は C_{w,q}(m) の奇偶だけで決まる。
m≥q−1 では

[
g(arnothing)=w(q-1)mod2,
]

従って先手勝ちは q が偶数かつ w が奇数の場合に限る。

満容量 (q−1)w への真の安定化長は

[
oxed{M^{mathrm{line}}_{w,q}=q-1qquad(q>w)}.
]

各線の候補点数が m_i と異なる場合も

[
C=sum_imin(m_i,q-1)
]

に置き換えるだけで同じ結論になる。

## 2. circle-only：q>2w なら禁止集合そのものが消える

**定理**。q 点共円だけを禁止し、q>2w とする。

一つの円は一本の直線と高々2点で交わるので、w 本の平行線上にある候補点のうち
一円上に載れるものは高々2w<q 点である。

従って q 点共円は一度も発生しない。全ての未使用点が常に合法であり、
盤が全て埋まるまでゲームが続く。

従って任意の局面 S で

[
oxed{g(S)=(wm-|S|)mod2}
]

が**全 m≥1**について成立し、空盤は

[
oxed{	ext{先手勝ち}iff wm	ext{ が奇数}}
]

である。

各線の候補点数が m_i と異なる場合は総候補点数
[
C=sum_i m_i
]
として g(S)=(C-|S|) mod 2 となる。

## 3. 標準版との比較

三つを並べると、高 q 領域の違いが明確になる。

| ルール | 単純化条件 | その条件下で残る禁止 |
|---|---|---|
| line-only | q>w | 同じ候補線上の q 点だけ |
| circle-only | q>2w | なし |
| 標準（circle + line） | q>2w | 同じ候補線上の q 点だけ |

標準版で閾値が q>2w になるのは、直線より円の方が一本の候補線と2点まで交われるためである。

line-only は q>w の時点で既に完全分離するので、標準版より広い領域が即座に強解決できる。
circle-only は q>2w では禁止条件自体が消えるため、標準版とは終局石数が異なる。
