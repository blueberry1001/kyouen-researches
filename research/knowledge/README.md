# Knowledge

`items/` は、研究知識を正規化して管理する正本です。

1ファイルは原則として1つの「主張・定義・未解決問題」を表します。
研究作業そのもの、実験の手順、長い時系列ログはここには置きません。

## 基本原則

- ID は内容や種類を表さない永久識別子とする
- 予想が証明されても、同じ命題なら同じ ID を使い続ける
- 命題の意味自体を修正した場合は新しい ID を作る
- 反証・撤回・置換された項目も削除しない
- 分類は物理ディレクトリではなく metadata で持つ
- 逆リンクは手書きしない
- 索引・依存グラフは metadata から生成する
- 実験・コード・結果・証明書は path で参照し、知識本文に複製しない

詳細は [SCHEMA.md](SCHEMA.md)、標準語彙は [VOCABULARY.yaml](VOCABULARY.yaml) を参照してください。

## ID

main に入った項目は `K0001` のような永久 ID を持ちます。
並行作業中に番号を確保できない場合は `KTMP-...` を使用できますが、
main へ統合する前に永久 ID へ変更し、同じブランチ内の参照も更新します。

## 生成ビュー

`generated/` は正本ではありません。`tools/knowledge/build.py` が
`items/` から再生成します。手編集しないでください。
