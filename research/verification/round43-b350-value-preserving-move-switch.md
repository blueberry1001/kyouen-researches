# B350: 値保存・勝ち手変更の最小合法点数5、最小盤4×4

作成: 2026-09-30。**B350原文SUPPORTED。**
高階制約をすべて削除しても真のgが同じだが、Pへ進む手集合が変わる標準残局を独立検算した。
原文の存在は既存round2に証拠があった。今回の新結果は、最小合法点数5と最小盤4×4の証明、
ならびに最小合法点数を達成する非退化な5×5証人である。
二つの最小量は別々で、5合法点の証人の最小盤が4だという意味ではない。

## 最小合法点数を達成する5×5証人

点IDはx+5y。

    S=[14,15,19,23,24]
    L=[0,2,6,12,17]
    R={{0,2},{12,17},{0,6,12},{2,6,17}}

二点競合は二つのK2と孤立点6。高階制約は三点辺二つで、四点辺なし。
完全版と高階全削除版のgはともに1である。

| 手 | 完全版の子g | 二点近似の子g |
|---|---:|---:|
| 0 | 2 | 0 |
| 2 | 2 | 0 |
| 6 | 0 | 0 |
| 12 | 2 | 0 |
| 17 | 2 | 0 |

完全版の勝ち手は{6}、近似の勝ち手は合法5点全部。
ゲーム値だけを検査して近似を採用すると、四つの手を誤って必勝と判定する。
二点競合が非空なので、節35の純孤立点の退化例には当たらない。

## 全盤での合法点数の下界

合法点数mの標準残余族はサイズ2・3・4の集合の包含極小族である。
m≤4のそうした全族を、二点辺を持たない族も含めて完全列挙した。

| 合法点数m | 全極小族 | 値保存・勝ち手変更の族数 |
|---|---:|---:|
| 1 | 1 | 0 |
| 2 | 2 | 0 |
| 3 | 9 | 0 |
| 4 | 114 | 0 |
| 5 | 6,893 | 1,100 |

0合法点では手がないので変更もない。
従ってどの盤にも4合法点以下のB350証人はなく、上の5合法点証人で下界を達成する。
5点の1,100族のうち二点辺がある非退化な族は330。
この抽象族数をそのまま格子実現数や同型類数とは扱わない。

列挙器は二点族、許容三点族、許容四点族の順に生成する。
下界に必要なm≤4については、全候補辺の全部分族から包含関係を直接検査する別列挙とも
全族の集合が一致した。mex・勝ち手もメモ再帰と逆順全部分集合DPで照合した。
これは有限盤への外挿ではなく、全盤に共通する最小残余サイズの下界である。

## 最小盤は4×4

旧round2の4×4証人S=[0,1,3,5]を正しい盤点IDで再検算した。

    L=[8,9,10,11,12,13,14,15]
    g_full=g_pair_only=3
    winning_full=[9,10]
    winning_pair_only=[9,10,12,14]

二点辺18本、三点辺{11,12,14}一つ、四点辺なし。
旧JSONの勝ち手[1,2]等はL上の圧縮IDで、実盤IDは上記となる。
1×1〜3×3の全2・15・298安全局面について、完全版と二点版を直接比較し、B350の該当0。
よって原文を実現する盤サイズの最小値は4。
