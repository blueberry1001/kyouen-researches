## B142 [漸近・大胆] 非共線共円四点組はn^(4+o(1))

原文の要約: `C_n = n^{4+o(1)}`。円の格子算術による約数的増加が、独立な自由度の一つより小さい可能性。

- 判定: **REFUTED**（前回: REFUTED → 今回: REFUTED 確認・強化）
- 今回の範囲: C_n を n=2..14 で三手法により完全計算。C_n/n^5、C_n/(n^5 log n)、C_n/n^6 の挙動を比較。局所次数と log-log フィットを測定。
- 証拠:
  - **C_n/n^5 は n=4..14 で単調増加**（0.180 → 0.636）。C_n は n^5 より速く成長する。n^{4+o(1)} には絶対に収まらない。
  - **C_n/(n^5 log n) も単調増加**（0.130 → 0.241）。n^5 log n にも収まらない。
  - **C_n/n^6 は n=5..14 で 0.045–0.050 に安定**。n^6 が最有力の主項次数。
  - **局所次数** log(C_n/C_{n-1})/log(n/(n-1)) は n=6..14 で 5.65–6.19、平均 ≈ 5.9。
  - **log-log フィット** n=6..12 で次数 ≈ 5.97。
  - 三手法一致（下記）。`round5_b142_data.json`。

- 三手法一致:

- 次数の評価:
  - **n^{4+o(1)}**: 不成立（C/n^4 は n=4 で 2.88 と既に発散傾向、n=14 で 44.5）
  - **Θ(n^5)**: 不成立（C/n^5 が 0.18→0.64 と単調増加、有限極限なし）
  - **Θ(n^5 log n)**: 不成立（C/(n^5 log n) も 0.13→0.24 と単調増加）
  - **Θ(n^6)**: 最有力（C/n^6 ≈ 0.048 で安定、局所次数 ≈ 5.9、log-log フィット ≈ 5.97）
  - ただし n≤14 の有限データでは漸近次数を証明できない。`Θ(n^6)` と `Θ(n^6 / log^c n)` や `Θ(n^{6-ε})` の区別は不可能。

- 円束縛法の内訳（n=10 の例）: 12,170 個の円（≥4 点）が 48,513 の 4 点組を生む。
  大半は 4 点円（10,868 個、各 C(4,4)=1）だが、8 点円 261 個（各 C(8,4)=70）が寄与の 38% を占める。
  円の「大円テール」が n^6 主項を押し上げている可能性。

- 残った障害: 漸近次数の証明には、円上の格子点数の分布（二平方和問題 r_2(m) の重み付き和）に関する理論が必要。有限データでは「Θ(n^6) に見える」以上のことは言えない。

## B141 文書訂正指示

HANDOVER §2 の証明（`round4-collinear-asymptotic.md`）により、B141 は SUPPORTED に訂正済み。

### 訂正 1: `batch-08.md` の B141

**現状**（47–49 行付近）:
```
## B141 [漸近] 共線四点組の主項はn^5
- 判定: **REFUTED**
- 範囲: D_n を n=2..40 まで閉形式で完全計算。D/n^5、D/(n^5 log n)、D/n^6 を比較。
- 証拠: D_n/(n^5 ln n) = 0.0323 で n=28..40 に安定。D_n/n^5 は 0.053 (n=9) → 0.119 (n=40) で対数的に上昇し続け、有限極限を持たない。真の主項は **D_n = Θ(n^5 log n)**（係数 ≈ 0.0323）。
```

**訂正後**:
```
## B141 [漸近] 共線四点組の主項はn^5
- 判定: **SUPPORTED**（訂正: 第1回 REFUTED は誤読。round4-collinear-asymptotic.md で証明）
- 範囲: D_n を n=2..40 まで閉形式で完全計算 + 方向別の恒等式による証明。
- 証拠: D_n = 7ζ(2)/(60ζ(3)) n^5 − 3/(4ζ(2)) n^4 log n + O(n^4)。主項定数 7ζ(2)/(60ζ(3)) ≈ 0.15965。D_n/(n^5 ln n) が n=28..40 で 0.0323 に見えるのは、n^4 次の補正項の log が主項に見えたため。対数は主項ではなく次項にある。
- メモ: 三手法一致（外積全走査 / 有限和 / 最大線分 C(ℓ,4) 和）で n=4..11 の D_n が完全一致。詳細は round4-collinear-asymptotic.md と ROUND4-B141-VERIFICATION.md。
```

### 訂正 3: `round2-batch-b471.md` の B473

**現状**の問題点:
- `c_hat = 平均_{n≥28} D_n/(n^5 ln n) = 0.032268 で主項を引き` — **n^5 log n を主項とする前提が誤り**
