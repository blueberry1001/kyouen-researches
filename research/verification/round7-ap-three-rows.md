# B558候補: 三行横断の共円四点を一般に排除

作成: 2026-09-28。B558は引き続き **PARTIAL**。
前回: [放物線候補と行間隔39までの検証](round6-ap-parabola.md)。

後続の更新: [素数を公差とする別構成](round8-ap-quadratic-prime.md)でB558は **SUPPORTED** になった。
以下の公差1候補についての部分証明と有限範囲は引き続き有効だが、全w安全性は未証明。

候補は、w行の各行r=0,…,w−1へ

\[
 (2(r+w)^2-2w^2+j,r),\qquad j=0,1,2
\]

を置くもの。幅は6w²−8w+5。
今回、**三行にまたがる共円四点の不存在を全wに対して証明**した。
有限の厳密検証もw≤201まで進めた。全w安全性はまだ証明していない。

## 1. 一般補題

整数a≥2、w≥1について

\[
 P_a(t,j)=(at^2+j,t),\qquad w\le t\le2w-1,\quad j=0,1,2
\]

を考える。この集合から相異なる三行に選んだ四点は共円でない。

### 円の中心の横座標を固定する

三行四点では一行rに二点がある。その二点のラベルをu<vとし、

\[
 m=(u+v)/2,\qquad K=(v-u)^2/4
\]

と置く。円の中心の横座標はa r²+mに固定される。
他の行y≠rの点P_a(y,j)と同じ円に載るために必要な中心の縦座標は

\[
 C_j(y)=\frac{y+r}{2}
 +\frac{a^2}{2}(y-r)(y+r)^2
 +a(j-m)(y+r)
 +\frac{(j-u)(j-v)}{2(y-r)}. \tag{1}
\]

これは二点から中心までの距離の二乗を等置し、y−rで割った式である。
三行にまたがる共円があるなら、相異なるy<z（双方rとは異なる）とラベルj_y,j_zで
C_{j_y}(y)=C_{j_z}(z)となる必要がある。

### 行が上がると、可能な中心の縦座標区間が離れる

G(y)=(y−r)(y+r)²とすると

\[
 G'(y)=(y+r)(3y-r)\ge2w(w+1)
 \quad(w\le y,r\le2w-1).
\]

また|j−m|≤3/2、|j_z−j_y|≤2。
(j−u)(j−v)は−1,0,2のいずれかであり、整数y≠rに対し式(1)の最後の項の絶対値は高々1。
D=z−y≥1として、式(1)の各項を評価すれば

\[
 2\{C_{j_z}(z)-C_{j_y}(y)\}
 \ge D\{2a^2w(w+1)+1-3a\}-4a(y+r)-4.
\]

w≥3なら中括弧は正。y+r≤4w−2を使って

\[
 2\{C_{j_z}(z)-C_{j_y}(y)\}
 \ge2a^2w(w+1)-16aw+5a-3
 \ge8w^2-24w+7>0. \tag{2}
\]

二番目の不等式では、a≥2において右辺がaとともに増加することを使った。
w=1,2では相異なる三行を選ぶこと自体ができない。
従って全wについて二つの中心縦座標は一致せず、共円は不可能。□

## 2. 未解決部分が四行に限定された

前回の一般証明と合わせて排除済みなのは次のケース。

- 全ての共線四点。
- 同一行に三点を含む共円、二行に二点ずつの共円。
- 今回の三行横断共円。
- jが全共通、または三点共通で一点だけ異なる共円。

従って候補の全w安全性を決める残件は、**四つの相異なる行**で、jの多重度が
**2+2または2+1+1**となる場合だけである。
共通整数シフトhに関する二次式は前回個票の式(4)を引き続き使える。

## 3. 独立整数実装による有限範囲の拡張

[C++実装](scripts/round7_ap_parabola.cpp)、[再現ドライバ](scripts/round7_ap_parabola_driver.py)。
既に導入済みのWSL g++を使い、新たなコンパイラ・ライブラリは導入しない。

```text
python research/verification/scripts/round7_ap_parabola_driver.py --span 39 --coefficient 2
python research/verification/scripts/round7_ap_parabola_driver.py --span 128 --coefficient 2
python research/verification/scripts/round7_ap_parabola_driver.py --span 200 --coefficient 2
```

| 最大行間隔 | 全パターン数 | 非負整数シフトの禁止根 |
|---:|---:|---:|
| 39 | 645,710 | 0 |
| 128 | 22,752,064 | 0 |
| 200 | 86,746,900 | 0 |

行間隔39では、パターン総数、行数別内訳、多項式次数別内訳、負整数根数3,025が
前回のPython任意精度実装と一致した。
行間隔200では負整数根は348,390個あったが、非負整数根はなかった。
有限のシフト走査ではなく、各二次式の整数根を全て解いている。
従って候補の安全性はw≤201について確定し、任意wでも行間隔200以下の四点組は安全。

証明書:
[span39](round7_ap_parabola_a2_span39.json)、
[span128](round7_ap_parabola_a2_span128.json)、
[span200](round7_ap_parabola_a2_span200.json)。

### 整数計算の範囲

実装は符号付き128ビット整数を使う。受理するパラメータは
(a=2, ℓ≤500)または(2≤a≤8, ℓ≤200)に制限している。
U=aℓ²+2とすると、二次式Ah²+Bh+Cの係数は

\[
 |A|\le48a^2\ell^3,\quad |B|\le24aU^2\ell^2,\quad
 |C|\le6U\ell(U^2+\ell^2).
\]

この上界から、受理範囲では|B²−4AC|<10³⁸<2¹²⁷−1であり、途中の行列式も範囲内。
平方根の初期値だけ浮動小数で求め、その後整数の積で上下を補正して厳密な整数平方根にする。
根の確認では大きなhの二乗を作らず、h≠0ならC mod h=0とAh+B+C/h=0を確認する。

式(2)の補助照合としてw=3,…,8、a=2,3,5の30,618条件を有理数で直接評価し、
二倍した中心縦座標差が全て証明中の正下界以上となることも確認した。
一般補題の根拠は第1節の不等式であり、この有限照合ではない。

## 4. 継続課題

四行に限った二つのj多重度について、二次式にh≥行間隔+1の整数根が存在しないことを
一般に示すか、具体的な反例を構成する。201行までの支持だけでB558をSUPPORTEDへ変えない。
今回の保存済み計算はすべて正常終了している。
