## 1. 最小幅の確定

五行・幅12の証人は次の通り。行番号は0〜4。

```
0: 0, 1, 2
1: 1, 5, 7
2: 6,10,11
3: 0, 4,10
4: 0, 9,11
```

この15点の全1,365四点組をPythonの整数行列式で検査し、禁止組がないことを確認した。
一方、幅11では各行三石の安全配置が存在しないことを、以下の二つの全探索で確認した。
幅が11未満の盤は幅11盤の部分盤なので、別途一つずつ調べる必要はない。
従って `m_*(5)=12`。各行四石は共線禁止に反するため、15石の存在と各行三石は同値である。

全w≥2で `m_*(w)=2w+1` とするB557は、w=5で反証された。
前回監査した旧証人は幅10の誤った肯定だったが、今回の反証は逆に**幅11でも不足する**という結論。
旧コードの見落としを修正したと仮定して旧出力を再解釈したものではなく、新しい二方式を独立に実行した。

## 2. 各行を等差数列に限定した最小幅

五行・幅14には次の証人がある。

```
0: 0, 1, 2
1: 0, 6,12
2: 2, 5, 8
3: 9,11,13
4: 3, 8,13
```

各行の公差はそれぞれ1,6,3,2,5。全1,365四点組の独立検査で安全。
幅13のAP配置は二方式とも全探索で不存在。従ってこの条件での最小幅は14。
これはB558の有限の進展であり、全wの二次上界の証明ではない。
公差1の全w構成については [前回の三次上界](round4-ap-construction.md) を参照。

## 3. 二つの全探索が尽くすもの

### 方式A: 行ごとの三点組

各行の全 `C(m,3)` 三点組（AP限定時は等差三点組だけ）を辞書順に選ぶ。
同一行の三点の二点和は三つあり、異なる二行の二点和が等しいと共円四点になる。
従って既に使われた二点和と交わる候補を除く。この除外条件は必要条件なので安全な配置を落とさない。

その後、新行を加えて新たにできる四点組を全て検査する。

- 旧三点＋新一点: 旧三点が同じ旧行の場合を除き全て検査。
- 旧二点＋新二点: 旧二点が異なる行なら全て検査。同じ旧行なら二点和条件で既に検査済み。
- 旧一点＋新三点: 新三点は新行で共線、旧点は新行外なので禁止組にならない。

四点の一つを原点へ平行移動した3×3行列式を64ビット整数で計算する。
実行した小盤の座標範囲では積・和は64ビットの範囲内に十分収まる。
旧コードのように二行だけの合併を調べる方式ではなく、旧三点・旧二点は全ての既存行から取る。

### 方式B: 全禁止四点集合から一石ずつ配置

Python側で盤の**全四点組**を独立に列挙し、4×4行列式の直接展開で禁止集合を生成する。
そのマスク一覧をテキスト保存し、別のC++探索が一石ずつ行内昇順に配置する。
この探索には円の方程式や二点和条件を実装せず、禁止集合が全部含まれたかだけを検査する。
65点を扱う場合もあるため、マスクは128ビット整数を使う。

選択を行番号と行内昇順で進めるので、四点組はその最大番号の点を追加した時点で必ず検査される。
AP限定では三点目が最初の二点の等差延長となる条件を加えるだけである。
探索の停止上限は一度も到達しておらず、全結果が `complete=true`。

## 4. 独立照合の数値

| 盤と条件 | 結果 | 禁止四点集合数 | 方式Aの安全な行プレフィックス | 方式Bの同プレフィックス |
|---|---|---:|---:|---:|
| 5×11、任意三点 | 不存在 | 8,455 | 218,022 | 218,022 |
| 5×12、任意三点 | 存在 | 10,981 | 3,502 | 3,502 |
| 5×13、AP限定 | 不存在 | 13,968 | 9,229 | 9,229 |

存在時は最初の証人で停止するため、その行プレフィックス数は全配置数ではない。
不存在時は全候補を尽くしている。二方式は判定だけでなく到達した完全行プレフィックス数まで一致した。
方式Bの部分行も含めた探索ノード数は順に1,422,974、19,757、121,290。
幅12の最初の証人も二方式で一致。

基礎確認として、方式Aでw=2,3,4の一般三点の最小幅5,7,9も再現。
w=4のAP最小幅10も再現した。全ての肯定証人はPythonで全四点組を再検査した。
JSONにはソースSHA-256と禁止集合ファイルのSHA-256を保存している。

## 5. 付随する一般下界

各行三石の安全配置では、各行の三つの二点和は相異なり、異なる行の二点和も共有できない。
盤の列番号を0,…,m−1とすると、異なる二点の和は1,…,2m−3に限られる。
従って

\[
 3w\le2m-3,\qquad m\ge\left\lceil\frac{3w+3}{2}\right\rceil.
\]

さらにw≡3 (mod 4)では等号の幅 `m=(3w+3)/2` も不可能。
等号なら二点和全体が1,…,3wを一度ずつ使うが、その総和 `3w(3w+1)/2` は奇数。
一方、各行の二点和の総和は石の横座標和の二倍なので、全体も偶数となり矛盾する。
この場合は `m≥(3w+5)/2`。

この一般下界だけで五行の最小幅12を示せるわけではない。五行の結論には3〜4節の完全計算を使う。
