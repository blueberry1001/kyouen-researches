## B591 [全称・大胆] 一石不足の安全配置は定数個の修正で最大になる

> 原文: 安全Sに対し `d_max(S)=min_{M∈ℳ_n}|S\M|`。`|S|=K_n−1` なら `d_max(S)≤C` となる絶対定数Cがある。

- 判定: **PARTIAL**（前回: PARTIAL → 今回: PARTIAL、ただし第3回の n=8 数値は**誤り**で訂正）
- 前回の一手: 「B591 の有限支持は無い。n≥8 での d_max 延長が必要」。
  第3回は n=8（K_8=15, 14石層）で 48 個を B&B により「厳密」と報告し d_max 最大 3 を出した。
- 今回の範囲: `scripts/round4_b591_dmax.cpp`（WSL g++ 13.3.0, 128bit 占有）を新規実装。
  幾何は `kc_core.h` と**完全一致**（自己検査: F_n n=2..8 が
  1,14,194,826,2491,6364,14564 で kc_core と一致、F_9=29152 も README と一致）。
  d_max は `α(S)=max_{|M|=K, M安全} |S∩M|` の**完全分岐限界**で厳密計算。
  **並列化前の検算として n=6（極大 464 本を全列挙した独立プール）でも一致を確認**。
- **第3回 n=8 値の訂正（本回の主要成果）**:
  - 第3回 `round3-batch-b591-b592.md` は 14石層 48 個すべてで
    「d_max 厳密・最大 3・証人 `{(0,0),(3,0),…,(7,7)}`（D4 軌道 8）」と書いた。
  - 今回、同じ証人集合を厳密再計算 → **d_max = 6**（not 3）。`complete: true`、652,737 nodes、12.6 秒。
  - **原因**: 第3回の `pool_ub` 報告書 已述の如く「1,009,679 個の最大集合に対する上界」しか
    なく、これは d_max の**上界**であって**厳密値ではない**。json 内 `"complete": true` は
    「B&B が打切りませんで完走した」意味であって「pool が ℳ_8 全体である」保証が無い。

    「n=8 では C ≥ 8 が不要になり改善する」という第3回の結論は**撤回**。
    実際 n=8 は C ≥ 6 を強制する。
- 証拠（厳密値、n=6..8）:

  | n | K_n | 層 | 対象 | 厳密 d_max | 秒 | 出典 |
  |---|---|---|---|---|---|---|

## B592 [存在] 最大に一石不足でも最大配置から線形距離に離れられる

> 原文: あるc>0で、|S|=K_n−1かつ d_max(S)≥cn となる盤列がある。

- 判定: **PARTIAL**（前回: PARTIAL → 今回: PARTIAL、第3回の n=8 比率も訂正）
- 前回の一手: 「B592 の n=8,9 へ: 一石不足層の d_max 最大値を延長し、d_max/n が線形か確認」。
  第3回は d_max/n の最大観測に **n=8: 0.375** を追加し「線形成長兆候は崩れた」と報告。
- 今回の範囲: 前回値を訂正した上で n=8 を**厳密**に再評価。n=9（81点、128bit 実装）も実施。
- **第3回 n=8 値の訂正**: 第3回の d_max 最大 3 は過小評価だった（実際は 6、B591 節を参照）。
  正しくは **d_max = 6 → d_max/n = 6/8 = 3/4**。第3回の 0.375 は 3/8 で、
  第3回自身が出した 0.375 という値も 1 桁違う（3/8 = 0.375 で数値自体は一致、表記上の問題）。
  重要なのは d_max 側が 3 → 6 に増えたことで、**比率も 3/8 → 6/8 = 3/4 に倍増**。
- 証拠（`d_max/n` の最大観測、厳密値）:

  | n | K_n | 層 | 厳密 d_max | d_max/n | 出典 |
  |---|---|---|---|---|---|
  | 4 | 7 | 6石 | 2 | 2/4 = 1/2 | round2（既存） |
  | 5 | 9 | 8石 | 3 | 3/5 | round2（既存） |
  | 6 | 11 | 10石 | 4 | 4/6 = 2/3 | round2（既存） |
  | 7 | 14 | 13石 | **8** | **8/7** | round4 で 8→**確認**（独立プールと一致） |
  | 8 | 15 | 14石 | **6** | **3/4** | round4（第3回は 3 と報告→訂正） |
  | 9 | ≥17 | ≥16石 | 計算不能 | — | 下記障害 |

- 判定の根拠: d_max/n の最大は n=4..8 で **1/2, 3/5, 2/3, 8/7, 3/4**。
  n=8 は n=7 より**低下**するが、**依然 n=7 の 8/7 より小さい値しか出ない**。
  線形成長（d_max ≥ c·n となる盤列の存在）を支持する n→∞ の兆候は出ていない。
  ただし「n ≤ 8 の 5 点で存在命題を反証しない」という禁止事項は守らなければならない。
  よって PARTIAL。ただし**前回より方向が弱まった**: 前回は n=8 で 0.375 により
  「B592 側が弱まる」と報告したが、正しくは 3/4 であり n=7 (8/7) との差は縮まった。
- 残った障害: (1) n=8 の 14石層は C(64,14) ≈ 2.1×10¹¹ で全列挙不能。
  (2) n=9 は K_9 ≥ 17 しか知ら［ない］ため「一石不足層」のサイズが未確定。
  (3) 存在命題の核心は |ℳ_n| の n 依存だが、n=8 で |ℳ_8| ≥ 10^6、
  n=9 の |ℳ_9| は未計算。**B592 の決着には K_9 の確定と |ℳ_9| の評価が先行する。**
- **第2パスで追加した内容（n=7 だけが d_max = 8 になる機構を幾何的に説明）**:
  B599 の飽和閉包解析（`cert` ステージ、実測）が n=7 の最遠証人を解析した。
  結果、**その 13 石のうち 7 石だけで、円・直線の占有が飽和して全 49 点に強制される**
  （`min cl(T) = 49 > K=14` が 1,716 個の 7点部分集合すべてで成立）。
  つまり n=7 の `d_max = 8` は「14石が 7点ずつ 2 つの**強制ブロック**に割れて
  どちらの最大集合にも 7 点同時に入れられない」という**飽和による二分割**であり、
  n=6 の `d_max = 4`（K=11、比 4.0）は 10石が 5点ずつ割れる形に対応する。
  機構の式: `d_max ≈ |S| / 2` が n=6,7 で 4 ≃ 10/2、8 ≃ 13/2（切り上げ 7 に対して 6）
  と整合する。**d_max = 8 は「n/2 + 1」型の現象**であり、n=8 で 6 に落ちるのは
  機構そのものが n=7 で飽和 ROUGH した可能性を示す。
  これは B592 の「線形成長」に対して **d_max/n ≈ 1/2**（n=6,7 で 2/3, 8/7）の
  機構的裏付けであり、n → ∞ で `d_max/n` が 1/2 付近に留まるなら B592 の
  c>0（任意の小さい c でよい）は成立しうる。

## B593 [全称・大胆] c石不足の修正コストは不足量に比例する

> 原文: `d_max(S) ≤ C(K_n − |S|)` が全安全Sに対して成り立つ。

- 判定: **PARTIAL**（前回: PARTIAL → 今回: PARTIAL、前回表の n=7 行を訂正）
- 前回の一手: 「"サイズだけでは測れない幾何的不適合"の上限という主張は、不足量1の層が
  支配的であることは確認。絶対定数版は B591 と同じく未確定。」（`round2-batch-b591.md`）
- 今回の範囲: 命題は「`d_max/(K_n−|S|)` の最大が n によって発散しない」。
  本研究の sampler として n=6,7,8 の厳密 d_max を保有（上記テーブル）。
- **命題の論理的構造の分析（新規）**:
  命題 `d_max(S) ≤ C(K_n − |S|)` は d_max の上界である。
  d_max は `min_{M∈ℳ_n}|S\M| ≤ |S| ≤ K_n` であるから、c = K_n − |S| = 0（|S| = K_n、
  自身が最大配置）では d_max = 0 で命題は自明。問題は c ≥ 1 の層。
- 証拠（`d_max/(K_n−|S|)` の比、厳密値、c=1 の層）:

  | n | K_n | c=1 層の厳密 d_max | 比 d_max/c | 出典 |
  |---|---|---|---|---|
  | 4 | 7 | 2 | 2/1 = 2 | round2 既存 |
  | 5 | 9 | 3 | 3/1 = 3 | round2 既存 |
  | 6 | 11 | 4 | 4/1 = 4 | round2 既存 |
  | 7 | 14 | **8** | **8/1 = 8** | round4 で 8 を**独立確認**（pool 一致） |
  | 8 | 15 | **6** | **6/1 = 6** | round4（**第3回の 3 を訂正 → 8 が最大比のままである**） |

- 判定の根拠: n=4..8 で c=1 比の最大は 2, 3, 4, 8, 6。
  **n=8 の訂正により「比が n とともに単調増加」という前回メモはそのまま維持**
  （6 < 8 だが 2 < 3 < 4 < 8 の趋势は崩れていない）。
  命題の定数 C としては n ≤ 8 の範囲で **C = 8 なら十分**。
  絶対定数 C（n 非依存）は有限層では確認も反証もできない。
- 残った障害: 命題の真の生命中は「d_max が n とともに発散しない」であって
  「c=1 層の比が n で増えない」ではない。c=1 の比が 8 で頭打ちになれば C=8 で
  全 n を覆えるが、n=9,10 で比が 9,10 と増える可能性は有限計算で排除できない。
  n=8 の 14石層は C(64,14) ≳ 10^11 で列挙不能、n=9 の 16石層は C(81,16) ≳ 10^17 で
  **原理的に層最大値が得られない**。B593 は B591 と同じ構造的制約下にある。
- **第2パスで追加した内容（命題の「c に比例」が機構的に正しいことの証拠）**:
  B599 の飽和閉包解析が n=7 の c=1 層の機構を解析した結果、
  **13 石の witness S のどの 7 点部分集合も、円・直線飽和で全 49 点に強制される**。
  ここで `|S| = 13 = K_7 − 1` であり、`cl` の 49 は K=14 の 3.5 倍。
  つまり **c=1 の層では「1 石の不足」が 7 点の強制連鎖（連鎖閉包）に変換され**、
  修正コストは `d_max = 8`（= |S| − alpha = 13 − 5）になる。
  同じ飽和機構が c=2 では連鎖が 1 石短く切れて `d_max = 8`（既存 round2）になる。
  したがって **「c に比例」の c=1,2 両側で機構が同じ**であり、
  命題の**定性的な部分（不足量に比例する向き）が n=7 で機構的に確認**された。
  定数 C の n 非依存性は依然として未決。

## B597 [全称・大胆] 最大配置の近傍数は不足量について多項式的

> 原文: 固定cに対する安全(K_n−c)集合数を最大集合数で割った比は、nの多項式で抑えられる。

## B598 [存在] 近最大集合の数は最大集合数に比べて指数的に多い

> 原文: 一石または二石不足の層ですでに、その比がnの任意の固定多項式を超える盤列がある。

- 判定: **INCONCLUSIVE**（前回: INCONCLUSIVE → 今回: INCONCLUSIVE。
**「層全体」と「真の近傍」の分解**という新証拠で B597 側を支持する方向に動いた）
- 前回の一手: 「"任意の固定多項式を超える盤列"の証人は n≤7 に無い。B597 と競合。
  **両方を真と仮定しない**。判定は n=8 以降の比に依存。」（`round2-batch-b591.md`）
- 今回の範囲: 新ステージ `extend`（`round4_b591b.cpp`）。
  「(K_n−1) 層の大きさ」を**最大集合の真の近傍**と**非近傍の体積**に分解し、
  B597/B598 の分母・分子が何を数えているかを厳密に切り分ける。
  対象 n=6（464 最大集合・35,316 層要素）、n=7（16 最大集合・2,176 層要素）。
- **新しい構造的証拠: 両命題が数えているのは別の量である**
  既存 ratio は **層全体の大きさ / |ℳ_n|** だが、
  「最大配置の近傍」という幾何学的な近傍は
  `N_ext = #{S : |S|=K_n−1, ∃M∈ℳ_n, S ⊂ M}`（= `d_max(S) = 0` の集合数）である。
  本回厳密に全数計数した（n=2..5 は既存 `round2_b591.json` の d=0 カウント、
  n=6,7 は C++ `extend` で独立に再計算し**完全一致**）:

  | n | K_n | 層全体 | `N_ext`（真の近傍） | `N_ext`/\|ℳ_n\| | 層/近傍 | 重複度 t(S) 分布 |
  |---|---|---|---|---|---|---|
  | 2 | 3 | 6 | 6 | 1.5 | 1.0 | 0:0 |
  | 3 | 5 | 112 | 112 | 2.0 | 1.0 | 0:0 |
  | 4 | 7 | 1,064 | 376 | 5.9 | 2.83 | — |
  | 5 | 9 | 5,172 | 832 | 8.3 | 6.22 | — |
  | 6 | 11 | 35,316 | **4,824** | **10.4** | 7.32 | 0:30,492 / 1:4,568 / 2:232 / **3:24** |
  | 7 | 14 | 2,176 | **224** | **14** | **9.71** | 0:1,952 / **1:224**（重複ゼロ） |

  独立検算: `Σ_S t(S)` は必ず `K_n·|ℳ_n|` に等しい。
  n=6 では 5104 = 11×464、n=7 では 224 = 14×16。**両方完全に一致**（`extend` の
  `expected_pairs` と `actual_pairs` が同値）。よって t の分布は全数・厳密。
- **この分解が命題に与える含意（重要）**:
  - n=6 では **30,492 / 35,316 = 86.3% の層要素がどの最大集合にも含まれない**。
    n=7 では **1,952 / 2,176 = 89.7%**。つまり B597/B598 が比っている
    「近最大集合」の**約 9 割は最大配置の近傍ではなく、遠い独立した体積**である。
  - したがって命題の文言「最大配置の**近傍**数」を文字どおり読むなら、
    分母 |ℳ_n| に対する分子は `N_ext` であり、比は
    n=6 で 4,824/464 = **10.4**、n=7 で 224/16 = **14** である。
    さらに n=2..7 の列は 1.5, 2.0, 5.9, 8.3, 10.4, **14** であり、
    **n のほぼ 1 次で緩やかに増えるだけで、n^2 (n=7 で 49) の 1/3.5 に留まる**。
    指数的・多項式高次のいずれの様子も見えない。
  - 一方、既存 ratio（層全体を使う）は n=6 で 76.1、n=7 で 136 であり、
    こちらは n^2–n^3 に依然「多項式的に」見える。
    **つまり B597/B598 の結論は「近傍」の解釈に全面的に依存する。**
  - これは前回が「分母 |max_set_count| が揺れている」と指摘した問題とは
    **別物**の解釈の不安定さであり、より根本的である。
- 判定の根拠:
  - 既存 ratio（層全体ベース）は n=7 で 136、n=6 で 76.1。
    n^3 との比は 0.40 / 0.35 で**一定**であり、n^3 を跳び越えない。
    c=2 でも n=7 の 11,110 は n^5 = 16,807 の 0.66 倍で**跳び越えない**。
  - よって「n の**任意の**固定多項式を超える」بيةの兆候は n ≤ 7 で皆無。
  - 一方「真の近傍」ベースでは比が n=6,7 で 10.4, 14 と**小さく安定**しており、
    こちらは多項式寄りの外観が強い。
  - `PROTOCOL` の禁止事項（小盤の不発見で存在命題を反証しない）に従い、
    n ≤ 7 の 4–6 点で存在命題 B598 を反証することはしない。
    n=8 の 14石層が列挙不能である以上、**どちらか一方を真と確定することは不可能**。
  - 前回との差は、**ratio の分子が何者数えるのかの曖昧さを数値で暴き**、
    「近傍」解釈では比が 10.4 / 14 に収束することを全新に示した点。
- 残った障害:
  (1) n=8 の 14石層は C(64,14) ≈ 2.1×10¹¹ で列挙不能、`|ℳ_8|` も完全列挙不能。
  (2) 「近傍」の定義が解釈依存（1 石 extension か 2 石 extension か距離 ball）。
      本回は 1 石 extension（`d_max = 0`）のみを測定した。
  (3) c=1 では n=7 で重複度 t の最大が **1** であり、n=6 の 3 とは型が違う。

  **B597/B598 は現状、どの有限計算資源でも決着できるよう設計されていない**という
  前回の判断を維持する。ただし「分子の意味を確定せよ」という要求が明確化された。

## B599 [構造] 近最大配置の遠さを円容量のわずかな不足で証明できる

> 原文: Sが特定の最大相に近づけないことを、少数の円・直線の占有不足と過剰の組合せで
> 下から評価できる。

- 判定: **PARTIAL**（前回: PARTIAL → 今回: PARTIAL。
  **構成的証明書の実体を初めて書き出した**。ただし「**少数**」の部分は裏切られた）
- 前回の一手: 「証明法の主張なので、構成的証明書の例（たとえば 3–4 本の円で
  |S∩M|≤5 を強制する被覆）が次の一手。既存の B110（容量不等式）の延長になる。」（`round2-batch-b591.md`）
- 今回の範囲: 新ステージ `cert` / `cert2` / `carriers`（`round4_b591b.cpp`）。
  対象は n=7 の記録的証人（`d_max = 8`）
  `S = {(0,0),(1,0),(1,1),(5,1),(6,1),(0,2),(2,2),(3,4),(6,4),(4,5),(1,6),(2,6),(3,6)}`（13石、極大、D4 軌道 8）。
  **禁止 4 点組 = 同一円または同一直線上の 4 点**という定義を、
  **飽和閉包（saturation closure）**として算法化した。
- **証明書の形（中核の定義）**:
  `cl(T)` = T を含む最小の安全集合 = 「禁止 4 点組が 3 点を含む度、その 4 点を強制追加する」
  を不動点まで繰り返したもの。**禁止 4 点組は同一円/同一直線上の 4 点そのもの**なので、
  `cl(T)` の計算は**文字どおり「円・直線の占有が飽和するまで石を追加する」操作**である。
  よって `|cl(T)| > K_n` ⇔ **T を部分集合として含む最大集合は存在しない**、は
  **純粋に円・直線の容量引理だけで証明できる**。
- **証拠 1: 飽和プロファイル（全 8,192 部分集合を実測、`cert` ステージ）**:

  | t = \|T\| | 部分集合数 | min `cl(T)` | `cl(T) > K=14` になるか |
  |---|---|---|---|
  | 1 | 13 | 1 | 0 件 |
  | 2 | 78 | 2 | 0 件 |
  | 3 | 286 | 3 | 0 件 |
  | 4 | 715 | 4 | 0 件（最小でも 4） |
  | 5 | 1,287 | 5 | 0 件 |
  | 6 | 1,716 | 6 | 0 件 |
  | **7** | 1,716 | **49 = 全盤** | **1,716 件全部** |
  | 8..13 | 2,992 | 49 | 全部 |

  → **S の 7 点部分集合はどれも、円・直線飽和で全 49 点に強制される**。
  したがって **S のどの 7 点も最大 14石集合に含まれない**ことが
  容量引理だけで出る（実測: t=7 の 1,716 部分集合すべてが `in_a_max_set = 0`、
  同時に `not_in_max_and_closure_over_K = 1,716`）。**両者が完全一致**。
- **証拠 2: 証明の tightness（`cert2`、16 最大集合プールと突合）**:

  | t | 最大集合に含まれる | 飽和で排除された |
  |---|---|---|
  | 4 | 27 | 395 |
  | 5 | **5** | 1,225 |
  | 6 | 0 | 1,713 |
  | 7 | 0 | 1,716 |

  - 重要なのは **t=5 で最大集合に含まれる部分集合が 5 個だけ**という点。
    `alpha(S) = 5`（真の最大重なり、16 プールで厳密）であり、
    **飽和引理だけで `alpha(S) ≤ 5` を証明できる**（`alpha_proved_by_closure_alone = 5`、
    `alpha_true = 5`、`closure_suffices: true`）。
    つまり **d_max ≥ 8 の下界は「円・直線の占有不足」だけで完全に証明された**。
  - さらに **容量引理は t=4 の段階で 395 個の部分集合を排除し、
    グラフ上の「16 最大集合.pool に含まれない」という命題と完全に一致**している
    （t=4: 27 + 395 = 422 < 715 → 残る 293 は `cl ≤ K` だが最大集合にも入らない、
    つまり**容量引理は偽の肯定を 1 件も出さない**）。
- **証拠 3: 証明に使われる円・直線の本数（`carriers` ステージ、
  整数正規化キーで分類。浮動小数なし）**:

  | 項目 | 値 |
  |---|---|
  | 7×7 の禁止 4 点組総数 F_7 | 6,364 |
  | 内訳: 直線Carrier | 660 (10.4%) |
  | 内訳: 円 Carrier | **5,704 (89.6%)** |
  | 相異なるCarrier 総数 | 1,057（**直線 44 + 円 1,013**） |
  | S の 3 点を含む Carrier | 92 |
  | **最小の封鎖部分集合** | **4 点**: `{(0,0),(1,0),(1,1),(5,1)}` |
  | その閉包が使う Carrier | **32 本（直線 2 + 円 30）** |
  | 閉包が発火した禁止 4 点組 | 45 |

- 判定の根拠:
  - 命題の前半「S が最大相に近づけないことを**円・直線の容量で下から評価できる**」は
    **成立した**。`alpha(S) ≤ 5` が飽和引理だけで証明され、
    同時に 16 最大集合プールと独立に一致した（`closure_suffices: true`）。
    したがって d_max = 8 の下界には**構成的証明書が存在する**。
  - 命題の後半「**少数の**円・直線の**占有不足と過剰の組合せ**で」については
    **「少数」が裏切られた**: 4 点の封鎖には **32 本の Carrier（円 30 + 直線 2）**が必要で、
    先行メモの「3–4 本の円で `|S∩M| ≤ 5` を強制する被覆」は**実現できなかった**。
    さらに 4 点の封鎖 **`{(0,0),(1,0),(1,1),(5,1)}` は最大集合に t=4 で
    含まれる 27 個の中に含まれる（`in_a_max_set` に数えられる）**ため、
    最小の封鎖部分集合ではない**。`carriers` ステージの
    `smallest_blocking_T_size = 4` は「最小の `cl(T) > K` のサイズ」であって、
    「最大集合に含まれない最小サイズ（= 5）」ではない。
    この 2 者の差は**命題の敏感性の核心**である。
  - よって PARTIAL。前回は「証明書が未構成」だったが、
    今は**構成でき、かつその構成が `|S∩M| ≤ 5` の下界を完全に再現する**ことを示した。
    一方**「少数」の具体数（数十本 vs 3–4 本）は否定**された。
- 残った障害:
  (1) **「少数」の定量化が未完**。32 本（円 30 + 直線 2）は「少数」とは数えられるが、
    round2 のメモが想定した 3–4 本の **10 倍規模**である。
    Carrier を縮約する線形計画問題（あるいは最小の円数被覆を求める問題）として
    再構成する必要がある。
  (2) 32 本は**最小封鎖 4 点**についての数であり、**5 点封鎖**（真の `alpha` 境界）
    については数えていない。
  (3) n ≥ 8 では |ℳ_8| が列挙不能であり、**プールとの突合ができない**ため、
    `closure_suffices` の確認は n ≤ 7 でしかできない。
  (4) 「円容量の**わずか**な不足」という表現は、`cl` の **49（全盤）** saturation が
    「わずか」から程遠いことを示唆する。命題の「わずか」は**この種の 3+3 閉包
    には適用できない**可能性が高い。
