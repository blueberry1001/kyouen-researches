## B591 [全称・大胆] 一石不足の安全配置は定数個の修正で最大になる
- 判定: **PARTIAL**（前回: PARTIAL → 今回: PARTIAL、n=8 の層を初めて実測）
- 前回の一手: 「B591 の有限支持は無い。n≥8 での d_max 延長が必要」（round2 一手 1 は
  B592 の n=8,9 延長）。C は既に C≥8 必要。
- 今回の範囲: n=2..7 は前回と同一（既存 `round2_b591.json` の読み取りのみ）。
  **新規は n=8（K_8=15, 一石不足層=14石）**。`scripts/round3_b591_b592_final.py`
  で ℳ_8 の 1,009,679 個の最大集合を局所探索で構築し（pool バイナリ
  `research/verification/round3_M8_pool.bin`）、14石安全集合 48 個について
  分岐限界で **d_max を厳密（48/48 完了）** 計算した。
- 証拠（n=8、14石層、厳密 B&B、48 個）:
  - d_max 分布 = **{1: 18, 2: 27, 3: 3}**。最大重なり 11/12/13（=14−3, 14−2, 14−1）。
  - 最大値 **d_max = 3**（3 件）。証人座標:
    `(0,0),(3,0),(3,1),(0,2),(4,2),(5,3),(3,4),(4,4),(5,4),(0,6),(2,6),(5,6),(0,7),(7,7)`
    （D4 軌道 8 個）。d_max=3 は全 ℳ_8 に対し |S\M|≥3、|S∩M|≤11。
  - n=7 最遠 13 石の 1 石成長 51 通り中 24 通りを評価: d_max = {1:10, 2:14}、最大 2。
    **n=7 の記録 8 が n=8 では 2 に崩れる。**
  - 機構（新規）: d_max の上限は最大集合族の大きさで決まる。|ℳ_n| = 56,64,100,464,**16**
    (n=3..7) に対し n=8 では **|ℳ_8| ≥ 1,009,679**（局所探索が到達した個数）。
    前回 d_max 最大 0,0,2,3,4,8 は K_n ではなくこの比に従う。n=7 の d_max=8 は
    |ℳ_7|=16 という退化が主因であり、n の線形成長の証拠ではない。
  - (pool 上界) 1,009,679 個の最大集合に対して 14石集合の d_max ≤ 3 または 4
    （実測 max 4）。n=8 では C ≥ 4 しか強制されず、n=7 の C ≥ 8 を上回らない。
- 判定の根拠: 有限層（n=2..8）で C=8 を否定する層は出ない。一方 C=8 の上界は
  n=8 で改善されないため、**B591 を支持する新証拠は得られなかった**。C≥8 の要求は
  依然 n=7 の 8 件（13石）に由来する。
- 残った障害: n=8 の 14 石層は C(64,14) ≫ 10^11 で全列挙不能。d_max 上界は
  「ℳ_8 の部分族に対する上界」しかなく、|ℳ_8| を全部集めても上界 4 からしか動かない。
  絶対定数 C の存在/不存在は n≥9 の無限族を要求するため、有限計算では不可。

## B592 [存在] 最大に一石不足でも最大配置から線形距離に離れられる
- 判定: **PARTIAL**（前回: PARTIAL → 今回: PARTIAL、n=8 の層を実測）
- 前回の一手: 「B592 の n=8,9 へ: 一石不足層の d_max 最大値を延長し、d_max/n が
  線形か確認。K_8=15 なので 14 石層が必要」（round2 一手 1）。今回その 14 石層を実測。
- 今回の範囲: n=2..7 は前回データ（`round2_b591.json`）。新規は n=8 の 14 石層で
  14石安全集合 48 個（n=7 最遠集合からの成長 24 + ランダム層 24）。B&B は 48/48
  完了＝**d_max 値がすべて厳密**。n=9 は 17 石層が必要で 81 点中 17 個の列挙が
  現環境（3 分制限）で不可、本回は未着手。
- 証拠:
  - d_max/n の最大観測（前回 n=4..7: 0.50, 0.60, 0.67, 1.14）に **n=8: 0.375** を追加。
    d_max 最大は 3、n=8 では 1.14 → 0.375 と**低下**した。
  - n=7 の記録的証人（13石, d_max=8, 全16最大集合と共通5石以下）を n=8 に 1 石
    成長させても d_max は 1〜2 に留まる（51 通り中評価 24、hist {1:10, 2:14}）。
  - 機構（新規・B592 対 B591 の切り分け）: d_max は「一石不足層の大きさ」ではなく
    **最大集合族 |ℳ_n| の相対的な小ささ**に支配される。n=7 は |ℳ_7|=16 と極端に
    小さいため 8 石の修正が必要になる。ランダムな 14 石集合は 13/14 個の最大集合に
    含まれる（実測 max_overlap = 13 が 18/48、12 が 27/48）。B_8 では ℳ_8 が
    大きすぎて d_max が 3 に落ちる。
- 判定の根拠: 存在命題（無限族で d_max ≥ c·n）を **n=8 のデータが支持しない**。
  線形成長の兆候は n=7 の 1 点（|ℳ_7|=16 という退化）だけに依拠し、n=8 で崩れる。
  ただし n≤8 の 8 点で存在命題を反証はできない（禁止事項どおり、小盤の不発見を
  無界の存在命題の反証にしない）。よって PARTIAL のまま、ただし**方向は前回と逆に
  転じた**（前回「有限データは B592 側に傾く」→ 今回「n=8 では B592 側が弱まる」）。
- 残った障害: (1) n=8 の 14 石層は C(64,14)≳10^11 で全列挙できず、48 個は標本に
  すぎない。d_max=3 の層が本当に最大 3 かは未確定（pool 上界は 4 を許す）。
  (2) 存在命題の鍵は |ℳ_n| の n 依存（n=7 で 16 に落ち、n=8 で 10^6 以上）であり、
  これは n=9,10 の K_n と |ℳ_n| の確認が要る。K_9 ≥ 17 は既存、ℳ_9 の大きさは未計算。
