## B141 [漸近] 共線四点組の主項はn^5
- 判定: **REFUTED**
- 範囲: D_n を n=2..40 まで閉形式で完全計算。D/n^5、D/(n^5 log n)、D/n^6 を比較。
- 証拠: D_n/(n^5 ln n) = 0.0323 で n=28..40 に安定。D_n/n^5 は 0.053 (n=9) → 0.119 (n=40) で対数的に上昇し続け、有限極限を持たない。真の主項は **D_n = Θ(n^5 log n)**（係数 ≈ 0.0323）。`batch08_followup.py` / `batch08_results2.json`。
- メモ: 「n^5 か n^6 か」の対立では n^5 側が近く、log 修正のみが不足。F-W の「D_n=Θ(n^6)」も n=11..20 の D/n^6 単調減少 (0.0059→0.0047) で否定される。

## B142 [漸近・大胆] 非共線共円四点組はn^(4+o(1))
- 判定: **REFUTED**
- 範囲: C_n = F_n − D_n を n=2..12 で計算。C/n^4, C/n^5, C/n^6 を比較。
- 証拠: C_n/n^5 = 0.180 (n=4) → 0.568 (n=12) で単調増加。C_n は n^5 より速く成長し、n^4 には絶対に収まらない。n^6 近似 (C/n^6 ≈ 0.047–0.050) が n=8..12 で相対的に安定。`batch08_results2.json`。
- メモ: n^(4+o(1)) は 4 乗も下回る主張で、小盤ですら C_3=14, C_4=184 が n^4=256 の半分以上。棄却は自明。

## B143 [漸近] 共円四点組にはn^5級の非長方形族がある
- 判定: **SUPPORTED**
- 範囲: liminf C_n/n^5 > 0 を n=4..12 で検査。非長方形族の存在は R_n < C_n から確認。
- 証拠: C_n/n^5 = 0.180→0.568 と単調増加、liminf ≥ 0.57 > 0。さらに長方形 R_n は C_n の 5–24% しかなく、主項は非長方形の円族が担う。`batch08_results2.json`。
- メモ: 「n^5級」は過小評価（C_n/n^5 自体が発散気味で n^6 近似が良い）。不等式としては成立し、B142 との競合では B143 側が生き残る。長方形族だけでは liminf を説明できない点は予想どおり。

## B144 [漸近・大胆] 十分大きい盤では共線が多数派になる
- 判定: **REFUTED**
- 範囲: D_n/F_n を n=4..12 で計算。D_n=Θ(n^5 log n) と F_n=Θ(n^6)（F-T）の比較。
- 証拠: D/F は 5.2%→10.9% (n=11) で一旦頭打ちの後 10.8% (n=12) と横ばい。D_n/n^6 は n=9 以降単調減少 (0.0059→0.0030 at n=40)。F_n が n^6 級なら D_n/F_n → 0 で、共線はむしろ**消滅する側**。「共線が多数派」は正反対。`batch08_followup.py`。
- メモ: 小盤の「共線比 11% 安定」（F-W）は n=9..12 の偽のプラトー。長期では共円が支配的（C_n/F_n → 1 が本命）。

## B145 [構造] 共線数の主項定数を原始方向の収束級数で書ける
- 判定: **PARTIAL**
- 範囲: D_n を primitive 方向 (dx,dy) ごとの C(run,4) 総和に分解（重複なし、enum 一致）。方向別の n^5 係数を n=16,32,64 で測定。
- 証拠: `fact_collinear_run_formula.json` の by_dir 合計 = D_n。固定方向の D(a,b;n)/n^5 は極限を持つ（(1,0)→1/24 候補、(1,1)→1/60 候補）。方向の総和は Σ_m O(m)·O(m^{-2}) 型で log を生み、係数 c≈0.0323 は方向級数で書ける。
- メモ: 「主項定数」が純粋な n^5 定数としては存在しない（log 因子付き）。n^5 log n の係数の明示的級数としては本命。部分線分の二重計数（F-W の落とし穴）を避ける最大線分ラン長和が正しい分解。

## B148 [構造] 固定した原始円テンプレートの平行移動数は閾値後に二次式
- 判定: **SUPPORTED**

## B154 [漸近] 算術的な次数揺らぎは内部でも消えない
- 判定: **PARTIAL**
