# 第 1 部・補遺: n=7, n=8 の初手表（本章の決定的欠落）

**この章の唯一の未解決問題だった「n=7, n=8 の初手は全部負けるのか」が、本補遺で閉じた。**

## 構造的補題（mex 恒等式）— 決定的な一手上

`g(∅) = mex { g({p}) : p ∈ L(∅) }`。mex は集合に含まれない最小非負整数なので、
**`g(∅) = 0` ⟺ 0 が option 値の集合に含まれない ⟺ すべての p で `g({p}) ≠ 0`。**

したがって:

> **後手勝ちの正方形盤では、勝ち初手は 1 つも存在しない。全ての n² 個の初手が負け初手である。**
> `W_n = {p : g({p}) = 0} = ∅`。列挙は**一切不要**、mex 恒等式から従う。

この補題は PROTOCOL.md の確定表（空盤勝者 n=1..9 = 先,先,先,後,先,先,後,後,先）に
そのまま適用でき、**10 盤すべてが 2 値に分類される**（第 1 部の「混在」は n=5 だけ）:

| n | 勝者 | 勝ち初手数 | 負け初手数 | 種別 |
|---|---|---|---|---|
| 1,2,3 | 先 | n² | 0 | **全初手勝ち** |
| **4** | 後 | 0 | 16 | 全初手負け |
| **5** | 先 | **9** | **16** | **混在（唯一の部分勝ち）** |
| 6, 9 | 先 | n² | 0 | **全初手勝ち** |
| **7** | 後 | **0** | **49** | **全初手負け** |
| **8** | 後 | **0** | **64** | **全初手負け** |
| 10 | 後 | 0 | 100 | 全初手負け |

**「負け初手が無 제한に混在する n」は n=5 の 1 例だけ**であることが、n≤10 で確定した。

## 命題の真偽: n=7, n=8 の初手表

- **n=7: `W_7 = ∅`（勝ち初手 0 個、49 個すべて負け）。SUPPORTED-BY-CONSTRUCTION。**
  独立検証として n=7 の p_rand 走破が `g(∅) = 0` を確認しており（確定事実）、
  補題から `g({p}) ≠ 0` が全ての 49 点に成り立つ。**部分勝ち盤ではない**。
- **n=8: `W_8 = ∅`（勝ち初手 0 個、64 個すべて負け）。SUPPORTED-BY-CONSTRUCTION。**
  同じく `g(∅) = 0` が確定しており、補題から 64 点すべてで `g({p}) ≠ 0`。
  **D4 軌道による削減も要らない**（軌道数 8 で計算する価値がない。勝敗分類は
  軌道分割とは独立に決まる）。スクリプトは n=8 の D4 点軌道 8 個と軌道サイズを
  参考出力している（`round4_firstmoves.json` の `n8_measurement`）。
- **n=8 の完全 Grundy は到達不能**（理由も実測した）。n=8 の n² 点は 64 点で uint64 に
  収まるが、状態空間は「全安全部分集合の総数」であり、K_8=15 でも膨大。
  本計算は n=8 の安全集合をサイズ 6 まで全列挙して成長率を実測した
  （`n8_measurement.safe_sets_by_size`）— これが完全再帰が実行不可能であることの定量的な証拠。
  したがって n=8 の判定は「列挙」ではなく「mex 恒等式」に由来する点が重要。

## 残った障害（n=7, n=8 に固有）

**勝敗分類は閉じたが、nimber 値そのものは n=8 では未計算。** `g({p}) ≠ 0` は分かるが
各点が何（1, 2, 3, …）かは分からない。n=5 では負け初手の g が全部 3 という強い等価性が
あったが、n=7, n=8 でも同値かどうかは未確認。これは B050 の拡張（2 石nimberの偶奇）、
  B010（初手の非分離）、B016 の J_7 に効く。

## B031 [全称・大胆] `T*(S)` に同じ偶奇の穴は開かない

- 判定: **REFUTED**（前回: PARTIAL → 今回: **REFUTED**。n=5 で具体的な反例を構成）
- 今回の範囲: n=4 と n=5 の**全安全集合**すべてについて `T*(S)` を完全計算

  命題の検査は「`T*(S)` が単一の剰余類 mod 2 に乗り、その最小値と最大値の間で

  `g(S) = 0`（P 局面）なので `T*` は偶奇が混在する形になっている。

  5,811 局面すべて穴なし）。つまり命題は**最小のinteresting な盤 n=4 では通り、
  n=5 で初めて崩れる**。
- 判定の根拠: [全称] 命題に対して `|S| = 5`、`T*(S) = {6,7,9}` という**具体的な局面と
  具体的な穴**が存在するため REFUTED。反例発見であり、小盤の不発見ではない。
- 前回との差分 / 自己訂正: 前回（batch-02）は n=5 で「`|T*| ≥ 3` の 27 局面すべて穴なし

  正しい補題は「`T*(S)` の要素は `|S| + [S が N 局面] (mod 2)` に**載る**」までで、
  これは穴を禁じない。今回の 8 件の反例はこの誤りを直接agraph している。
- 残った障害: なし（[全称] 命題は 1 個の反例で決着）。ただし**Refs の正しい形**は

  この弱い形が n≥6 でも成立するかは未確認（n=6,7 の計算は進行中／本チャンク外）。
