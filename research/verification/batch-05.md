### 本バッチの追加計算

1. `research/verification/scripts/batch05_inventory.py` — 証人 7 例の安全・極大性を独立再検証（すべて safe=true, maximal=true）。三つ組の共線/非共線分解。

8. `night-research/maxsafe_enum.exe count 8 15` は 90s で未完（n=8 最大集合の全数カウントは数分〜数十分級）。n=8 K=16 UNSAT は既存ログで確定扱い。

## B081 [全称] 9×9の最大安全サイズは17
- 判定: **REFUTED**
- 範囲: 後日の先行研究棚卸しで、2018年公開資料に **k(9)=18** が明記されていることを確認したため訂正。
- 証拠: `docs/RELATED_WORK.md` に出典と k(1)..k(9) の公開値を記録。本repo自身の9×9証明書も17石安全配置を独立に含むが、18石の本repo内再探索は未実施。
- メモ: 旧判定INCONCLUSIVEは「repo内のu64ツールだけを見た」ための見落とし。数学的命題B081は公開既知値18により反証済み。128-bit探索は独立再現の課題であって、K_9の値を決めるための未解決課題ではない。

## B082 [全称・大胆] 10×10では20石まで届く
- 判定: **INCONCLUSIVE**
- 範囲: K_10 の直接最大集合探索は無し。既知の K_9=18 を隅へ埋め込めるため **K_10 ≥ 18** が定理的に従う。20 = 2n は n=7 に次ぐ 2 度目の「2n 到達」になる。
- 証拠: 10×10 の最大安全探索ログは results/10x10 に無し（同ディレクトリは対局証明/probe 系）。`fact_10x10_maximal_*` は最小極大側の探索。
- メモ: 現在の下限は18。19 (=2n-1) または20 (=2n) の証人を探せば下限が動く。

## B083 [漸近・大胆] K_n/nは2へ収束する
- 判定: **INCONCLUSIVE**
- 範囲: n=1..9 の K_n/n = 1, 1.5, 1.667, 1.75, 1.8, 1.833, 2.0, 1.875, 2.0。2 へ単調収束には見えない（n=7 で 2.0、n=8 で 1.875 に落ち、n=9で2.0へ戻る）が、有限サイズの例外として矛盾しない。
- 証拠: 上記 K_n 表。PROTOCOL「大胆な漸近予想は整合確認のみで INCONCLUSIVE 可」。
- メモ: B084 が成立すれば B083 に従う。B082 が正でも (20/10=2) で矛盾しない。

## B084 [全称・大胆] 2nからのずれは有界
- 判定: **INCONCLUSIVE**
- 範囲: n=1..9 で |K_n-2n| ≤ 1（n=7,9 で 0）。C=1 が現時点で全点を覆う。
- 証拠: K_n 表の K_n-2n 列。`batch05_inventory.json` の max_observed_abs_K_minus_2n = 1。
- メモ: とても強い整合。しかし全称なので n→∞ の証明は不可。B085 と排他的（両立しない）。

## B085 [存在] 2nを任意に大きく上回る盤がある
- 判定: **INCONCLUSIVE**
- 範囲: n≤9 の全既知値で K_n ≤ 2n。上振れの証人も、任意 M への到達も未探索。
- 証拠: K_n-2n ∈ {0, -1} のみ。n=7 の 2n 到達すら「超過」ではない。
- メモ: B084 の競合。存在主張のため、1 つの強い反例（|K_n-2n| が観測最大を更新する n）で B084 と同時に決着しうる。

## B086 [全称・大胆] 一段拡大による増分は高々3
- 判定: **SUPPORTED**
- 範囲: 全既知の連続対 n=1..9。増分は 2,2,2,2,2,3,1,3。最大 3（n=6→7 と n=8→9）。
- 証拠: K_n 表の Δ 列。`batch05_inventory.json` max_observed_delta = 3。
- メモ: 単調性（Δ≥0）は定理だが、Δ≤3 は経験則。n=7→8 の +1 と n=6→7 の +3 が同居するので「常に 2」などより弱い主張として自然。全称なので範囲外は未証明。

## B087 [存在] 既存最大配置に外周を足すだけでは次の最大へ届かない
- 判定: **SUPPORTED**
- 範囲: n=6→7 と n=7→8 の全最大配置 × 全 4 平行移動埋め込みについて、伸長先の最大サイズを計算。
- 証拠: **n=7 が証人。** `b087_extend_n7.exe` の結果、maxsafe_n7_K14.bin の 16 集合 × 4 移動 = 64 埋め込みすべてで、8×8 上に**加えられる点が 0 個**（add_count_hist {"0": 64}）。つまり 7×7 最大配置は 8×8 の最大 15 石へ 1 石も足せない。対照的に n=6→7 では 1856 埋め込み中 16 が K_7=14 に到達（reach_hist {11:1016, 12:760, 13:64, 14:16}）。出力: `research/verification/batch05_compute.json`、実装: `research/verification/scripts/b087_extend*.cpp`。
- メモ: 「外周を足すだけ」では n=7 最大配置は完全に詰む。K_8=15 は n=7 結晶から到達不能で、別構造の 15 石（cycle6-maxsafeset-n8-15.json の witness）を使う必要がある。CYCLE14H の「n=8 では (2,2) も中心ブロックも自由」と整合。

## B088 [構造] 2n-O(1)石の安全配置を無限族で作れる
- 判定: **NOT-CHECKED**
- 範囲: 有限体放物線の整数化など構成的無限族は本バッチでは試していない。
- 証拠: 既存データにも無限族の構成記述は無い。K_n≈2n-1 の既知値と整合するが、構成の存在は未検証。
- メモ: 有限体 → 整数盤の安全性移行条件が本体。parabola y=x² の格子点は 3 点共線にならないが 4 点共円を避ける保証は別途必要。次の一手: 小 n で「2n-O(1) 石の系統的構成」が既知最大に近いかを機械的に照合。

## B089 [構造・大胆] 少数の代数曲線の和で漸近最適になる
- 判定: **NOT-CHECKED**

- 証拠: なし。n=7 の 16 集合が「結晶的」で曲線族には見えない（CYCLE6）ことは弱い緊張材料。
- メモ: B088 の強い版。B083/B084 が真なら自然な達成方法だが、ここでは判定不能。

## B090 [統計] 最大配置の難しさはサイズより型数に現れる
- 判定: **PARTIAL**
- 範囲: n=6（464 集合 / 58 D4 軌道 / ρ=1 が 64% / 1-swap 辺 608）と n=7（16 集合 / 2 軌道 / ρ=2 全数 / 1-swap 辺 0）の対照。
- 証拠: CYCLE6_MAXSAFE_EXCHANGE.md の表。軌道数が極小（2）の n=7 で交換障壁が最大（ρ=2, 辺 0）という対応は 1 点確認。CYCLE14H サンプルでは n=8 は ρ が 1/2 混在で n=7 型の孤立に転じていない。
- メモ: 統計的主張なので n=6,7 の 2 点では相関の確度に足りない。n=8 最大集合の全数（または大標本）で軌道数と ρ の共分散を見る必要。最大集合数そのもの（464 vs 16）と軌道数は同時に動いており、交絡あり。

## B095 [漸近・大胆] 最小極大は線形より小さくなる
- 判定: **INCONCLUSIVE**
- 範囲: 確定 s_n = 5,5,5,6,7 は n=6,7 で s_n = n（線形）。s_n/n → 0 とは緊張するが、仮説は「小盤は過渡」と明示。
- 証拠: F-AM / F-BA。s_8 ∈ [7,8]、s_10 ∈ [7,11] はまだ n と同程度。
- メモ: s_n の上界が o(n) に落ちる兆候は未観測。三つ組被覆の不等式（F-AX 型: n²−k ≤ C(k,3)·(M(n)−3)）は k を下から押すだけで上界は作らない。

- メモ: B095 の精密版。B095 が偽なら B096 も偽。

## B099 [統計] 最小極大配置では長い直線と豊富な円を併用する
- 判定: **PARTIAL**
- 範囲: 既知の最小極大・近傍証人 7 例について、三つ組の共線/非共線を分解。全例で共線三つ組が 2–5 個、非共線が大多数（例: n7_s7 は 35 三つ組中 3 共線、n10_s11 は 165 中 5）。
- 証拠: `batch05_inventory.json` の witnesses（collinear_triples / noncollinear_triples）。n5_s5 は 10 中 2、n6_s6 は 20 中 2、n8 の 8 石新証人は 56 中 3。
- メモ: 「併用」の弱い支持（どちらも 0 ではない）だが、「豊富な円」は未測定（非共線三つ組＝共円三つ組ではない。補完数 0 の三つ組は円に属さない）。共線/共円どちらのブロックで空点を塞いでいるかの帰属分析が次の一手。棒状配置（F-V / F-AU 系）は直線偏重に見える緊張あり。

## B100 [全称・大胆] 極大サイズのスペクトルは区間
- 判定: **PARTIAL**
- 範囲: n=3,4,5,6 の完全極大スペクトルはすべて連続区間 [s_n, K_n]。n=7 以上は未列挙。

- メモ: 反例探しは n=7 で最短。16 個の最大（14）は既知なので、s_7=7 から 13 までの各サイズに極大が在るかを `list_maximal_size.exe 7 k` で潰す。欠落 1 つで REFUTED。
