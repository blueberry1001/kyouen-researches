## B501 [全称・大胆] 標準盤のP局面のランダム勝率は2/3以下

- 判定: **PARTIAL**（前回: SUPPORTED → 今回: PARTIAL。範囲が n≤4 から n≤5 に拡大し、
  同時に n=5 で **2/3 超えの反例が 36 個** 現れて束が破れたため SUPPORTED を維持できない）
- 前回の一手: 「**n=5 の p_rand 完全 DP**（B501/B502 の決着）。C++ 移植か状態圧縮。
  P の最大が 0.563 を超えるか、2/3 を超えるか。」
- 今回の範囲: **n=5 の 151,394 状態すべてが完全 DP で解けている**（到達可能安全集合の総数
= Σlevel_sizes = 151,394、層サイズ 1/25/300/2300/11824/37272/59192/35208/5172/100、
辺 885,065、最大安全サイズ 9）。P 局面は 40,325、N は 111,069。
計算時間は合計 **7.7 秒**（build 0.149 / enumerate 3.44 / edges 3.02 / grundy 0.16 /
prand 0.26）。分母は層ごとに 19〜21 桁まで増え、多倍長整数で逐次既約化されている。
- 証拠（すべて厳密な整数演算、報告は分数）:
  - n=5 の P 局面 p_rand の**最大は 2383/3360 = 0.709226190476…**。
    2/3 = 2240/3360 との差は **+143/3360 ≈ +0.0426**。**束 2/3 は破られた。**
  - この最大を与える P 局面は **16 個**（`P_max_n_attaining`）。証拠となる 1 個:
    `occ = 11329`、石数 k=5、座標 (x,y) = **(0,0), (1,1), (0,2), (1,2), (3,2)**、
    **g = 0（P 局面）**、|L| = 8、残り最大手数 max_rem = 3、
    子 p_rand（降順）= 1/2, 2/5, 1/3, 1/4, 1/4, 1/4, 1/5, 1/7。
    平均 = 583/3360、よって 1 − 平均 = **2383/3360**（独立再計算で一致を確認済み）。
  - **2/3 を超える P 局面は 36 個**（`P_gt_2_3`）、1/2 を超えるものは 644 個
    （`P_gt_1_2`）。n=4 では 0 個だったので、これは n=5 で初めて現れた違反である。
  - 残り最大手数 h ごとの P の最大値（`P_max_by_maxrem`、n=5）:
    | h | 0 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
    |---|---|---|---|---|---|---|---|---|
    | max p_rand | 0 | 0 | **2383/3360** | 212/315 | 12459851/23284800 | 66591319117/112935513600 | 0.48427… | 0.51752… |
    h=3 の 2383/3360 だけが 2/3 超え。h=4 の 212/315 は 2/3 を 2/315 下回る（= 0.6730…）。
    h≥5 ではすべて 2/3 を下回る。→ **違反は h=3 の層だけに集中している。**
  - 参考（既存の確定結果の再掲ではない、空盤の値）: 5×5 空盤は **g = 1（N 局面）**、
    p_rand = 2098233734897851147/4218230592576000000 ≈ 0.4974203493…、|L| = 25、max_rem = 9。
    5×5 は n=4 の 4×4 と異なり**先手勝ち**である点に注意（4×4 は g=0）。
  - n≤4 の前回値（最大 76/135 = 0.56296…）は前回の確定結果。本回の新規分は n=5 全部。
- 判定の根拠 / 残った障害:
  - 2/3 という具体的な束は **反例を持つ**（occ=11329、2383/3360 > 2/3、差 143/3360）。
    全称命題なので、n=5 の 36 件のうち 1 件を見つけるだけで仮説が壊れる。
  - したがってラベルは SUPPORTED ではなく **PARTIAL**。成立している部分:
    「P 局面の p_rand は n≤5 では 1 に近づかない」＝ 151,394 状態中の P 40,325 個のうち
    40,289 個（99.911%）が 2/3 以下で、2/3 超えは 36 個（0.089%）にすぎない。
  - 残った障害: 標準盤＝n×n の無限族についての全称命題なので、n≤5 の有限検証では
    原理的に閉じない。n=6 以降の完全列挙（極大 349,596、状態数は桁で増える）は今回未実施。
    残った具体的問いは「2/3 超えは n=5 の h=3 の 36 例に限られるのか、それとも n で増えるのか」。

## B502 [存在] P局面でランダム勝率3/4を超えられる

- 判定: **INCONCLUSIVE**（前回: INCONCLUSIVE → 今回: INCONCLUSIVE。ただし「壁」は
  0.563 から 0.709 へ上がったので、前回と同一の理由の転記ではない）
- 前回の一手: 「n≥5 の P 局面探索」（n≤4 に証人なし、0.563 の壁）
- 今回の範囲: n=2,3,4,5 の**全到達可能安全局面 152,706 個**（n=5 のみ 151,394、
  n≤4 は 1+15+298+5811 程度）の P 局面を完全 DP で走査。n=6 は未。
  （n=5 の 151,394 は `round3_b501_pgrand_n5.json` の実測値。n≤4 の母集団数は
  round2-batch-b501.md の記載：n=2:15、n=3:298、n=4:5811。）
- 証拠:
  - n=5 の P 局面で p_rand > 3/4 となるものは **0 個**（`P_gt_3_4 = 0`）。
    n≤4 でも 0 個。したがって **n≤5 の全 P 局面で p_rand ≤ 2383/3360 < 3/4**。
  - 余裕は **3/4 − 2383/3360 = 137/3360 ≈ 0.0408** しかなく、前回の 0.563 相比べると
    「壁」は 0.563 → 0.709 と 0.146 も上がった。0.709 から 0.75 までが薄い。
  - 参考（N 側の値）: n=5 の N 局面の p_rand 最小は **1/12**、最大は 1。
    N の 1/12 は n=4 の 0.0909… と同一直線上の値で、前回の観測を再現している。
- 判定の根拠 / 残った障害:
  - 存在命題なので n≤5 の不発見は反証にならない。3/4 超えの **証人は n≥6 でのみ現れる可能性がある**。
  - n=6 は極大 349,596 個、到達可能安全集合は 6×6 全体で 2^36 スケールの序数となり、
    今回の層別 numpy アプローチ（n=5 で 7.7 秒）をそのまま 2 桁上には拡大できない。
  - 構造的手がかり（今回得られた新材料）: n=5 の P の最大 2383/3360 は
    |L|=8、k=5、max_rem=3 の局面で達成される。子の p_rand 分布が
    {1/2, 2/5, 1/3, 1/4, 1/4, 1/4, 1/5, 1/7} と**不揃いに散らばっている**のが高値の機構で、
    「値の異なる多数の子に手を広げた P 局面」が random 側の勝率を上げる。
    |L| を増やせばさらに上がりうるが、n=5 の 16 例では |L|=8 が上限だった。
    **n≥6 で |L|≥9 の同型構成が存在するかが B502 の核心**。もし 9 手以上のこの型があれば 3/4 は射程内に入る。
  - したがって「n≤5 に証人なし」という結論は前回より強い（母集団が 26 倍）が、ラベルは INCONCLUSIVE のまま。

### 今回決着した動き

- **B501: SUPPORTED → PARTIAL（退行）。** 前回 n≤4 で束 2/3 は成立していたが、
  n=5 の完全 DP（151,394 状態、7.7 秒、P 40,325 個）で **2/3 超えが 36 個**見つかり、
  具体的反例（occ=11329、k=5、g=0、2383/3360 = 0.7092… > 2/3、差 143/3360）が得た。
  「P で 2/3 以下」は **n≤5 で偽**になった。反例を 1 つ書くだけで全称は崩れるので SUPPORTED ではない。
- **B502: INCONCLUSIVE のまま（強化）。** n≤5 の全 P 局面（152,706 状態）で 3/4 超え 0 件。
  ただし P の最大が 0.563 → 0.709 に上がり、3/4 までの余裕が 137/3360 まで縮小した。
  存在命題なので n≥6 の探索が必須で、証人はまだない。

### 残る未解決とその一言理由

- B501: n≥6 の P 局面 p_rand が 2/3 を超えるか（2/3 超え 36 例が n で増えるか消失するか）。
- B502: n≥6 の P 局面で 3/4 超えの証人が存在するか。鍵は |L|≥9 の不揃い fork 型 P 局面。

### 最も有望な次の一手（1つだけ）

**n=6 の P 局面の p_rand 上界を、|L| と子の p_rand 分散の構造から絞り込む。**
n=5 の 16 例が「k=5, |L|=8, max_rem=3, 子が 8 種の不揃い」という 1 つの型に
収束していることは、その型を n=6 で列挙する方針が立つことを意味する。
`round3_b501_pgrand_n5.py --n6 N`（同スクリプトに n=6 サンプリング分岐が既にある）は
ランダム対局から到達した位置の部分木を完全列挙して厳密な上界を出すので、
B502 の証人探しとしては最小のコストで動く。n=6 の完全 DP 全体はまだ重い。

### 検算・注記（信頼性）

- B501 の証人 occ=11329 について、json の `top` 行（子 p_rand 8 種、|L|=8、p_rand=2383/3360）を
  `kyouen_core` の `is_safe` / `legal_moves` / 自前の有理数 DP で**独立に再計算し一致を確認**。
  さらに 2383/3360 − 2/3 = 143/3360 > 0、3/4 − 2383/3360 = 137/3360 > 0 を有理数で確認した。
- json の `top` 表の 9〜10 行目（occ=5124, 20484）では `L`=21 だが `child_p_rand_sorted` に
  19 個しか入っていない。これは表示の省略であり、json の p_rand 値本体は
  21 手全部から計算された正しい値。`top` 表の子のリストは 8 個で満杯に truncate されている。
  **見出し数値（P_max, P_gt_2_3, P_gt_3_4, n_P, n_N, edge_total, level_sizes, P_max_by_maxrem）**
  はすべて内部整合（Σlevel_sizes=151394、P+N=151394、各 P_gt_* の値が n_P 以下）。
  したがって本判定は表の子の省略には依存しない。
