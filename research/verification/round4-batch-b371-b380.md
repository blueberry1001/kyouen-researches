# 第0節：8石極大全列挙の成立（第3回の最大障害が解消）

第3回個票の核心は「8石極大の**全列挙が未達**」で、B371–B375/B378/B380 の 6 件が
これだけで閉じていた（`round3-batch-b371-b380.md:54, 68, 82, 96, 110, 125, 139`）。
WSL C++ でこの障害は解消した。成果は `scripts/round4_b371.cpp`。

## 0.1 手法

8×8 盤・8 石の**安全かつ極大**な集合を全列挙する。刻み盤は `uint64_t` 1 個に収まる。

- 各盤上の三つ組 T に対し、comp(T) = {p : T∪{p} が共円または共線} を前計算（CSR 表）。
- 占有集合 occ に対し `blocked(occ) = ⋃_{T ⊂ occ} comp(T)`。
  **p ∉ occ が合法手 ⟺ p ∉ blocked(occ)**。この判定は 1 回あたり O(C(k,3))≒56 回で済み、
  共有コアの `kc::legal_mask`（1 回あたり O(F_8)=O(14564)）より大幅に速い。
- 添字昇順に深さ 8 の DFS。最上位は添字**対** (a,b), 0≤a<b<64 で分割し、
  8 点集合はちょうど 1 タスクに属するので重複も漏れもない（`-fopenmp` で 16 並列）。

## 0.3 検査中に見つかった 2 つの実バグ（自分の側。共有コアは無罪）

1. **三つ組の添字関数の衝突。** `a + b(b−1)/2 + (c−2)` は単射ではない。組の番号は
   組合せ数体系 `C(a,1)+C(b,2)+C(c,3)` で与えるべき。誤った版では n=4 で
   4,903 エントリ中 **3,077 が不正**・1,050 が重複していた。
2. **極大集合の列挙に「候補殺し」枝刈りは不可。** 通常の
   「quad を完成させる候補は後で入れられないので捨てる」枝刈りは、
   *極大*集合の列挙では不正である。点 p は現在の occ に対してだけ禁止されるのであり、
   p 自身が最終状態として合法でありうる。実際 4×4/k=6 で 688 件しか取れず
   （正しくは 3,608）。よって全添字域を走査する。

> 参考: `kc_maximal.cpp` は極大になった時点で記録するため、その出力個数は
> **サイズ K ちょうどではなく「サイズ ≤ K の極大集合の総数」**である
> （`data/kc_maximal_n5_k8.bin` はヘッダ 16,760 = n=5 極大総数 16,860 − サイズ9の 100、
>  ファイル数も 8+16760×8=134088 と整合）。本ソルバはサイズちょうど 8 を数える。

## 0.4 8×8・8石極大の全列挙＝**408 個**（103.1 秒・16 スレッド）

8×8 の 8 石極大集合は **408 個しかない**。全称 3 件（B371/B372/B373）は
全称の反証を探せるだけの母集団が揃った。既存証人 W=`[0,1,6,20,24,32,34,60]` は
この 408 個の中に**含まれる**（独立に再発見された）。
各葉の極大性判定を `kc::legal_mask` と突き合わせた結果 **不一致 0/408**。

主要分布（`round4_b371.json`）:

| 量 | 分布 |
|---|---|
| 共線三つ組の本数 | 1:24, 2:112, 3:176, 4:88, 5:8 → **0 本のものは 0 個** |

| min b / ρ | 全 408 個が min b=1, ρ=1 |

# B371 [全称・大胆] 8×8 の 8 石極大集合は三点共線を必ず含む

- 判定: **SUPPORTED**（前回 PARTIAL → 今回 **SUPPORTED**。全称（全 408 個）で成立）
- 範囲: 8×8 のサイズちょうど 8 の安全極大集合 **408 個全件**（全列挙）。
- 証拠: 共線三つ組の本数の分布は `{1:24, 2:112, 3:176, 4:88, 5:8}`、
  **`ncol = 0` の集合は 1 つも存在しない**（`round4_b371.json` `b371.sets_with_no_collinear_triple = 0`）。
  最小でも 1 本は共線を持つ。
- 前回からの前進: 第3回は「既知の証人 1 個（3 本の共線）のみ」で全称の射程の外
  （`round3-batch-b371-b380.md:53`）。今回は**反証側が問われる存在命題
  「共線 0 本の 8石極大は存在しない」が全列挙で証明**された。
  つまり命題の趣旨「円だけで効率よく 56 空点を覆う 8 石構成は存在しない」は
  この 8 石極大の族の範囲で**肯定**された。
- 注意（射程の明示）: 命題は「8×8 の 8石極大集合」という有限族についての全称であり、
  全列挙で**閉じた**。ただし「円のみで覆う 8石構成が存在しない」を一般 n・一般石数に
  外挿してはならない。8 石**未満**の極大（例: n=5 のサイズ 5–7）は別問題で本判定は言わない。
- 残った障害: なし（本件は決着）。

# B372 [全称・大胆] 8×8 の 8 石極大集合には方向の異なる三点直線が二本ある

- 判定: **REFUTED**（前回 PARTIAL → 今回 **REFUTED**。反例を 1 つも具体的に構成）
- 範囲: 8×8 の 8石極大 408 個全件。
- 証拠: 共線方向の種類数の分布 `{1:26, 2:146, 3:175, 4:57, 5:4}`。
  **方向が 1 種類しかない 8石極大が 26 個存在する**（`b372.sets_with_at_most_one_direction = 26`）。

  に過ぎなかった（`round3-batch-b371-b380.md:67`）。今回は**1方向型が実際に存在する**

# B373 [全称・大胆] 8×8 の 8 石極大集合は少なくとも二辺に触れる

- 判定: **REFUTED**（前回 PARTIAL → 今回 **REFUTED**）

- 証拠: 接触する辺数の分布 `{1:72, 2:160, 3:160, 4:16}`。
  **1 辺しか触らない 8石極大が 72 個存在する**（`b373.sets_touching_at_most_one_side = 72`）。
  よって「少なくとも二辺」は偽。0 辺のもの（周縁に 1 点も無い）も 0 個だが、

- 残った障害: なし（本件は決着）。「周縁を塞ぐには境界接触が要る」という

# B375 [存在] 新しい 8 石証人とは D4 軌道占有数も異なる 8 石極大がある

- 判定: **SUPPORTED**（前回 INCONCLUSIVE → 今回 **SUPPORTED**）
- 範囲: 8×8 の 8石極大 408 個 → 309 個の D4 軌道。軌道占有シグネチャ **26 種**。
- 証拠: 既知証人 W の型は `((4,1),(8,2),(8,2),(8,3))` だが、
  全 309 軌道は **26 種の異なるシグネチャ**に分布する
  （`b375.orbit_signature_hist_per_d4_orbit`）。例えば
  `8:1|8:2|8:2|8:3`（大きさ 4 の軌道に一切触れない＝角も (1,1) 系も 0 占有）が 25 軌道、
  `4:1|8:1|8:1|8:1|8:2|8:3` が 28 軌道、`4:1|8:1|8:2|8:2|8:2` が 30 軌道 等。
  W の型と異なる軌道型は **308 軌道**（W の型 1 軌道を除く）であり、存在命題は充足。
- 追加の構造的事実: **全 408 個が自明な D4 安定化群**（`d4_stabiliser_order_hist = {0:408}`）。
  つまり軌道長は 8 で一様で、409 個…ではなく 408 = 51×8 = 309 軌道と整合。
- 残った障害: なし（本件は決着）。

# B378 [存在] 8 石極大の一石削除は、削除点以外の合法点をちょうど一つだけ生む

- 判定: **REFUTED**（前回 INCONCLUSIVE → 今回 **REFUTED**）
- 範囲: 8×8 の 8石極大 408 個全件。
- 証拠: 一石削除で新たに合法になる空点数の**最小値**の分布
  `{2:8, 3:8, 4:64, 5:104, 6:88, 7:64, 8:56, 10:16}`。
  **最小値がちょうど 1 の集合は 1 つも存在しない**（`b378.sets_with_min_exactly_one = 0`）。

  その条件を満たす集合が 408 個中に 0 個。したがって**存在命題は偽**。
- 最も弱い弱化版（delmin ≤ 2）の集合は 8 個（`2:8`）存在する。
  しかし命題の閾値は 1 であり、これは満たされない。
- 残った障害: なし（本件は決着）。

# B380 [統計] 8 石極大の探索では被覆数和より一重被覆点の配置が型を分ける

- 判定: **PARTIAL**（前回 INCONCLUSIVE → 今回 **PARTIAL**。母集団は揃ったが「型分裂」は未確認）
- 範囲: 8×8 の 8石極大 408 個（被覆和 `sum_b` でグループ分け）。
- 証拠:
  - 被覆和 `sum_b` の値は 22 種の値を取る（86,88,89,92,…,118）。各値に 8–32 個の集合。
  - グループごとに「一重被覆点(b=1)の辺点数 se / 内部点数 si」を記録した
    （`b380.by_sum_b`）。例えば:
    - `sum_b=88`: 8 個すべてが `se=10, si=25`（**内部優位**）
    - `sum_b=95`: 24 個が `si=5..11, se=15..20`（**辺優位**）
    - `sum_b=116`: 8 個が `se=13, si=3`（**辺集中**）
    - `sum_b=86`: 8 個が `se=16, si=15`（**均衡**）
  - よって被覆和が同じ集合群の**一重被覆点の分布は確かに異なり**（辺集中型・内部集中型・
    均衡型が存在する）、**B380 の記述の前半（被覆和より一重被覆点の配置が型を分ける）は
    観察される**。
  - ただし命題の後半「別々の**局所改良盆地**を作る」は、
    一重被覆点の分布だけから**論理的に導けない**。局所改良（1-swap での移動次数等）を
    別途測る必要があるが、本ランではそれを計算していない。
- 判定の根拠: 統計的母集団（408 個）は揃い、被覆和と一重被覆配置の**対応**は
  データとして確立した。よって「型が被覆和以外の変数で分かれる傾向」は
  SUPPORTED 寄りの観察だが、命題が要求する「局所改良盆地」の測定は
  本ランの範囲外。よって **PARTIAL**。
- 残った障害: 局所改良盆地（1-swap / 1-2swap の安全移動グラフ上の連結成分、
  盆地サイズ）の測定。次の一手。
