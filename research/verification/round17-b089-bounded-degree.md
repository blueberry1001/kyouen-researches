# B089反証: 定数本の低次数代数曲線では漸近最適にならない

作成: 2026-09-29。**B089: REFUTED（一般証明）。**
原文は [仮説バンク](../hypothesis-bank-2026-09-27.md) の
「定数個の二次または三次曲線上の点を選ぶ構成で、K_nとの差がo(n)になる」。

定数本の次数3以下の実代数曲線の和に含まれる安全集合のサイズは、
曲線の係数をnごとに自由に変えてもo(n)である。
一方、任意に大きい素数pについてK_p≥floor((p−1)/4)。
従って両者の差は素数部分列上で少なくともp/4−o(p)となり、o(n)ではない。
仮説K_n≈2n、B088の2n−O(1)構成、有限盤の最適解のいずれにも依存しない。

## 1. 外部から使う一様な格子点数定理

J. Pila, *Density of integer points on plane algebraic curves* の冒頭の定理を用いる。
絶対既約な実平面代数曲線Γの次数をd≥2、軸平行正方形の辺長をN≥2とすると

    #(Γ ∩ Z² ∩ square) ≤ (3d)^(4d+8) N^(1/d) (log N)^(2d+3)。       (1)

この上界は曲線の係数に依存しない。本文§3でも実係数F∈R[x,y]を明記している。
一次資料: [著者公開PDF、冒頭のTheorem](https://people.maths.ox.ac.uk/pila/alcurves.pdf)。
ここで(1)を新しく証明したとは主張せず、適用条件とゲームへの帰結を証明する。

n×n盤は[0,n]²に含まれるので、d=2,3に対して使う上界を

    U₂(n)=6^16 n^(1/2)(log n)^7,
    U₃(n)=9^20 n^(1/3)(log n)^9                            (n≥2)

と置く。どちらもo(n)。係数を固定しなくても同じU₂,U₃が使える点が必要である。

## 2. 可約曲線・直線成分・孤立実点も処理する

各曲線は非零な実多項式の零点集合とする。重複因子を除き、R上の既約因子に分ける。
次数3以下なら、次の全てを尽くす。

1. **実直線因子**。安全集合からは各直線に高々三点しか置けない。
   一つの元曲線には高々三本なので、合計高々九点。
2. **絶対既約な二次因子**。次数の和から高々一個。寄与はU₂(n)以下。
3. **絶対既約な三次因子**。高々一個。寄与はU₃(n)以下。
4. **R上既約だが絶対既約ではない因子**。
   次数3以下では二次のみ。C上で相異なる共役な二直線の積になる。
   実点はその両方に載るので、高々一つ。平行なら実点はない。

最後の分類理由: 共役は複素既約因子を置換する。
R上既約性により一つの共役軌道しかなく、その大きさは1または2。
大きさ2なら全次数は偶数なので、次数3以下では二次だけである。
従って実係数や孤立点を例外扱いして線形個の格子点を隠すことはできない。

よって一曲線上から選べる安全点数は、同時には現れない成分も足して緩く評価すれば

    10+U₂(n)+U₃(n)

以下。r本（rはnによらない固定定数）の曲線の和に含まれる任意の安全S_nは

    |S_n| ≤ r[10+U₂(n)+U₃(n)] = o(n)。                       (2)

曲線どうしの交点の重複は、上界なので数えて構わない。
円成分も二次の場合に含まれ、実際には安全性から高々三点となるが、その改善は不要。

## 3. 素数盤に線形個の安全点を置く明示構成

素数p≥5に対しm=floor((p−1)/4)とし

    S_p={(t, t² mod p): t=1,…,m} ⊂ {0,…,p−1}²。              (3)

第二座標は0以上p−1以下の整数代表を取る。

三つの異なるtについて、共線判定行列式はmod pで

    det[1,t,t²] = ∏_(i<j)(t_j−t_i) ≠ 0。

従ってS_pには三点共線さえない。
四つの異なるt_1<t_2<t_3<t_4について、共円・共線判定行列式はmod pで

    det[1,t,t²,t²+t⁴]
      = det[1,t,t²,t⁴]
      = (t_1+t_2+t_3+t_4) ∏_(i<j)(t_j−t_i)。                (4)

(4)の最後の等式は、左辺が交代多項式なのでVandermonde積で割れ、
商が対称一次式となり、最高次項の係数比較からΣt_iになることによる。
全差はmod pで非零であり、また

    0 < t_1+t_2+t_3+t_4 ≤ 4m ≤ p−1。

従って(4)は非零。整数平面で四点が同一円または直線に載れば、
同じ整数行列式は0になりmod pでも0となるので矛盾する。
これで全ての素数pについて安全性を証明した。m<4の場合も自明に安全。

以上より

    K_p ≥ |S_p| = floor((p−1)/4) ≥ p/4−5/4。                (5)

素数が任意に大きく存在することだけで、B089の反証には十分である。
なおBertrandの定理でn/2<p≤nの素数を選んで埋め込めば、全n≥3にも
K_n≥n/8−5/4を得るが、この強化を反証の必須前提にはしない。

## 4. 原命題との矛盾と、有限体曲線との区別

仮に原文のような固定rと安全S_nがあれば、(2),(5)から素数pに沿って

    liminf_(p→∞, p素数) (K_p−|S_p|)/p ≥ 1/4。

これは差がo(n)という要求と矛盾する。よって**B089は偽**。
曲線の本数がnとともに増える構成や、次数が増える構成は排除していない。

(3)は有限体上では放物線だが、整数代表を取った点集合全体が
実平面の一本の二次曲線に載るわけではない。
各点はy=x²−jpという多数の異なる放物線片に分かれる。
有限体曲線の構成はB089の定数本の実代数曲線とは別であり、(2)と矛盾しない。

同じ議論から、線形個の安全点を次数3以下の曲線で覆うには、素数盤上で
少なくともΩ(p^(1/2)/(log p)^7)本が必要になる。
理由はU₃(p)=o(U₂(p))であり、(2)を本数について解けばよい。
絶対既約三次曲線だけならΩ(p^(2/3)/(log p)^9)本が必要。
