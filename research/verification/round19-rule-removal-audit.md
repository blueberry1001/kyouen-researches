# B522の原文決着とB255の4×4全域不可能証明

作成: 2026-09-30。

- **B253・B522 SUPPORTED**。既存の同じ三禁止解除証人が両方の原文を満たす。
  今回独立に再検証し、4×4の最小反転解除数が正確に3であることも完全計算した。
- **B255 PARTIAL**。原文の「最大サイズ・全最大配置族の保存」を使うと、
  n≤4では勝者反転は不可能。従って存在証人を探す場合はn≥5に限定できる。

原文: [B253・B255](../hypothesis-bank-2026-09-27.md)、
[B522](../hypothesis-bank-round2-2026-09-27.md)。
ユーザーの201件リストは監査候補であり、上の二件が載っていること自体を未決着の証拠にはしない。

## 1. B253の証人はB522もそのまま満たす

4×4盤、座標0,…,3で、標準禁止族194組から次の三組だけを解除する。

    e₁={(3,0),(1,1),(1,2),(2,3)}
    e₂={(0,1),(1,1),(0,2),(1,2)}
    e₃={(2,1),(3,1),(1,2),(1,3)}

この証人は [既存B253個票](round5-batch-b251-b270.md) と
`round5_b251a_triples4fast.json` に保存されていたもの。新発見として数えない。
ところが別のB522個票には三組の証人が未発見という古い記録が残っていた。
原文B522は「4×4の三つの禁止解除で勝者が反転する」という存在命題なので、同じ証人で決着する。

今回は全8部分族を、共円・共線判定から再生成した禁止族とmexによる状態DPで独立に計算した。

| 解除する組 | 空盤の真のg | 最大サイズ | 最大配置数 |
|---|---:|---:|---:|
| なし | 0 | 7 | 64 |
| e₁ | 0 | 7 | 70 |
| e₂ | 0 | 7 | 70 |
| e₃ | 0 | 7 | 72 |
| e₁,e₂ | 0 | 7 | 78 |
| e₁,e₃ | 0 | 7 | 78 |
| e₂,e₃ | 0 | 7 | 78 |
| e₁,e₂,e₃ | **2** | 7 | 86 |

従って全ての真部分族では勝者が変わらず、三組全体で初めて先手勝ちとなる。
標準版と三組解除版のgは、署名を用いない四点包含判定と再帰mexでも再確認した。
既存 `round5_b251a.cpp` は勝敗だけを返す `solve_n4_fast` の値を `g0_triple=1` と出力していた。
その1は先手勝ちのフラグであり、真のGrundy値とは区別する。勝者反転の結論は変わらない。

さらに標準194組の全単独解除194通り、全二組解除18,721通りを、
D4対称性による39軌道・2,554軌道に縮約して全て厳密に解いた。
いずれも空盤Pで、標準盤との反転はない。軌道サイズの総和も全通り数に一致する。
従って

    δ_quad(4×4)=3。

これは「包含極小」だけの主張でなく、**基数最小**の確定である。
なお上の最小族の共通部分は{(1,2)}の一点なので、共有三点を要求するB523にも反例となる。

## 2. B255では「最大」と「極大」を区別する

B255の原文は「最大サイズ・全最大配置族が標準版と一致するのに勝者が反転する」。
従前の `round5_b251a_b255_witness.json` は全極大集合（追加不能な集合）928個と900個を比較していた。
原文に必要なのはサイズK₄=7の**最大**集合であり、その数は64個と86個である。
この三組解除証人は原文の最大配置族も保存しないため、B255の証人にはならない。

以下では正しい「最大」の意味を使い、全ての禁止解除族について4×4での不可能性を示す。

## 3. 全最大配置を保存するなら152組は解除できない

Qを標準禁止族、σ(A)={q∈Q:q⊆A}とする。
7点集合Aが標準では禁止組qをちょうど一つだけ含む、すなわちσ(A)={q}とする。
qを解除するとAは必ず安全になる。最大サイズが7のままなら新しい最大配置が増え、
それより大きくなる場合は最大サイズが変わる。いずれもB255の保存条件に反する。
従ってそのようなqは、最大サイズと全最大配置族を保存する全ての解除族で保持される。

全7点集合を整数計算で調べると、この単独禁止証人を持つqは**152組**ある。
各qに対する具体的な7点集合をJSONに保存した。
よってB255の候補解除族Eは、残りの42組からなる集合Oの部分族でなければならない。

これは必要条件だけだが、次の節はOの**任意の部分族**について勝者が変わらないと証明する。
最大配置を保存する部分族だけを探し直す必要はない。

## 4. 42組の任意の解除に勝つ共通の後手戦略

固定したE⊆Oに対して、状態Aが合法である条件はσ(A)⊆E。
先手にはOを全て解除した盤で可能な全ての着手を許す一方、
後手は「σ(A+p)=σ(A)」となる着手だけを選ぶことにする。
その後手の着手は、新しい禁止組の解除を一つも必要としないので、
現在の状態が合法な任意のEについて必ず合法である。

この制限付きの後手戦略が勝てることを、次の有限DAG上の再帰で証明した。
Fは保持が必要な152組とし、状態集合を

    Ω={A:σ(A)∩F=∅}

とする。これが先手に許す全状態6,925個である。
D(A)は後手の手番で確実に勝てること、O(A)は先手の手番で後手が確実に勝てることを表す。
空の選言は偽、空の連言は真として

    D(A) = OR  O(A+p)  [p∉A, A+p∈Ω, σ(A+p)=σ(A)],
    O(A) = AND D(A+p)  [p∉A, A+p∈Ω]。

毎手一石増えるので後ろから完全に計算でき、**O(∅)=真**が得られた。
D(A)を真にする着手を一つずつ選んだ戦略では、先手の全可能応答を展開して
到達する状態は1,333個、後手の指定着手は849個である。
この指定着手表を保存し、別の検査関数が四点の包含を直接計算して
全先手応答と全後手着手の条件を再検証した。

固定Eで先手が打てる手は、上の先手に許した手の部分集合である。
後手の指定着手はどの固定Eでも合法なので、この証明書は全E⊆Oに対して勝つ。
従って**2^42通り全て**の禁止解除に対し後手勝ちを保証する。
全解除族を標本抽出して勝敗が変わらなかった、という統計結果ではない。

第3節と合わせ、4×4で全最大配置を保存して勝者を変えることは不可能。□

## 5. 小さい盤と残る範囲

- n=1は解除できる禁止組がない。
- n=2は唯一の禁止組を解除すると最大サイズが3から4へ変わる。
- n=3は全14禁止組のそれぞれに、サイズK₃=5でその禁止組だけを含む集合がある。
  よって第3節と同じ理由で、一組も解除できない。

従ってB255の存在証人は、あるとすれば**n≥5**。
原文全体をREFUTEDとしたわけではない。次は5×5で単独禁止を持つ9点集合から
保持必須の禁止組を求め、残った禁止組に対して同じ共通戦略が成り立つかを調べられる。
