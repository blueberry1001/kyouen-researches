# Batch 04: B061-B080

対象: 二点競合グラフと高階制約の効き方 (B061-B070)、禁止点の重複被覆と三つ組の幾何 (B071-B080)。
スクリプト: `research/verification/scripts/batch04_geom.py`, `batch04_graph.py`
データ: `research/verification/batch04_geom.json`, `batch04_graph.json`

記号: `b_S(p)` = 空点 p を禁止する S 内 3 点集合の個数。`P(S)` = L(S) 上の 2 点残余制約からなる競合グラフ。2 点制約のみのゲーム = P(S) の独立集合ゲーム（端点の両方を占めない）。

## B061 [統計] P(S)に三角形が多い局面はnimberが小さい

- 判定: **REFUTED**
- 範囲: n=2..5 の安全集合（n=5 は 1/2 サンプル、計 75,697 局面）。k 固定層内で三角形密度と g の Spearman 相関。
- 証拠: 仮説は「負に結びつく」だが、実測は主に**正**。n=4 k=3 で ρ(dens,g)=+0.50、k=5 で +0.52、n=5 k=6 で +0.47、k=5 で +0.28（`batch04_graph.json` boards.*.b061_within_k）。g>0 の局面の平均三角形数は g=0 より大きい層が多い（n=4 k=3: 46.4 vs 24.0、k=5: 7.1 vs 0.14）。n=5 の k=2,3 ではわずかに負（-0.09, -0.18）で方向は層依存。
- メモ: 「三角形同士が潰し合う」着想の符号が逆。k 固定しても正相関の層が支配的。母集団が n≤5 のため一般則としての棄却だが、主張どおりの負相関は再現せず。

## B062 [全称・大胆] 三石局面のP(S)の彩色数は3以下

- 判定: **REFUTED**
- 範囲: n=2..4 の全 3 石安全集合（n=4 では 560 全件を正確に彩色判定）。n=5 は頂点数 22 で厳密彩色を打ち切り（未判定扱い）。
- 証拠: 反例 4×4、S={0,1,2}（id=y*4+x）。P(S) は頂点 12、辺 31、次数列 (8,7,7,6,6,5,5,5,3,2,2,2) 程度。正確彩色で **χ>3**。独立再検でも 3-colorable=false（4-colorable も false で greedy=6、χ≥5 の可能性）。4×4 の 3 石 560 件中 **224 件が χ>3**（`batch04_graph.json` boards.4x4.chrom_stats）。n=2,3 では χ≤3 が成立（3×3 は 84 件すべて χ≤3）。
- メモ: 大胆予想どおり 4 石前から壊れるのではなく、**4×4 の 3 石ですでに反例**。B063 と対照的（表現能力の階層は石数より盤サイズでも壊れる）。

## B063 [構造] 四石以降で初めて現れる競合グラフの最小型がある

- 判定: **INCONCLUSIVE**
- 範囲: n=2..5 の P(S) を (nv, ne, 次数列, 三角形数, 木か) の型で棚卸し。k=3 と k=4 の型集合の差を確認。
- 証拠: 型レベルでは k=4 のみに現れるものは多数（3×3 で 5 型、4×4 で 166 型のうち k3 にないもの、5×5 で 1510 型）。ただし型は同型判定ではなく、**誘導部分グラフとしての最小 H** は特定できていない。k=3 の P(S) は盤が大きいと稠密になり（4×4 で nv=13, ne=31）、K4 などの小 H を誘導部分に含む可能性が高い。全盤の 3 石に現れない H の証明には次数・円幾何からの構造制約が必要。
- メモ: 型差から「k=4 で新規な全体グラフ」は言えるが、誘導部分グラフ版は未証明。B062 の反例（3 石で χ>3）と整合するため、石数 3 での強い彩色制約はすでに崩れている。

## B064 [存在] P(S)が木でも高階制約が勝敗を変える

- 判定: **SUPPORTED**
- 範囲: n=2..5。P(S) が木で頂点数≤12 の局面について、2 点制約のみのゲーム値 g2 と実値 g(S) を比較。
- 証拠: 反例多数（n=3 で 8 件、n=4 で 16 件、n=5 サンプルで 178 件）。最小例: 3×3、S={0,1,6}、P(S) は木（nv=5, ne=4）、残余 3 点制約 res3=3、g_actual=0 に対し g_2pt_only=3。つまり 2 点競合だけでは N 局面（g=3）に見えるが、実際は P 局面。`batch04_graph.json` b064。
- メモ: 木の P(S) でも高階制約が勝敗を動かす。B065 と合わせて「P(S) は勝敗の十分な不変量ではない」。

## B065 [存在] P(S)が空でも高nimberを持つ

- 判定: **INCONCLUSIVE**
- 範囲: n=2..5 の全（またはサンプル）安全集合で P(S) が辺 0 かつ g(S)≥4 を探索。
- 証拠: **該当 0 件**。P(S) 空の局面は多く存在するが g は 0-2 に収まる例ばかり。n=5 の最大 nimber は 6（既知）なので g≥4 の局面自体は存在するが、そのとき P(S) に必ず辺があるかは未確認。
- メモ: 非存在の証明には「P(S) 空 ⇒ 残余は 3 点以上のみ ⇒ ゲーム値の上限」の解析が要る。検索はしたが証人も反例もなし。

## B066 [統計] 二点競合の近似が外れるのは高階制約の重なりが大きい場所

- 判定: **PARTIAL**
- 範囲: n=2..5。2 点制約のみの P/N と実値 g の不一致率を、残余 3 点制約の個数・2 点共有率と比較。
- 証拠: 不一致 (err) 局面は残余 3 点制約が**多い**（n=4: 平均 19.8 vs 正常 4.4、n=5: 12.9 vs 3.8）。この方向は仮説と整合。ただし「3 点辺どうしの 2 点共有数」の比率は err 側が**低い**（n=4: 0.37 vs 0.51、n=5: 0.38 vs 0.44）。`batch04_graph.json` b066。
- メモ: 「高階制約が多いと近似が外れる」は支持、「2 点共有で説明できる」は符号が逆または測度が不適切。共有ペア数の絶対数や 3 点制約の交差グラフ次数などへの測度変更が必要。

## B067 [全称・大胆] 終盤のP(S)には大きな誘導奇サイクルがない

- 判定: **INCONCLUSIVE**
- 範囲: n=2..5 で K(S)−|S|≤3 の局面の P(S) に長さ≥7 の誘導奇サイクルがないか検査。ただし**K(S) 計算にバグ**（追加候補を id>max(S) に限定）があり、初回の「反例 8 件」は信頼できない。
- 証拠: 初回実行で n=4 に K−|S|≤3 かつ誘導 7 係数の報告 8 件（例: S={0,6,7,9}, nv=8, 報告 K=6）。しかし同じ S で K=4 なのに nv=8 という矛盾（合法手があるなら K≥|S|+1）があり、K が過小評価されている。K 修正版は打ち切りのため未再実行。n=2,3 では違反なし。
- メモ: `K_of` は空点全体から追加可能な全点を列挙するよう修正が必要（`batch04_followup.py` に修正版 `K_of_fixed` あり、未実行）。修正後の再計算が次の一手。

## B068 [存在] 同じP(S)の次数列・スペクトルでも勝敗が違う

- 判定: **SUPPORTED**
- 範囲: n=2..5。高階残余（サイズ3-4）を持たない局面に限定し、P(S) の次数列が同じで g の零非零が違う組を探索。

## B069 [統計] 競合グラフのseparatorが小さい局面は戦略を分割できる

- 判定: **INCONCLUSIVE**
- 範囲: n=2..5 サンプルで最小被覆数 vc（separator の代理）と局面の関係を記述。証明長は測定していない。
- 証拠: vc≤1 の局面は |L| が小さく（n=4 で平均 1.70）、vc≥3 は |L| 大（6.94）。vc≤1 のほうが LOSS 率は低い（n=3: 0.14 vs 0.65、n=4: 0.11 vs 0.27）。「separator が小さいほど戦略を分割できる」は証明長の計測なしでは判定不能。`batch04_graph.json` b069。
- メモ: 命題の本体は「小さな勝敗証明」で、証明サイズの定義（探索木の節点数など）が必要。代理測定のみで方向は不明。

## B070 [構造] 実現できる競合グラフには有限の小さい禁止型がある

- 判定: **INCONCLUSIVE**
- 範囲: n=2..5 の k=0..5 に対する P(S) の型インベントリ（nv 範囲、木の個数、三角形自由、最大三角形数）。
- 証拠: k ごとの型数は n とともに爆発（5×5 で k=5 が 3594 型）。k 固定で n を変えたときの共通禁止誘導部分グラフは特定できず。三角形自由な P(S) も稠密な P(S) も両方実現。`batch04_graph.json` b070。
- メモ: 「三角形の有無だけではない」制約の候補としては彩色数（B062 が 3 で失敗）や奇サイクル長（B067）があるが、どちらも未確立。固定 k で n→∞ の P(S) の極限制約は構造論の課題。

## B071 [全称] 一つの禁止点を作る三つ組族は線形

- 判定: **SUPPORTED**（証明付き）
- 範囲: 幾何証明 + n=2..5 の全安全 S・全空点 p（計 157,518 安全集合）+ n=6 の極大 464 集合（K=11, `maxsafe_n6_K11.bin`）の全検査。
- 証拠: **証明**: p を禁止する二つの 3 点集合 T1={a,b,c}, T2={a,b,d} が 2 点共有する場合、{a,b,p} が非共線なら円が一意で c,d が同じ円上 → {a,b,c,d}⊂S が共円で S が安全でない。{a,b,p} が共線なら {a,b,c,p} の det=0 は 4 点共線を強制し、やはり {a,b,c,d} が共線で矛盾。計算: 違反 **0 件**（n=2..5 全安全集合、n=6 極大 464）。`batch04_geom.json` 各 board の b071_violations。
- メモ: 定理として成立。三つ組被覆は線形 3 部分集合ハイパーグラフ。B072 の前提。

## B072 [全称] 点ごとの被覆重複には二次上限がある

- 判定: **SUPPORTED**（証明付き）
- 範囲: 同上（n=2..5 全安全 + n=6 極大 464）。
- 証拠: B071 より、p を禁止する三つ組族は線形（どの 2 つも 1 点以下しか共有しない）。各三つ組は |S| に 3 つの点対を消費し、点対は高々 1 つの三つ組にしか属さない。よって `3 b_S(p) ≤ C(|S|,2)`、すなわち `b_S(p) ≤ floor(|S|(|S|−1)/6)`。計算: 違反 **0 件**。最大の b_S(p) は n=6 の k=11 で b=10（二次上限 18）。`batch04_geom.json`。
- メモ: 等号は Steiner 三つ組系。B073 参照。

## B073 [存在] B072に等号を達成する非自明な配置

- 判定: **REFUTED**
- 範囲: 幾何論証 + n=2..5 全安全集合（k≥7 で k≡1,3 mod 6）と n=6 極大 464 の等号探索。
- 証拠: **論証**: p からの反転（inversion）は p を通る円/直線を直線に写す。b_S(p) の等号達成は「反転後の S の点集合で、どの点対も直線上にちょうどもう 1 点を持つ」= 通常直線が存在しないこと。これは Sylvester–Gallai の定理（ℝ² の有限点集合で全共線でなければ 2 点のみを通る直線が存在する）と矛盾。|S|≥7 の STS(7)（Fano）は ℝ 上で直線配置に実現できない（古典的事実）。計算: 等号ヒット **0 件**（n=4 で k=7 が存在するが不達成、n=5 で k=7,9 不達成）。`batch04_geom.json` boards.*.b072_eq_hits_kge7。
- メモ: B074 への影響大。等号（二次達成）は ℝ 幾何で不可能。オーチャード（orchard）問題の最大三本線数 t_3(k) が自然な上限。

## B074 [全称・大胆] 幾何によりB072より厳しい線形上限がある

- 判定: **INCONCLUSIVE**
- 範囲: n=2..5 全安全 + n=6 極大 464 での max b_S(p)/|S| の測定。理論的考察（オーチャード問題）。
- 証拠: 測定された最大比: 0.333 (n=2), 0.40 (n=3), 0.714 (n=4), 0.75 (n=5), **0.909** (n=6, k=11, b=10)。線形則 `b≤C|S|` に対して小盤では C=1 で足りる。一方 B073 の反転論証より b_S(p) は反転点集合の「3 本線数」= オーチャード数 t_3(k) であり、ℝ² では t_3(k)=Θ(k²) まで達成可能なことが知られる（等号 Steiner は不可でも二次的構成は存在）。格子点に制限されると二次構成が実現できるかは未解決。`batch04_geom.json` b074。
- メモ: 大胆版（絶対定数 C）は反転 + オーチャード構成が格子実現できれば**棄却**される。k=11 で比 0.91 は C≥1 を要求。B073 の棄却と整合する方向は「二次には近づくが等号は打てない」。

## B075 [全称] 二つの三つ組補完集合の重複は小さい

- 判定: **SUPPORTED**（証明付き）
- 範囲: 幾何証明 + n=2..5 の全 3 点組対（補完集合非空で、T∪U が安全なもの）+ n=6 でも同型の論証。
- 証拠: **証明**: T, U の補完集合はそれぞれ T（U）を通る円または直線上の格子点。二つの円/直線が異なるなら交点は高々 2。同一の円/直線上なら |S∩C|≥|T∪U|≥4 となり S が安全でない。したがって安全 S 内の異なる 3 点組は共通補完点が高々 2。計算: n=2..5 の全対で違反 **0 件**（`b075_violations` 空、max_common を記録）。T∪U が安全な対に限定した検査で、同円の場合は安全条件により自動的に除外。
- メモ: 包除原理への応用可能。B071 と合わせて被覆の線形性の基盤。

## B076 [統計] 最小極大配置は被覆の重複が少ない

- 判定: **SUPPORTED**
- 範囲: n=2..5 の全極大安全集合（4+56+928+16,860 件）について、サイズ別に平均 b_S(p) を比較。
- 証拠: 平均 b はサイズの増加とともに単調に大きい（小さい極大のほうが被覆が薄い）。
  - 4×4: k=5 → 1.24、k=6 → 1.86、k=7 → 3.11
  - 5×5: k=5 → 1.15、k=6 → 1.52、k=7 → 2.01、k=8 → 2.89、k=9 → 4.18
  単調性、サイズ間の平均差はいずれも期待どおり。`batch04_geom.json` b076_summary。
- メモ: 「少ない石で重複を避けて全面を塞ぐ」という予想の方向と一致。n=6 極大（k=11 のみ）は比較対象サイズがないため対象外。

## B079 [構造] 六石非存在は三つ組の共起だけで短く説明できる

- 判定: **NOT-CHECKED**
- 範囲: 10×10 で安全 6 点集合が全面（94 空点）を塞げないという事実（s_10≥7, 発見記録 F-BE）を、三つ組補完数と交差制約の有限個の不等式で示せるかどうか。
- 証拠: 初等的計数だけでは閉じない。Σ_p b_S(p) = Σ_{T⊂S,|T|=3} |compl(T)| ≥ 94 が必要だが、|S|=6 の三つ組は高々 20、各 compl(T) の上限（円上の格子点数、F-Z より 4τ(m) 程度）では 20×O(10) が 94 を上回り、重複制約（B071, B075）を組み合わせても有限不等式系の探索は実施せず。時間内に証明候補の不等式系を構成できず。
- メモ: B071/B075 の線形性は使える。次は (a) 各三つ組の |compl(T)| の 10×10 での最大を計算し、(b) 6 点のどの点対が何個の三つ組に属するかの組合せ不等式を敷く。組合せ設計論の「被覆数」の下限評価が定石。
