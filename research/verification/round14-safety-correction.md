# B480: 閾値尺度の安全確率の第一補正と、Poisson誤差率の鋭さ

作成: 2026-09-29。原文: [B478–B480](../hypothesis-bank-round2-2026-09-27.md)。
前提となる一般評価: [round13-poisson-limit.md](round13-poisson-limit.md)。

**B480 SUPPORTED（閾値尺度における一様な剰余評価付き）。**
round13で未解決だった「固定nの形式展開から、nと密度の同時極限への移行」を解決する。
同時に、B478の禁止四点数のPoisson近似誤差は **Θ(n^(−1/4))** と鋭いことを示す。
異なる円・直線の相互作用を評価する際は、同じ一般化円上の全違反を一つの事象にまとめる。

## 1. 定義と主結果

V_n={0,…,n−1}²、N=n²。共線または非共線共円な四点集合を禁止辺と呼び、
その総数をF_nとする。G_rは同じ円または直線に載るr点集合の総数（r≥4）で、G_4=F_n。
禁止四点数をZ、円・直線のうち選択点を4点以上含むものの数をWとする。
「安全」はZ=0と同値であり、W=0とも同値である。
全変動距離は `d_TV(P,Q)=sup_A |P(A)−Q(A)|` の規約を使う。

以下、誤差定数は密度尺度の上下定数に依存してよい。

### 独立占有モデル

各点を独立に確率pで選び、p=Θ(n^(−5/4))とする。任意のε>0について

    log Pr(安全) = −F_n p^4 + 4G_5 p^5 + O_ε(n^(−1/2+ε)).             (1)

さらに c_5=ζ(3)/(45ζ(4)) とすると

    G_5 = c_5 n^6 + O_ε(n^(5+ε)).                                    (2)

従ってp=a n^(−5/4)、aが(0,∞)の固定コンパクト区間を動く場合

    log Pr(安全) = −F_n p^4 + 4c_5 a^5 n^(−1/4)
                  + O_ε(n^(−1/2+ε)).                               (3)

### 一様k点モデル

k=Θ(n^(3/4))、λ_n=F_n(k)_4/(N)_4=E Zとする。このとき

    log Pr(安全) = −λ_n + 4G_5(k/N)^5 + O(n^(−3/8))
                = −λ_n + [4ζ(3)/(45ζ(4))] k^5/n^4 + O(n^(−3/8)).     (4)

第一補正は正で、大きさはΘ(n^(−1/4))。三点共有の禁止辺対数A_3は10G_5なので、
第一補正は `(2/5) A_3 (k/N)^5` とも書ける。
ペアのみの包含排除では係数を過大に数える。同じ五点上の5辺を全てまとめた係数が2/5である。
主項F_nまたはλ_nは有限nでの正確な値を保持する。これを極限定数に置換した際の誤差は別に扱う。

## 2. 外部入力と既証の補題

Ghosal–Goenka–Keevash (2026),
[*On Subsets of Lattice Cubes Avoiding Affine and Spherical Degeneracies*](https://link.springer.com/article/10.1007/s00454-026-00853-7)
のTheorem 1.3からF_n=Θ(n^5)を使う（共線分は同論文Proposition A.3）。
同命題でr=5とし、順序付きの数を5!で割ると、共線五点集合数は

    D_5 = ζ(3)/(45ζ(4)) n^6 + O(n^5 log n).                          (5)

これらの数え上げ定理は既知の外部結果であり、ここでの新しい導出とは区別する。

round13 §2で証明済みの共次数評価を使う。j点集合Tを含む禁止辺数をd_j(T)、その最大をΔ_jとすると

    Δ_1=O(n^3),   Δ_2=O_ε(n^(2+ε)),   Σ_T d_j(T)=binom(4,j)F_n.      (6)

同節の整数円の補題より、盤内3点で定まる円の完全整数点数はO_ε(n^ε)。
従って共円五点数は、各円の四点寄与の高々O_ε(n^ε)倍で、O_ε(n^(5+ε))。
これと(5)を合わせると(2)が従う。**五点直線束が第一補正の全ての主要部を与える。**

以下のPoisson近似では、Arratia–Goldstein–Gordon (1989),
[*Two Moments Suffice for Poisson Approximations*](https://dornsife.usc.edu/larry-goldstein/wp-content/uploads/sites/221/2023/06/AGG.pdf#page=12)
のLemma 1（雑誌p.20、PDF第12頁）のStein方程式の評価だけを外部入力とする。
指示関数hについて解fは `||Δf||≤(1−exp(−Λ))/Λ≤1` を満たす。
共分散への帰着と必要な結合は次節で明示的に証明する。

## 3. 違反を含む円・直線のPoisson近似

盤内に4点以上を持つ全ての円・直線の族をC_nとする。
各Cの盤との交点数をm_Cとする（完全な無限直線の点数ではない）。
相異なるC,Dは高々2点で交わる。またm_C≤2n。

I_Cを「C上で少なくとも4点選ばれた」ことの指示変数、
q_C=Pr(Bin(m_C,p)≥4)、W=Σ_C I_C、Λ=E W=Σ_C q_Cとする。
q_C≤binom(m_C,4)p^4だから、Λ≤F_n p^4=O(1)。

### 3.1 単調な条件付き結合

各Cごとに、独立占有集合Xと条件付き集合X^C（I_C=1を条件とした分布）を、X⊆X^Cとなるよう結合する。
Cの外は変更しない。C内は一様ランダム順序と一様U∈(0,1)を用い、
K~Bin(m_C,p)とK'~Law(K|K≥4)をその分位点関数で結合する。
K'≥Kなので、最初のK点と最初のK'点が望む結合を与える。
各I_Dは占有点に関して単調なので、W^C≥WかつI_C^C=1。

J_C=W^C−W≥0とおく。I_C=0ならJ_C≥1、I_C=1ならJ_C≥0であるから

    |1−J_C| ≤ J_C−1+2I_C.

Stein方程式と `E[I_C f(W)]=q_C E[f(W^C)]` により

    |E h(W)−E h(Poisson(Λ))|
      ≤ ||Δf|| Σ_C q_C E|W+1−W^C|
      ≤ ||Δf|| [Var(W)−Λ+2Σ_C q_C^2]
      = ||Δf|| [Σ_C q_C^2 + Σ_(C≠D) Cov(I_C,I_D)].                  (7)

和Σ_(C≠D)は順序付き。この計算に一般的な正の関連性定理は必要ない。
条件付き期待値から `Σ_C q_C E(W^C−W)=Var(W)` を用いた。

### 3.2 一点・二点の共有による共分散

t=|C∩D∩V_n|≤2とする。共有点を固定するとCとDの残りの占有は独立。
共有Bernoulli変数の中心化積による展開の直交性から、厳密に

    Cov(I_C,I_D)= t p(1−p) a_m a_l
                 + 1_(t=2) [p(1−p)]^2 b_m b_l,                  (8)

ただしm=m_C,l=m_Dで

    a_m=Pr(Bin(m−1,p)=3),
    b_m=Pr(Bin(m−2,p)=2)−Pr(Bin(m−2,p)=3).

例えば二点共有なら、条件付き確率を
`q_C+a_m[(X_1−p)+(X_2−p)]+b_m(X_1−p)(X_2−p)`
と展開すれば(8)が直接分かる。一点共有も同様。

nが十分大きければ全Cについてm_C p≤1なので

    0≤a_m≤binom(m−1,3)p^3,
    |b_m|≤2 binom(m−2,2)p^2.

ここで全曲線にわたる局所和は、禁止辺の共次数そのものである:

    Σ_(C∋v) binom(m_C−1,3)=d_1({v}),
    Σ_(C⊃T) binom(m_C−2,2)=d_2(T)       (|T|=2).

これらと(8)から

    Σ_(C≠D) |Cov(I_C,I_D)|
      ≤ p^7 Σ_v d_1(v)^2 + 4p^6 Σ_(|T|=2) d_2(T)^2
      ≤ 4F_n Δ_1 p^7 + 24F_n Δ_2 p^6
      = O_ε(n^(−3/4)+n^(−1/2+ε)).                                  (9)

対角を加えて上から抑えたため、交わらない曲線を誤って独立とみなす省略はない。
最大q_C≤binom(2n,4)p^4=O(n^−1)、Λ=O(1)からΣq_C²=O(n^−1)。
(7)–(9)により

    d_TV(Law(W),Poisson(Λ))=O_ε(n^(−1/2+ε)).                       (10)

同じ一般化円内の束をまとめた数Wは、四点違反数Zより速くPoisson分布へ近づく。

## 4. Poisson平均Λの一様展開

二項分布の裾の厳密な多項式表示は

    q_m=Σ_(r=4)^m (−1)^(r−4) binom(r−1,3) binom(m,r)p^r.

従って先頭はbinom(m,4)p^4−4binom(m,5)p^5。
mp≤1、m≥6の場合、r=s+6の項を基準項binom(m,6)p^6と比較すると

    binom(r−1,3) binom(m,r)p^r / [binom(m,6)p^6]
      ≤ 120 (mp)^s / [(s+6)(s+2)!] ≤ 20/(s+2)!.

Σ_(s≥0)1/(s+2)!<1より、剰余の絶対値は20binom(m,6)p^6以下。
m<6なら剰余は0。全曲線について足し合わせて

    Λ=F_n p^4−4G_5 p^5+O(G_6 p^6).

m_C≤2nから `binom(m_C,6)≤O(n²)binom(m_C,4)`。
G_6=O(n²F_n)=O(n^7)なのでG_6p^6=O(n^−1/2)。

(10)とW=0⇔安全から `Pr(安全)=exp(−Λ)+O_ε(n^(−1/2+ε))`。
Λ=O(1)でexp(−Λ)は0から離れるため、対数を取っても同じ誤差率を保つ。
これで(1)と(3)を得る。巨大な禁止辺部分族の包含排除を形式的に打ち切ってはいない。

## 5. 固定kへの移行

round13 §4の同一ランダム順序による結合を用いる。p=k/N、M~Bin(N,p)とし、
最初のk点と最初のM点の禁止数をZ_k,Z_Mとすると

    Pr(Z_k≠Z_M)≤E|Z_k−Z_M|=O(k^(−1/2))=O(n^(−3/8)).

安全確率の差にも同じ上界が使える。どちらも0から離れるので、対数の差も同程度。
`F_n(k/N)^4−λ_n=O(1/k)=O(n^(−3/4))` であり、(1)にε<1/8を選べば(4)の第一式を得る。
(2)のG_5の誤差は `O_ε(n^(5+ε)(k/N)^5)=O_ε(n^(−5/4+ε))`。
これはn^(−3/8)より小さいので、(4)の第二式も従う。
G_5(k/N)^5をG_5(k)_5/(N)_5へ置き換える差はO(n^−1)で、同じ誤差内である。

## 6. 禁止四点数のPoisson近似率は最適

独立占有ではμ_n=F_n p^4、一様k点ではμ_n=λ_nとする。
いずれもμ_nは(0,∞)の固定コンパクト区間内にある。
(1)または(4)と、G_5p^5=Θ(n^(−1/4))から

    Pr(Z=0)−exp(−μ_n)
      = exp(−μ_n)·4G_5p^5 + o(n^(−1/4)) > 0

が十分大きいnで成り立つ。よって

    d_TV(Law(Z),Poisson(μ_n)) ≥ |Pr(Z=0)−exp(−μ_n)|
                              = Ω(n^(−1/4)).

round13の上界O(n^(−1/4))と合わせて、**Θ(n^(−1/4))**。
これはPoisson極限（B478）を否定しない。束の確率は0に向かうが、その消える速度が近似誤差を決める。
