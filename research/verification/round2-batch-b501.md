# Round2 Batch B501–B530: 統計の符号 + 削除耐性

対象: `research/hypothesis-bank-round2-2026-09-27.md` の B501–B530 のみ。
データ: `research/verification/round2_b501.json`
スクリプト: `scripts/round2_b501_rand.py`, `scripts/round2_b501_del.py`,

## 検証で使った母集団（統計仮説）

- **p_rand**: 「到達可能な安全局面すべて」（n=2:15, n=3:298, n=4:5811）。
  定義は `p_rand(occ) = E[1 − p_rand(child)]`、子は合法手一様、終端で 0。
  抽出ではなく完全 DP。
- **B509**: 同じ n で「負け手が 2 つ以上ある N 局面」2202 個（n=4）。
  グループ固定 (n,k,|L|,|W|) は補助、主検定はプール Pearson と組内順位一致率。
- **削除耐性**: n=3,4 の全 1 点・全 2 点・全 3 点、n=5 の 1 点は batch-09 継承。
- **禁止四点解除**: 4×4 の F=194（直線 10 / 真円 184）。
  単独 194、ペア 878（共有 3 点ペア全部 + 無害単独の標本）、
  共有 3 点トリプル 120、束（同一線・同一円の全四点）5。

n=2,3 は parity locking（g∈{0,1}、p_rand∈{0,1}）のため統計が退化する。
p_rand の非自明な議論は n=4 が実質的な最小盤。

## B501 [全称・大胆] 標準盤のP局面のランダム勝率は2/3以下

- 判定: **SUPPORTED**（n≤4 の全 P 局面）
- 範囲: n=2,3,4 の到達可能局面すべてを完全 DP で p_rand 計算。n=4 の P 局面 1825 個。
- 証拠: n=4 の P 局面 p_rand の最大は **0.5629629629…**（=76/135、k=4, max_rem=3）。
  2/3 超えは 0 件。n=2,3 は p_rand が {0,1} に退化し、P は常に 0。
  空盤 (4×4) は g=0、p_rand=**0.3018756222…**（後手有利だが 2/3 以下）。
- メモ: 競合 B502 の側から 3/4 超えも不発。2/3 という束は n=4 では 0.563 まで
  しか張られておらず、束自体は緩い。n=5 で最大がどうなるかが次の数字。
  **n=5 の完全 p_rand は 180s 超で打ち切り（NOT-CHECKED）**。

## B502 [存在] P局面でランダム勝率3/4を超えられる

  「約 1/11」という率は盤サイズに強く依存する。率を固定した命題としては

## B516 [構造] 4×4の勝者反転12ペアは二つの幾何条件で分類できる

- 判定: **SUPPORTED**（種別 + マンハッタン距離で 12 組が層化される）
- 範囲: 12 組の両端を corner / edge / inner に分類し、距離 d=|dx|+|dy| を記録。
- 証拠: 種別ペアのヒストグラムは
  `(corner,corner)=4, (corner,inner)=4, (inner,inner)=4`。
  距離は `d=1:4, d=3:4, d=4:4`。edge を含む組は **0**。
  したがって「両端の種別組み合わせ」と「マンハッタン距離」の 2 量で
  3×4 のブロックに均等に割れる。個別 12 列挙なしで記述可能。
- メモ: edge を含む反転ペアが無いことは強い制約。次の仮説は
  「反転ペアは両端がともに頂点またはともに内部」という形で言える。

### 競合ペア B501 / B502

- B501（P の p_rand≤2/3）は n≤4 の全 P 局面で成立（最大 0.56296…）。
- B502（P で 3/4 超え）は n≤4 で証人なし。
- 両者は真に競合していない（0.563 < 2/3 < 3/4）。B502 が n≥5 で
  成立すれば B501 も同時に壊れる。次は n=5 の P 局面 p_rand の最大。
