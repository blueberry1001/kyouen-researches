## B381 [全称] 7×7の16最大配置のr(S)はすべて2

- 判定: **SUPPORTED**
- 範囲: 全16最大配置について、整数平面上で外接矩形 [0,6]² からの Chebyshev 距離 1〜3 の外点を全走査し、追加可能な最小距離を計算。
- 証拠: **16/16 で r=2**。距離1の外点は全埋め込み（B087）で追加不能と確認済み。距離2で各配置とも1〜2個の合法外点が存在（例: n7[0] は (8,1) など1個、n7[1] は2個）。`round2_b381.json` → `summary.n7_r_dist = {2: 16}`。
- メモ: B087（8×8 へ1石も足せない）の自然な続きとして、整数平面なら2層目で必ず逃げ道がある。

## B382 [構造] 7×7最大配置の最初の合法外点はD4軌道で少数型

- 判定: **PARTIAL**
- 範囲: 全16配置の距離2合法外点の位置を、外接矩形からの相対位置（辺・角、dx,dy）で分類。
- 証拠: A相 8個は各1個の合法外点を持ち、すべて角型（RT:1,2 / LT:2,1 など 8種類）。B相 8個は各2個（辺型+角型、例: R:2,0 + RB:2,2）。構造は規則的（A=角1個、B=辺1+角1）だが、「半径2の固定した短いパターン」というより位置の多様性がある（全16種類の位置型）。
- メモ: A/B の違いは明確。位置型の完全分類は D4 軌道の正規化が必要。

## B383 [存在] 同じ最大サイズでも盤外の飽和半径が異なる

- 判定: **SUPPORTED**
- 範囲: n=6 の 464 最大配置の r(S) を全計算。
- 証拠: n=6 で **r=1 が 424個、r=2 が 40個**。同じ K_6=11 で r が異なる。例: r=2 の配置は外側1層の全点が塞がる。`round2_b381.json` → `summary.n6_r_dist = {1: 424, 2: 40}`。

## B384 [全称・大胆] 最大配置の外部飽和半径は一様有界

- 判定: **INCONCLUSIVE**
- 範囲: n=6,7 の r を全計算。n≤2 しか確認できない。
- 証拠: n=6 で r≤2、n=7 で r=2。絶対定数 C=2 が n=6,7 では成立。しかし漸近主張の判定には n≥8 のデータが必要。

## B385 [存在] 盤内では最小極大なのに盤外の広い帯まで塞ぐ

- 判定: **INCONCLUSIVE**
- 範囲: 既知の 8×8 8石極大 `[0,1,6,20,24,32,34,60]` の r を計算。
- 証拠: **r=1**。外側1層に追加可能な点がある（例: (-1,-1), (-1,5), (-1,6) など6個）。「r を任意に大きくできる」の証人としては不十分。s_7=7 達成配置の r も計算する価値あり。

## B386 [全称] 7×7最大配置を8×8の15石へ変えるには元の石を2個以上捨てる必要がある

- 判定: **PARTIAL**
- 範囲: 全16配置×4平行移動=64埋め込みについて、既知の15石 witness との共通点数を計算。
- 証拠: **最大共通 = 6**（共有数分布 {1:10, 2:16, 3:17, 4:13, 5:5, 6:3}）。14−6=8 個の除去が必要。「≥2個除去」はこの witness に対しては大幅に成立。ただし n=8 の 15石最大集合の全数は未知（witness 1個のみ）のため全称としての確定は不可。
- メモ: B087（追加0手）よりはるかに強い。全 15石最大集合への拡張には n=8 の最大集合全列挙が必要。

## B387 [存在] 7×7最大配置の一方の相だけが少ない再配置で8×8最大へ届く

- 判定: **REFUTED**（witness 1個に対し）
- 範囲: A相・B相それぞれの最大共通点数を計算。
- 証拠: **A_max_shared=6, B_max_shared=6**。最小必要除去数は両相とも 8。差がない。
- メモ: 他の 15石 witness があれば結論が変わる可能性。ただし現時点の証人では非対称性なし。

## B388 [構造] 外点の禁止理由は遠方で直線だけに変わる

- 判定: **INCONCLUSIVE**
- 範囲: 外点が禁止される理由の分類（共円 vs 共線）の理論的主張。
- メモ: 理論的考察が必要。整数平面上で遠方の4点共円条件の解析は別課題。

## B389 [統計] 外部飽和半径は三点直線の方向数に結びつく

- 判定: **REFUTED**
- 範囲: n=6 全464配置の方向数（点対の方向ベクトル数）と r の相関。
- 証拠: **r=1 の平均方向数 = 27.06、r=2 の平均方向数 = 25.20**。方向数が多いほど r が小さい（逆相関）。仮説の「方向数が多いほど r が大きい」とは逆。

## B390 [存在] 内側の石を動かすだけで盤外の最初の合法点が遠くへ飛ぶ

- 判定: **PARTIAL**
- 範囲: n=6 の r=2 配置について一石移動近傍を走査。
- 証拠: r=2→r=1 の一石移動を発見。r の変化は確認できるが、「任意に大きくできる族」の証明には不十分。最大のジャンプは Δr=−1（縮小方向）。

## B391 [全称・大胆] 最大配置には連続した二本の空行がない

- 判定: **SUPPORTED**
- 範囲: n=6 (464), n=7 (16) 全配置の行・列の空行連続チェック。
- 証拠: **n=6, n=7 とも連続空行 0 件、連続空列 0 件**。n=6 では空行は最大1本のみ。

## B392 [全称・大胆] 最大配置の空行数と空列数は同時には多くならない

- 判定: **SUPPORTED**
- 範囲: n=6, n=7 全配置。
- 証拠: 両方 ≥2 となる配置 **0 件**。n=6 では空行≤1、空列≤1 なので自明に成立。n=7 では空行・空列とも 0。

## B393 [存在] 6×6の空行を持つ最大配置は空列も持つものと持たないものに分かれる

## B394 [構造] 6×6の空行の位置は中央の二本に限られる

- 証拠: 空行位置の分布 = **{1: 12, 2: 30, 3: 30, 4: 12}**。中央2本（2,3）に限られず、行1・行4 にも 12個ずつ出現。列も同様（{1:12, 2:30, 3:30, 4:12}）。

## B395 [統計] 空行を持つ最大配置は交換しやすい

- 判定: **REFUTED**

- 証拠: 空行/空列ありの平均交換次数 = **0.947**、全行列使用の平均 = **1.487**。空行を持つ配置の方が交換しにくい（次数が低い）。仮説は逆を主張。

## B396 [存在] 行・列占有ベクトルが同じでも最大集合の特定点数が違う

## B397 [構造] 最大配置の行列パターンには矩形の四隅を避ける制約が支配的

- 判定: **SUPPORTED**

## B398 [全称・大胆] 2n石以上の安全配置は空行・空列を持てない

- 判定: **SUPPORTED**（n=7 範囲）
- 範囲: K_7=14=2×7 の全16配置の行・列完全使用チェック。
- 証拠: **16/16 が全行・全列を使用**。n=6 では K_6=11 < 12=2×6 なので仮説の前提を満たす配置が存在しない（vacuously true）。
- メモ: n≥8 で K_n ≥ 2n となるかが残問。K_8=15 < 16 なので n=8 も vacuously true。

## B399 [存在] 行列占有数を固定した安全配置族に隔たりがある

## B400 [統計] 3石行の平行集中は最大性に不利

- 判定: **INCONCLUSIVE**
- 範囲: n=6 配置の3石行の連続/分散と一石移動次数の関係。
- 証拠: 3石行連続 (n=20) の平均交換次数 = 2.2、分散 (n=400) の平均 = 1.34。集中型の方が交換次数が高い。全配置が極大なので「最大性に不利」の直接判定不可。集中型が少ない (20/464) 事実はあるが、null model なしでは「不利」とは言えない。

## B401 [全称] 7×7最大配置の最小特定ペアは必ず異なるD4点軌道に属する

## B403 [全称] 7×7で相を指定すれば一点で最大配置を特定できる場合がある

### 最も重要な発見

1. **B397 の完全回避**: n=6 全464最大配置が軸平行矩形の四隅を一切占有しない。組合せ的制約として極めて強い。

4. **B389 の逆相関**: 方向数が多い配置ほど r が小さい。飽和半径の直感と逆。
