## B475 [漸近・大胆] 点数が固定の円が共円四点数の正の割合を担う
- 判定: **PARTIAL**（前回: PARTIAL → 今回: PARTIAL。n=3..20 の厳密計算で m=4 率が
  「1/n^2 へ減衰」ではなく**ほぼ一定 0.21 前後**であることが確定したが、無限 liminf は未証明）
- 前回の一手: 「B475/B476: n=7..10 の円スペクトル（M(n) が伸びるか）で競合を決める。」（round2-batch-b471.md）
- 今回の範囲: `research/verification/round3_b475_mn.json`（先行ワーカー計算済み・本担当は再実行せず
  読み取りのみ）。n=3..20 の円格子点数スペクトル M(n)、全円数 C_n、各円上の盤点数 m の
  4点組寄与 C(m,4) による分解。m ≥ 4 の円のみ保持、非共線3点の原始整数円鍵で重複除去。
- 証拠:
  - m=4 の円占比 f_n(4)（= `B475.f_by_m0["4"]`、全共円4点組のうち円上盤点がちょうど4のものの割合）:
    n=4: 0.2935, n=6: 0.2424, n=10: 0.2240, n=15: **0.2151（最小）**, n=20: 0.2196。
    n=4..20 の全 18 値で **0.215 以上を維持**し、n≥15 ではむしろ微増（0.2151→0.2196）。
  - 減衰なら当然出るべき n 依存が見えない証拠として、C_n は 48,513(n=10) → 2,493,800(n=20) で
    比 **51.4**、H_n[4] は 10,868 → 547,584 で比 **50.4**。両者の成長次数がほぼ同じ
    （n^4 と n^6 の間）なので比 f_n(4) は定数に留まる。`round3_b475_mn_asymptotic.py` の
    docstring が警告する「H_n[4] ~ c·n^2 なら f ~ c/c'·n^-2 → 0（B476）」という機構は
    実測では成立していない。
  - M(n) は n=3:4, n=4..7:8, n=8..11:12, n=12..20:16 と**単調増加**（前回メモの
    「M が 8 で頭打ちか」に回答：頭打ちではない）。
- 判定の根拠 / 残った障害: 観測範囲 n≤20 では B475 の主張（「ある m0 で liminf>0」）と矛盾する
  数値は一切出ず、特に m0=4 は下限 0.215 で安定している。**障害**: (1) 無限 n に対する
  証明がない。f_n(4) が n≳20 で突然 1/n^2 減衰へ転じる可能性は整数論的に排除できていない
  （C_n の非自明な円成分密度 الجمهورが未評価）。(2) 競合とされた B476 とは
  実測上**排反ではない**ことが分かった（下記 B476）。よって「Bold な漸近命題」を
  有限データで SUPPORTED にはできない。

## B476 [漸近・大胆] 四点寄与で重み付けすると円上点数は発散する
- 判定: **INCONCLUSIVE**（前回: INCONCLUSIVE → 今回: INCONCLUSIVE。ただし前回と状況が大きく
  変化。「M が頭打ちか」という前回メモの障害は解消し、**B476 の核心を反例にする数値が
  n=15 で出現した**ため、PARTIAL ではなく INCONCLUSIVE へ留めた）
- 前回の一手: 「B475/B476: n=7..10 の円スペクトル（M(n) が伸びるか）で競合を決める。」（round2-batch-b471.md）
- 今回の範囲: `round3_b475_mn.json` の `B476` セクション（P_le_by_m0 / weighted_mean_m_by_n）。
  n=3..20 の 18 個の n について、m0 ∈ {4,5,6,7,8,12,16} ごとの P(m ≤ m0) と加重平均 m。
- 証拠:
  - **加重平均 m は単調増加している**: 6.174(n=4) → 6.393(6) → 7.103(10) → 8.125(14) →
    **8.806(n=20)**。n=14→20 で +0.68(n=4→6 で +0.22 だったのに加速)。
    「発散する」側に動いている。
  - しかし **P(m ≤ m0) は 0 へ単調に落ちていない**。P(m ≤ 16) は n=3..20 で**常に 0.0**。
    P(m ≤ 8) は 0.0(n≤7) → 0.1024(8) → 0.1611(10) → 0.2562(12) → 0.3453(16) → **0.3876(20)**
    と**増加**しており、B476 の要求する「→0」と逆向き。
    P(m ≤ 4) も n=15 の 0.7849 を底に 0.7804(n=20) へ戻しており、0 へ向かう兆候がない。
  - m0=12 では P が n=11 まで 0.0、n=12 で 0.0412、n=20 で 0.1952。m0=16 は 0 のまま。
    → どの固定 m0 でも「確率が 0 へ向かう」ことが **n≤20 では一度も観測されていない**。
- 判定の根拠 / 残った障害: 主張は「任意の固定 m 以下である確率が 0 へ向かう」인데、
  実測はその方向に進んでいない（P(m≤8) は増加、P(m≤16) は恒等 0）。一方加重平均は発散寄りに
  動くため、主張の2つの部分のうち「平均は発散」側だけ兆候がある。**障害**: P(m ≤ m0) → 0 を
  言うには m0 を n とともに取る極限 distributional limit（円上点数の分布が測的極限を持つか）
  の議論が必要で、n=20 までの厳密整数計算では「まだ起きていない」と「起きない」を区別できない。
  特に M(n) が n=12..20 で 16 に留まっているため、m0=16 の P が恒等 0 なのは
  「M が 16 で頭打ち」という未検証の仮定の上に乗っており、
  B475 側で観測した M の単調増加と緊張する。

### 残る未解決とその一言理由
- **B475**: 無限 n の極限。n≤20 では m0=4 の割合が 0.215–0.294 に留まるが、
  n≳20 で 1/n^2 減衰に転じる可能性を排除できていない。
- **B476**: 「任意の固定 m 以下が確率 0 へ向かう」が n≤20 では一度も観測されない
  （P(m≤8) は 0.1024→0.3876 と増加、P(m≤16) は恒等 0）。加重平均の発散（8.81@n=20）のみ兆候。

### 最も有望な次の一手（1つだけ）
`round3_b475_mn_asymptotic.py` の設計どおり、
`H_n[4] / n^2` と `H_n[4] / n^4` の比を n=25,30 まで延长して**成長指数**を測る。
これが 4（=n^4 相当）なら f_n(4) は定数へ収束して B475 が決着し、
2（=n^2 相当）なら f_n(4) ~ 1/n^2 で B476 が強い形で決着する。n=3..20 の 18 点では
両仮説の区別が立っていないため、まずここを固めるのが最優先。
