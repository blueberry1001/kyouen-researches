## 最重要の新知見

1. **δ_quad(4×4) ≤ 7**（前回 ≤70 から大幅縮小）
   8 点円束のグリーディ最小反転族がサイズ 7、包含極小、共通点なし。
   B521 により 3 ≤ δ_quad ≤ 7。

2. **B523 REFUTED / B524 SUPPORTED**
   包含極小反転族は共通 3 点を持たない。B523 の「共有 3 点」は偽、
   B524 の「共通点なしの最小族」は真。

3. **δ_K(5) ≥ 3**
   5×5 で 1 点・2 点削除の全 325 組で K=9 が不変。n=4 の ≥4 と n=7 の 2 の間。

4. **幾何順 < ランダム順**（B530）
   空族→標準族の追加で、円束クラスタ順は 12 反転、ランダム順は 16 反転。
   幾何的順序が反転を抑制する方向の実証。

5. **n=5 でも対数凹が完全成立**（B561/B563）
   空盤・20 標本単一石・10 標本二石すべてで f ベクトルが対数凹。
   「1 点固定で壊れる」は n≤5 で標本上起きない。
