## 検証1: D_n の三重計数一致（n = 4..11）

三つの独立に導いた方法で共線四点組数 D_n を数え、**全 n で完全一致**した。

| n | 全四点組を走査（外積） | 有限和 (4) | 最大線分 C(ℓ,4) 和 | 一致 |
|---:|---:|---:|---:|:--:|
| 4 | 10 | 10 | 10 | ✓ |
| 5 | 64 | 64 | 64 | ✓ |
| 6 | 234 | 234 | 234 | ✓ |
| 7 | 660 | 660 | 660 | ✓ |
| 8 | **1,524** | **1,524** | **1,524** | ✓ |
| 9 | 3,156 | 3,156 | 3,156 | ✓ |
| 10 | 5,928 | 5,928 | 5,928 | ✓ |
| 11 | 10,428 | 10,428 | 10,428 | ✓ |

- 「全四点組を走査」は `C(n²,4)` 個の候補を正確な整数外積で判定する笨直な方法。
- 「有限和 (4)」は `round4-collinear-asymptotic.md` の式
  `D_n = 2Σ_H φ(H) Σ_{t≥3} C(t−1,2)(n−Ht)(2n−Ht)`。
- 「最大線分 C(ℓ,4) 和」は原始方向ごとに盤を横切る最大線分を求め `C(ℓ,4)` を足す、
  第1回個票が「二重計数を避ける唯一の分解」としたあの方法。

**n=8 の D_n = 1,524 は既知の確定値**（PROTOCOL.md の F_8 = 14,564 のうち
共線分が 1,524）と一致する。三手法一致で有限和 (4) の正しさが確認された。

再現: `python research/verification/scripts/verify_b141_independent.py`

## 検証2: 主項定数の区間評価（有理数演算）

φ を 200,000 までふるいで作り、`Σ_{H≤L} φ(H)/H³` を `Fraction` で厳密に評価。
尾部は `Σ_{H>L} φ(H)/H³ ≤ Σ_{H>L} 1/H² ≤ 1/L` で評価。

```
部分和 S_L        = 1.368429737992
主項定数 (7/60)S_L = 0.159650136099
尾部上界           ≤ 5.833e-07
```

したがって `0.159650136099 < 7ζ(2)/(60ζ(3)) < 0.159650719432`。

数値チェック: `7ζ(2)/(60ζ(3)) = 0.159650490722`（区間内 ✓）。

**原記録の主張区間 `0.159649781475 < c < 0.159650948143` は
我々の狭い区間を内包し、矛盾しない。**

重要なのは次の点:

> `D_n/n^5` の値は n=40 で 0.1189、n=1024 で 0.1566、n=100000 で 0.1596 と
> **単調に上昇し 0.15965 へ収束していく**。これは
> `D_n/n^5 = c − (3/(4ζ(2)))(log n)/n + O(1/n)` の**負の対数補正**の
> 正其自然であり、発散の兆候ではない。

第1回個票が `D_n/(n^5 ln n) = 0.0323` で安定したことから
`D_n = Θ(n^5 log n)` と結論したのは誤読だった。実際は
`D_n = c·n^5 − (3/(4ζ(2)))·n^4 log n + O(n^4)` であり、
**対数は主項ではなく n^4 次の補正項**に入る。
