## B101 [全称・大胆] 最大配置は四辺すべてに触れる
- 判定: **SUPPORTED**
- 範囲: n=6 の 464 最大集合・n=7 の 16 最大集合すべてについて、上辺 y=0 / 下辺 y=n-1 / 左辺 x=0 / 右辺 x=n-1 との交差を完全検査。

- メモ: 「平行移動による余地が残らない」の根拠としては n=6,7 で確定。全称 n≥4 は n=4,5 の完全データがあれば SUPPORTED に昇格可能。

## B102 [全称・大胆] 最大配置はどの行・列も空にしない
- 判定: **REFUTED**
- 範囲: n=6,7 の全最大集合について行射影・列射影の全域性を検査。
- 証拠: **n=6 で 84/464 集合がちょうど 1 本の空行を持つ**（`empty_rows_per_set = {1: 84, 0: 380}`）。列も同数。n=7 では 16/16 が行・列とも全域。反例: n=6 の空行をもつ 84 集合のいずれか（例は JSON の `empty_rows_per_set` と行プロファイルから復元可能）。
- メモ: n=7 では成立するが、n≥4 の全称としては n=6 で偽。n=6 の空行集合は「1 行だけ空」で、2 行以上の空は無い。

## B103 [統計] 最大配置の行占有数は2に集中する
- 判定: **PARTIAL**
- 範囲: n=6（464×6=2784 行）、n=7（16×7=112 行）の行・列占有ヒストグラム。
- 証拠:
  | n | 行占有 0 | 1 | 2 | 3 | frac(=2) | frac(∈{0,1,3}) |
  |---|---:|---:|---:|---:|---:|---:|
  | 6 | 84 | 856 | 1284 | 560 | 46.1% | 53.9% |
  | 7 | 0 | 28 | 56 | 28 | 50.0% | 50.0% |
  方向としては「0,1,3 の合計割合」が n=6→7 で 53.9%→50.0% と減少し、(=2) が 46.1%→50.0% に増加。ただしその差は小さく、「2 に集中」と呼べるほどではない（半数程度）。列も行と同分布。
- メモ: n=5 の 100 集合と n=4 の 64 集合の行占有があれば傾向の検定が可能。現状 n=2 点のみで「n が大きいほど小さい」は弱い支持。

## B105 [存在] 点を一つ指定すると最大サイズが2以上下がる
- 判定: **REFUTED**
- 範囲: n=6,7 について `max{|S|: p∈S}` を既知情報から評価。
- 証拠:
  - n=6: 全 36 点が何らかの最大集合に出現するため、任意の p で `max{|S|:p∈S} = K_6 = 11`。低下 0。
  - n=7: (2,2) の 4 点は最大集合に現れないが、Package B COMPLETE により **(2,2) を含む最大安全サイズは 13 = K_7−1**。他の点はいずれかの最大集合に出現するので低下 0。
  - よって n=6,7 で単一点指定による低下の最大は 1 であり、**2 以上下がる点は存在しない**。
- メモ: 中心+(2,3) で 12 = K−2 になることは既知だが、これは 2 点指定。「強い幾何的損失」を単一点で作るなら n≥8 の未探索盤を当たるべき。

## B106 [全称・大胆] 最大配置はO(log n)点で特定できる
- 判定: **PARTIAL**
- 範囲: n=6（464 集合）の 1,2,3-部分集合、n=7（16 集合）の 1,2,3-部分集合について min_det を完全計算。
- 証拠: n=7 は全 16 集合で **min_det = 2**（CYCLE6 の `min_det(S)=2` と一致）。n=6 は全 464 集合で **min_det = 3**。既知の n=4 (3–4)、n=5 (3) と合わせ、n=4..7 で min_det ≤ 4。`C_0 log n` は C_0≈2, n=6,7 で成立（3 ≤ 2·ln6≈3.6, 2 ≤ 2·ln7≈3.9）。漸近 O(log n) 自体は 4 点のデータから証明不能。
- メモ: 7×7 の 2 点特定は最良。n=6 が 3 であることは「点数が少ないほど特定しやすい」とも整合。n=8 の K=15 集合の min_det が 2–4 に収まるかが次の検証点。

## B107 [統計] 最大集合が少ない盤ほど最小特定点数も小さい
- 判定: **PARTIAL**
- 範囲: n=4,5,6,7 の (最大集合数, min_det) ペアを比較。
- 証拠: n=7 (16 集合, det=2) と n=6 (464 集合, det=3) の対では予想どおり。ただし n=4 (64 集合, det 3–4) と n=5 (100 集合, det=3) の対では「集合数が少ない n=4 が det も小さい」にならない（3–4 vs 3）。
- メモ: 対数情報量 `log_2 |M|` と min_det の相関を n=4..7 で計算すると (5.999, 3–4), (6.64, 3), (8.85, 3), (4.0, 2) となり単調でない。n=6→7 の急変が効いている。標本が少なく INCONCLUSIVE に近いが、n=6,7 の対は支持。

## B109 [存在] 同じD4軌道占有ベクトルに異なる交換障壁がある
- 判定: **SUPPORTED**
- 範囲: n=6 の 22 軌道占有クラスごとに 1-swap 次数分布を計算。
- 証拠: 例として 56 集合からなるクラス 0 は `deg_hist {0:32, 1:16, 2:8}`、72 集合のクラス 8 は `{0:48, 1:8, 2:8, 5:8}`、24 集合のクラス 19 は `{0:8, 6:8, 3:8}`。**同一の軌道占有ベクトル内で 1-swap 次数が 0〜6 に振れる**。deg=0 の集合は他最大集合へ移るのに K−1 以下への下降が必要、deg>0 は K のまま移動できる。したがって最小石数低下がクラス内で異なる。n=7 は 2 クラスとも全員 deg=0（ρ=2）で変化なし。
- メモ: 「軌道別占有数が同じでも交換障壁が違う」の存在証明は n=6 で成立。どのクラス・どの代表ペアが最もあるかの分類は未。
