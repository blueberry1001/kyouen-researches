# B079: 十盤六石の重複被覆総数は正確に85

作成: 2026-10-01。**B079 PARTIAL。**
10×10の安全六石Sについて、全空点での禁止理由の合計は

    Σ_{p∉S} b_S(p) ≤ 85 < 94 = 100−6.

上界85は等号を達成する。従って六石では極大になれない。
ただし85の上界は今回の完全な組合せ最適化による。
原文の「全局面の列挙に依存しない短い共起不等式の証明」はまだ得ていない。
非存在の再確認・鋭い上界と、原命題の決着を分ける。

## 総被覆の恒等式

石三つ組Tの盤内補完点数をc(T)とする。
安全Sでは、その曲線上に四石目がないので補完点はすべて空点である。
禁止関係(T,p)を二通りに数えることで

    Σ_{p∉S} b_S(p) = Σ_{T⊂S, |T|=3} c(T)

を得る。以前の一律c(T)≤9からの180という上界を、同じSに同時に現れる三つ組の総和85へ改善した。

等号証人は添字[13,22,32,53,62,63]、座標
[(3,1),(2,2),(2,3),(3,5),(2,6),(3,6)]。
全15四点組は安全。二十個のc(T)の内訳は
1が3個、2が1個、3が5個、5が7個、7が3個、9が1個で、合計85。
全94空点に対し、三つ組曲線と直接整数行列式によるbの値が一致する。

`round48_max_incidence.cpp`は安全六石の重複被覆を最大化する。
極大性による枝刈りを使っていないので、極大でない配置も最大化の対象に含む。
昇順で石を追加し、安全性だけで候補を除外する。
残り三つ組を既存2石+未来1石、既存1石+未来2石、未来3石に分け、
それぞれの区間付き最大補完数を足した楽観的上界が既知の最大値以下なら枝を除く。
上界は相互安全性と重複を無視するので過大側。
