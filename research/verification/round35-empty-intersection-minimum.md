# B524: 基数最小の反転解除族でも共通点は空

作成: 2026-09-30。**B524原文SUPPORTED、B523原文REFUTED。**
4×4の最小反転解除数は既に3と全域検査で確定している。
今回は、その最小基数3を達成し、三組の共通部分が空の解除族を見つけた。
過去のサイズ7の包含極小族より強く、基数最小という読みでも原文が成立する。

座標0始まり、点IDはx+4y。解除する禁止四点組は

    e1の点ID=[0,1,6,12]、e1={(0,0),(1,0),(2,1),(0,3)}
    e2の点ID=[1,7,8,14]、e2={(1,0),(3,1),(0,2),(2,3)}
    e3の点ID=[2,4,7,11]、e3={(2,0),(0,1),(3,1),(3,2)}

である。三組の共通部分は空。
e1∩e2={1}、e2∩e3={7}、e1∩e3は空なので、共通点を持たないことは座標からも確認できる。
標準族の辞書順インデックスは[3,78,97]、盤点maskは[4163,16770,2196]。

| 解除する族 | なし | e1 | e2 | e1,e2 | e3 | e1,e3 | e2,e3 | 全三組 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 空盤の真のg | 0 | 0 | 0 | 0 | 0 | 0 | 0 | **2** |

全8部分族の勝敗とmexを、禁止署名を使う全部分集合DPと、保持四点組を直接走査する逆手順の
メモ再帰で独立照合した。両方式は各版の**全安全局面のmex**で一致し、
再帰で訪れた局面数と全部分集合DPの安全局面数も一致した。

[round19の全域下界](round19-rule-removal-audit.md)は194通りの全単独解除と18,721通りの全二組解除を
D4軌道で漏れなく検査して勝者反転0を証明している。
その既存下界と今回の三組反転を合わせると、この族は**基数最小**である。
今回その下界計算自体は再実行せず、保存された全軌道結果・被覆数・P判定を監査し、
根拠ファイルのSHA-256を今回の証明書にも記録した。

B523の共有三点という要求は、基数最小族の共通部分が空なので反証される。
なおround19の別の三組証人でも共通部分は一点だったため、B523の反証は既に得られていた。
今回の新しい強い成果は、**共通点なしの族を基数3まで縮め、B524の最小性の留保を閉じたこと**である。

[探索器](scripts/round35_empty_intersection_search.cpp)は整数幾何から全194組を生成し、
固定seedの標本探索で候補を発見した。これは全三組族の分類ではない。
存在証明に必要なこの一族については、[検算器](scripts/round35_minimum_family_verify.py)が幾何を
生成し直して上記全域mex照合を行った。

    python research/verification/scripts/round35_minimum_family_verify.py
