## 技術的進展

1. **3-subset テーブルによる合法手計算の高速化**（3.7 倍）
   - 従来: F=14,564 四点組を全走査 → 新: C(k,3) ルックアップ
   - `triple_blk[p1][p2][p3]` = 4 点目のブロックビットマスク
2. **エッジカウントの gen_next_spill 統合**（メモリ OOM 回避）
3. **ストリーミング DP**（grundy u8 + p_rand u32 = 5B/state + mmap 子マスク）
   - 従来: 78.49 GB 必要 → 新: 18.60 GB で完走
4. **--resume の .ok マーカー方式**（途中再開対応）
5. **psum の u32→u64 変更**（オーバーフローバグ修正）

## 注意事項

- P_max_filter_value は **u32 固定小数点（SCALE=2^30）** の近似値。
  正確な分数は多倍長整数版（round4_b501_prand.cpp）での再計算が必要。
- 閾値カウント（1/2, 2/3, 3/4 超）は u32 の正確な整数比較で計算済み。
  **CRT 版の閾値制限は無い**（固定小数点比較）。
- n=8 の empty 盤の p_rand ≈ 0.47026（g=0、P 局面）。
