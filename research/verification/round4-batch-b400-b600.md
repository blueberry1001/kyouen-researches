## B473 [構造] 共線数の有限サイズ補正を境界長とgcd和へ分けられる
- 判定: **SUPPORTED（証明）**（前回: PARTIAL → 今回: **SUPPORTED**。`n^4 log n` の次項が導出され、
  round2 の「`n^5 log n` 主項」前提は誤りと確定）

  （round2-batch-b471.md:74-80）。今回は**証明に到達**。
- 原文の主張: 「主項の候補だけでなく、次項を `n^4` と**対数・約数和**の組合せで記述し、
  小盤の見かけの成長率の上昇を説明できる。」
- 今回の範囲: `round4-collinear-asymptotic.md` §6 の証明（境界効果とφ(H)を分離した厳密式）。
  再計算は不要（既に同ファイル §8 で n=1..20 の三方式一致と n=2..11 の既知 D_n 再現が確認済み）。
- 証拠（証明の骨格、ファイル §2 式(1)・§6 式(4)(6)(7)）:
  - 方向 v の共線四点組数は
    `D_v(n) = Σ_{t=3..⌊(n−1)/H⌋} C(t−1,2)·(n−at)(n−bt)`（H=max(a,b)、gcd(a,b)=1）。
  - 有限和を精确に閉じたものが**境界長とgcd和の分離**そのもの:
    `P_H(n) = H²S₄ − 3H(n+H)S₃ + (2n²+9nH+2H²)S₂ − 6n(n+H)S₁ + 4n²q`
    （`S_j(q)=Σ_{t≤q}t^j`, `q=⌊(n−1)/H⌋`）、そして **`D_n = Σ_H φ(H)·P_H(n)`**。
    φ(H) は**高さ H の原始方向の本数**＝gcd 和であり、`P_H` は剰余・床関数の**境界効果**だけ。
    この 2 項への分解が原文の「境界長と gcd 和へ分けられる」に厳密に対応する。
  - 一様評価 `P_H(n) = (7/60)n⁵/H³ − (3/4)n⁴/H² + O(n³/H)`（1≤H≤n）。
    積分部と和の差は台形公式で O(n³/H) に抑えられる（第 2 階微分絶対値の積分が同程度）。
  - φ を掛けて足し、`Σ_{H≤n}φ(H)/H ≤ n` を使い、級数尾部は §4 の O(n⁵/h) 評価で O(n⁴)。
    したがって **`D_n = (7ζ(2)/(60ζ(3)))n⁵ − (3/4)n⁴·Σ_{H≤n}φ(H)/H² + O(n⁴)`**。
  - 残る和はメビウス展開で `Σ_{H≤n}φ(H)/H² = Σ_{d≤n} μ(d)/d² · Σ_{k≤n/d} 1/k
    = (log n)/ζ(2) + O(1)`（`Σ(log d)/d² < ∞` のみで使う）。
  - よって **`D_n = 7ζ(2)/(60ζ(3))·n⁵ − 3/(4ζ(2))·n⁴ log n + O(n⁴)`**。
    **次項が「n⁴ × 対数の約数和」（φ 和が log n/ζ(2) に退化）で書けた** = 原文の要求を満たした。
- 小盤の見かけの成長率の上昇の説明（原文後半）:
  `D_n/n⁵ = 7ζ(2)/(60ζ(3)) − 3/(4ζ(2))·(log n)/n + O(1/n)`。

  実測（§8）: n=8 で 0.0465、n=32 で 0.1119、n=128 で 0.1428、n=1024 で 0.1566、
  n=16,384 で 0.15938、n=100,000 で 0.15960。**増加は有限極限への収束**であり発散でない。
  ただし証明は**「全 n で単調増加」までは主張しない**（O(1/n) 項が単調性を保証しないため）。
- 訂正: round2-batch-b471.md の B473 は n⁵log n を主項として残差を測っていたため
  「主項より一桁小さい補正」を観測できていなかった。正しい次項は **n⁴ log n** であり、
  上の二項漸近式の各項と §8 の実測表が整合する。
- 残った障害: O(n⁴) 誤差項の内訳（境界長 vs gcd 和の寄与比）は未分離。
  また本判定は**共線**四点組についての命題であって、
