# 5合法点の swap 則：列挙を使わない組合せ論的証明

2026-10-03。[主要ノート](game-structure-20261003.md) の「5合法点まで」という境界を、
6,894族の全列挙に依存せずに証明する。

## 設定

有限集合 \(V\) 上の下方閉族 \(K\subseteq2^V\) を合法集合族とする。
\(\varnothing\in K\) で、すべての一点集合も \(K\) に属する。
1手で一点を追加する通常プレイゲームの根の Grundy 数を \(g(K)\) と書く。

点 \(v\) を選んだ後のゲームは

\[
\operatorname{lk}_K(v)=\{T\subseteq V\setminus\{v\}:T\cup\{v\}\in K\}
\]

である。一点集合が合法でない頂点は、この link の頂点集合から取り除く。
したがって、このノートの頂点数は**現在の合法点数**を意味する。
三点の合法集合を「三角形」、四点の合法集合を「四点面」と呼ぶ。
円や直線による幾何は仮定しない。

補助 mex 値 \(h\) は終端で1、非終端で子の \(h\) の mex とし、
\(\tau\) は0と1を交換して2以上を固定する写像とする。
\(h\) は一般の直和を xor で計算できる値ではない。

## 補題1：最大合法サイズ2のゲーム

合法な二点集合を辺とするグラフを \(H\) とする。
三点以上の合法集合がないとき、通常値は次の通り。

| グラフ \(H\) | \(g\) |
|---|---:|
| 頂点なし | 0 |
| 頂点はあるが辺なし | 1 |
| 辺があり、孤立点もある | 2 |
| 孤立点なし（頂点はある） | 0 |

*証明。* 孤立点を選ぶと終端なので子の値は0。
非孤立点を選ぶと、一点以上は追加できるが二点は追加できないゲームになるので子の値は1。
従って根で現れる子の値集合は、順に空集合、\(\{0\}\)、\(\{0,1\}\)、\(\{1\}\)。□

## 補題2：高々5頂点の三角形被覆

空でない高々5頂点の集合が三角形の族で被覆されているなら、ある頂点 \(v\) が存在して、
**どの他頂点 \(u\) も、\(v\) と同じ三角形に属する**。

*証明。* 一つの三角形を \(A=\{a,b,c\}\) と取る。
外側の頂点がなければ明らか。外側が一点 \(d\) なら、\(d\) を含む三角形は
\(A\) の二点を含むので、その二点のどちらかを \(v\) にする。

外側が二点 \(d,e\) の場合、両方を含む三角形があれば、その三角形の残る頂点 \(v\in A\) を取る。
そのような三角形がなければ、\(d\) と \(e\) を被覆する三角形は、それぞれ \(A\) の二点を含む。
三元集合の二元部分集合どうしは交わるので、共通の頂点を \(v\) とする。
元の三角形 \(A\) と合わせて、\(v\) は他の全頂点と同じ三角形に属する。□

## 補題3：二つの三角形を含む4頂点ゲーム

4頂点の合法集合族が相異なる二つの三角形を含み、四点面を含まないなら、通常値は1である。

*証明。* 二つの三角形を \(abc,abd\) とする。
\(a\) の link の二点合法グラフは、\(b,c,d\) 上で少なくとも辺 \(bc,bd\) を持つ。
四点面がないので link に三角形はなく、孤立点もない。補題1より子の値は0。
\(b\) についても同じ。

\(c\) を選んだ後、\(d\) が合法でなければ、残る \(a,b\) は両方選べるので子の値は0。
\(d\) も合法なら、link の二点合法グラフは \(a,b,d\) 上で辺 \(ab\) を含む。
三角形はないため、補題1より値は、\(d\) が孤立すれば2、孤立しなければ0。
\(d\) を選ぶ場合も同じである。

したがって全ての子の値は0または2で、0は必ずある。mex は1。□

## 定理4：5頂点以下では、通常値0か1の子が必ずある

\(1\le|V|\le5\) の下方閉ゲーム \(K\) は、ある合法な初手 \(v\) を持ち、

\[
 g(\operatorname{lk}_K(v))\in\{0,1\}
\tag{3}
\]

となる。

*証明。* 五点の合法集合があれば、\(|V|=5\) で全ての部分集合が合法。
どの一点を選んでも残り四手のゲームになり、子の値は0である。
以下では五点の合法集合がないとする。

### 四点面がない場合

三角形に属さない頂点 \(v\) があれば、その link には二点の合法集合がない。
補題1より値は0または1。

全頂点が三角形に属するなら、補題2の頂点 \(v\) を取る。
その link は他の全頂点を持ち、二点合法グラフに孤立点がない。
四点面がないので link に三角形はなく、補題1より子の値は0。

### 四点面が二つ以上ある場合

高々5頂点なので、相異なる四点面 \(A,B\) の共通部分は三点ある。
\(v\in A\cap B\) を取ると、link は四頂点を持ち、相異なる三角形
\(A\setminus\{v\}, B\setminus\{v\}\) を含む。
五点面がないので link に四点面はなく、補題3より子の値は1。

### 四点面がちょうど一つの場合

唯一の四点面を \(A\) とする。\(V=A\) なら、任意の一点を選ぶと残り三点が全て選べるので子の値は1。
以下、\(V=A\cup\{e\}\) とする。

もし \(u\in A\) で \(\{e,u\}\) が合法でない点があれば、\(u\) の link は
\(A\setminus\{u\}\) 上の完全な三点集合だけで、子の値は1。

残る場合は、\(e\) と \(A\) の各点とのペアが全て合法である。
\(A\) 上のグラフ \(H\) を、\(\{u,w\}\) が辺であることと
\(\{e,u,w\}\in K\) が同値になるように定める。

- \(H\) に孤立点がなければ、\(e\) の link の二点合法グラフは \(H\) である。
  \(e\) を含む四点面はないため link に三角形はなく、補題1より子の値は0。
- \(H\) に孤立点 \(u\) があれば、\(u\) の link は、完全な三点集合
  \(A\setminus\{u\}\) と、これらのどの点とも同時に選べない一点 \(e\) からなる。
  \(e\) を選べば即終端、三点集合側を選べば残り二点を全て選べる。
  従ってこの link の全ての子の値は0で、その通常値は1。

全ての場合で (3) が得られた。□

## 定理5：5合法点の swap 則

現在の合法点が高々5個の任意の下方閉ゲームについて、

\[
 \boxed{h=\tau(g)}
\]

が成り立つ。

*証明。* 合法点数による帰納法を用いる。0点は終端なので \((g,h)=(0,1)\)。
一点を指すと合法点数は必ず減るから、子の通常値集合を \(B\) とすると、
子の補助値集合は帰納法の仮定から \(\tau(B)\) である。

非終端で \(B\cap\{0,1\}\ne\varnothing\) なら、

\[
\operatorname{mex}\tau(B)=\tau(\operatorname{mex}B).
\]

実際、0と1が両方 \(B\) にあれば mex は2以上で交換の影響を受けず、
片方だけなら二つの mex が0と1になる。
定理4はまさに \(B\cap\{0,1\}\ne\varnothing\) を保証する。□

この証明で調べたのは「四点面が0個・1個・2個以上」という構造だけであり、
6,894族の列挙、盤の対称性、共円・共線の性質には依存しない。

## 境界の鋭さ

6合法点で二点禁止グラフが \(C_6\) なら、一手後は \(P_3\) である。
\(P_3\) は通常・補助 mex が共に2なので、元の局面は \((g,h)=(0,0)\)。
したがって5点上限は鋭い。この \(C_6\) は主要ノートの5×5共円局面で実現される。

169同型類・69,940ラベル付き例外という**6点での完全な個数分類**は、引き続き計算機援用部分である。
一方、5点までの swap 則、および「6点で破れるなら必ず両 P」という結論は、
このノートと主要ノートの mex 交換補題だけで証明された。
