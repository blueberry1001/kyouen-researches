# Research log

研究の時系列を保存します。

推奨配置:

```
research/log/2026/10/01/
  0312-n11-dfpn-center20.md
  0415-fixed-width-proof.md
```

1日1巨大ファイルではなく、研究セッションやまとまった作業ごとに分けます。
複数エージェントが同時に同じログを編集しないことを優先します。

ログには必要に応じて次を残します。

- 何を考えたか
- 何を試したか
- 何が失敗したか
- 何を発見したか
- 次に何をするか

ログは「どうして現在の知識に到達したか」の履歴です。
重要な結論がログにしか存在する状態を長期間残さず、価値が確定したものはK項目へ昇格させます。

既存の Round / Cycle / night-research 文書は当面そのまま残し、必要なものから参照・移行します。
